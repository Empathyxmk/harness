# Directory Explanation

- src/: Primary library modules.
  - Implements the 'map' and 'rbtree' structures/APIs used in all tests. 
  - At present, only stubs are included; you must complete them.

- tests/original/: Translated original tests from the C project.
  - test_map.rs: Covers basic and edge-case map/rbtree operations.
  - test_rbtree.rs: Red-black tree correctness & structural tests.
  - Uses standard Rust #[test] unit test framework.

- public_tests/: Translated public test suite (as in challenge/exam/public case settings).
  - test_map_public.rs, test_rbtree_public.rs: Public evaluation cases.
  - Use #[test] and can be run via 'cargo test' as integration tests.

- Cargo.toml: Standard Rust manifest.
- run_tests.sh: Ultra-simple script to run all tests.
- README.md: Usage and high-level notes.

# Test Execution

1. Make sure you have Rust (cargo) installed.
2. Run:
   ./run_tests.sh
   (or alternatively, cargo test)

# Implementation Instructions

- To make tests pass, implement the required APIs for 'map' and 'rbtree' in src/map.rs and src/rbtree.rs.
- The test stubs are structured exactly after their C source, with full feature and edge-case parity.
