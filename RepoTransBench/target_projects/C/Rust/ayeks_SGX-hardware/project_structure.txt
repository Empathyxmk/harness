# Directory and file purpose:

# src/lib.rs         - Library functions for original (private/original) test logic
# src/lib_public.rs  - Functions for public tests (different stub values)
# src/*.rs           - Code modules for cpuid, rdmsr, vdso, xsave (with .public module for public tests)
# tests/original/    - All translated original C tests: structured as Rust #[test] functions
# public_tests/      - All translated public C tests; use src/lib_public.rs or the 'public' submodules
# run_tests.sh       - Runs `cargo test` to execute all test files (both original and public)
# Cargo.toml         - Standard Rust crate manifest for building and running tests

# To run ALL tests (original and public), run:
#   ./run_tests.sh

# To run only original tests:
#   cargo test

# To run only public tests:
#   cargo test --test test_main_public

# (or any test by name).
