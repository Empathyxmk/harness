- project_structure.txt: Overview of project organization

Testing and Setup Instructions:
1. Prerequisite: Install Rust (https://rustup.rs/)
2. Make `run_tests.sh` executable: `chmod +x run_tests.sh`
3. To run ALL tests (original and public): `./run_tests.sh`
   - This invokes `cargo test --all --release`, running tests from both `tests/original/` and `tests/public/`.
4. To run tests interactively:
   - `cargo test`           (or restrict via module name)
   - See individual files in `tests/original/` and `tests/public/` for details.
