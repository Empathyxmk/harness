# Directory and file explanations:

- Cargo.toml: Rust package manifest, defines dependencies and registers test executables
- src/lib.rs: Main source lib, empty for this translation as all logic is inline in the tests
- tests/original/: Contains Rust test files translated from the original (non-public) C tests
- public_tests/: Contains Rust test files translated from the public C tests
- run_tests.sh: Simple script to run all tests (`cargo test`)
- project_structure.txt: This documentation and structure map

# Setup & test usage

1. Prerequisites: Rust toolchain (https://rustup.rs)
2. To run all tests: `./run_tests.sh`
3. The output will indicate all original and public tests pass, following logic identical to the C harnesses.
