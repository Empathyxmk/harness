#
# Directory explanations:
#   src/            - Library source code (minimal stubs & scaffolding for test targets)
#   tests/original/ - Translation of original C unit tests
#   tests/public/   - Translation of public “reference” tests (sometimes generated from C)
#   run_tests.sh    - Simple script to execute all test suites
#
# To run tests:
#   chmod +x run_tests.sh
#   ./run_tests.sh
#
# All tests are written with Rust’s standard #[test] framework and can be individually run with `cargo test`.
