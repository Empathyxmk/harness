Setup and Testing Instructions:
1. This is a Rust project that requires Cargo to build and run
2. To run all tests, simply execute: ./run_tests.sh
3. To run specific tests, use: cargo test <test_name>
4. The project structure follows Rust conventions with src/ for source code
   and tests/ for test files
5. Original tests are in tests/original/ and public tests are in public_tests/
