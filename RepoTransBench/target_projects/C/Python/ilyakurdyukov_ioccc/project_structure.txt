# Directory/filename explanations:
# - src/: All Python solution/logic code. Fill in lettermixer.py/markovchain.py with actual implementations.
# - tests/original/: Python tests auto-adapted from "original" test cases of the C repo.
#     These check basic functional correctness (input doesn't crash, returns string).
# - public_tests/: Python tests using "public" input cases.
# - tests/2020-lettermixer/, tests/2020-markovchain/: These subfolders store the actual input files used by tests.
# - requirements.txt: Must have pytest or any other dependencies.
# - run_tests.sh: Installs dependencies and tests everything via pytest in one command.
# - README.md: Add a project description/instructions here.
# - project_structure.txt: This doc.

# Setup & Testing:
#   1. Ensure Python 3 is installed.
#   2. Run `./run_tests.sh` from the project root.
