Explanation:
- **src/quadprog/__init__.py**: This is a dummy placeholder. The actual `quadprog` module (containing `solve_qp` and `solve_qp_factorized`) is a C extension from the original repository and is assumed to be installed in the environment for the tests to run correctly. This file just makes `quadprog` importable from `src`.
- **tests/original/**: Contains Python translations of the original C test files (`test_linear_algebra.c`, `test_qr_update.c`) and the existing Python original tests (`test_1.py`, `test_factorized.py`). The C tests' logic is preserved by reimplementing the specific linear algebra functions they test in Python using NumPy.
- **public_tests/**: Contains Python translations of the public C test files (`test_linear_algebra_public.c`, `test_qr_update_public.c`) and the existing Python public tests (`test_1_public.py`, `test_factorized_public.py`).
- **requirements.txt**: Lists Python packages required to run the tests.
- **run_tests.sh**: A simple script to install dependencies and execute all tests using `pytest`. It ensures `src` is in `PYTHONPATH` for module discovery.
