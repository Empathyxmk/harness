Folders and Purpose:
- src/: (Python) implementation source; luautf8.py provides a mockup.
- tests/original/: Original author's full behavioral/coverage tests (all translated into pytest style).
- public_tests/: Minimal and public (generated) tests, for interface and limited correctness checks.
- run_tests.sh: Execute ALL tests in both original and public test folders.
- requirements.txt: Only pytest required.
- README.md: (to add) Usage instructions.

Running Tests:
- Ensure Python 3.x is installed.
- (Optional) Create and activate a venv.
- Install dependencies: `pip install -r requirements.txt`
- Run all tests: `./run_tests.sh`
