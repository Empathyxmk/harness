NOTES:
- To run ALL tests, use `./run_tests.sh` (runs pytest for all `pykdtree/test_*.py`).
- To run only public tests, use `./run_public_tests.sh`.
- All original and public test files remain in `pykdtree/` as in the original structure (mirrors input sources).
- Source and tests are all in the `pykdtree/` directory.
- Install dependencies first: `pip install -r requirements.txt`
- To run coverage, run: `pytest --cov=pykdtree --cov-report=term`
