Directory explanations:
- src/bplustree/__init__.py     : Contains the BPlusTree class and C-API-like wrappers.
- tests/original/               : Original test cases, mapped from C sources.
- public_tests/                 : Public test cases, mapped from public C test sources.
- requirements.txt              : Python project dependencies (pytest).
- run_tests.sh                  : Simple script to run all tests (`pytest`).
- project_structure.txt         : This file. Explains the layout and setup.
- (init.py files)               : Enable Python package/test discovery.

Setup & Testing:
1. Ensure Python (>=3.6) is installed.
2. Run `./run_tests.sh` from project root.
   This script will install dependencies (if needed) and run all tests using pytest.
3. Test output for all suites (original/public) will be displayed.
4. Implement your bplustree logic in src/bplustree/__init__.py for full feature parity.
