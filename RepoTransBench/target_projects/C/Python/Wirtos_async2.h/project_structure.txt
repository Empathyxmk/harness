Directory explanations:

- tests/original/: Original (“private”) test translations matching the source project’s C coverage, including integration coverage.
- public_tests/: Public-facing tests derived from public source tests
- requirements.txt: Installs pytest for testing

- project_structure.txt: This file (describes layout)

**Setup & Testing instructions:**
1. Install Python 3.7+.
2. Install dependencies: `pip install -r requirements.txt`
3. Run all tests: `./run_tests.sh`

To run only original or public tests:
- pytest tests/original/
- pytest public_tests/

**Test output**: Standard pytest output, passes/fails for all cases, replicating C test logic.
