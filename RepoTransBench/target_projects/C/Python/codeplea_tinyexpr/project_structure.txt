---
Directory/Files Purpose:
- src/tinyexpr/: Main package where a Python interface of tinyexpr is provided. For testing purposes, a Python "dummy" version is implemented to allow test execution.
- tests/original/: Contains translations of all original/private test cases from C using pytest.
- public_tests/: Contains all the public tests generated for verification purposes, translated to pytest.
- requirements.txt: List of all dependencies needed for running tests (just pytest for this project).
- run_tests.sh: Simple, executable shell script for running all tests with one command.
- project_structure.txt: Describes the complete Python project layout.
---
Setup & Testing Instructions:
1. Install Python 3.8+ if not already installed.
2. Run `pip install -r requirements.txt` to install pytest.
3. Run all tests with: `./run_tests.sh`
4. Add or modify code/tests following this structure.
