Directory Explanations:
- requirements.txt: Declares Python dependencies (pytest) for easiest setup with pip.
- run_tests.sh: Installs dependencies and runs both sets of tests with pytest for one-click verification.
- public_tests/: Contains Python translations of PUBLIC user-facing C tests ("_public" C sources). Clean, easy to copy/use tests.
- tests/original/: Direct Python translations of original user-space C test files for developer-internal testing, maximal coverage, not expected for end-users.
- Each test Python file contains translation of C assertions, boundary/value logic, and prints for inspection.
- __init__.py: Allows test discovery and Python module management.

Setup/Usage instructions (see README.md for details):
1. Make sure Python 3.7+ is installed (virtualenv recommended).
2. Run all tests: `./run_tests.sh`
3. To run tests individually: `pytest tests/original/` or `pytest public_tests/`

This structure keeps public and original/coverage tests clearly separated, and ensures all edge/branch cases and public outputs are covered.
