Directory/Module Explanations:
- src/                : Python source implementation (stub provided; to be replaced by correct buddy allocator code)
- tests/original/     : Original tests (main, edgecases, extras) mapped directly from source C tests.
- public_tests/       : Public tests (from test_public.c etc) mapped to Python, kept separate for clarity.
- run_tests.sh        : One-click script to run all tests (simply calls 'pytest').
- requirements.txt    : Python dependencies, just 'pytest'.
- \_\_init\_\_.py     : Mark folders as Python packages (required for import/discovery by pytest).
- project_structure.txt: This documentation file.

How to Run Tests/Setup:
1. Install dependencies: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`
