Directory purpose explanations:
- src/xiahouzuoxin_fft/: Python implementation of the core FFT library and math routines.
- tests/original/: Translations of all *original* C test cases (preserved logic).
- public_tests/: Translations of all C public test cases for public validation.
- requirements.txt: Lists pytest, numpy and any dependencies.
- run_tests.sh: One-click script to run *all* tests under both main and public test dirs.

To run all tests: see README.md or just execute ./run_tests.sh
