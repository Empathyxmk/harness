---
**Setup and Testing Instructions:**

1.  **Navigate to the project root directory:**
    `cd /path/to/project_root`

2.  **Make the test script executable:**
    `chmod +x run_tests.sh`

3.  **Run all tests:**
    `./run_tests.sh`

    This script will:
    - Install `pytest` (if not already installed) from `requirements.txt`.
    - Execute all tests found in `tests/` and `public_tests/` directories using `pytest`.
    - `pytest` automatically discovers files named `test_*.py` or `*_test.py` and functions/methods starting with `test_`.
    - Temporary directories for tests are managed by `pytest`'s `tmp_path` fixture and `conftest.py` setup, ensuring isolation and cleanup.
