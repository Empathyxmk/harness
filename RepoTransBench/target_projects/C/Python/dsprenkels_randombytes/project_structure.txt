# Setup Instructions:
# 1. Ensure Python 3.x is installed.
# 2. Navigate to the project_root directory.
# 3. Install dependencies: `pip install -r requirements.txt`

# How to Run Tests:
# Execute the provided script: `./run_tests.sh`
# This script uses `pytest` to automatically discover and run all tests
# in both `tests/original/` and `public_tests/` directories.
