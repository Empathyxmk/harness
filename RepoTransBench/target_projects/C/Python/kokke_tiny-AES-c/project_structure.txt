│       ├── __init__.py       # Test package init

│   ├── __init__.py           # Public tests package init
│   ├── test_public.py        # Python translation of test_public.c
│   └── test_edge_cases_public.py # Python translation of test_edge_cases_public.c
└── project_structure.txt     # This file: structure and directory explanations

Explanations:
- src/tinyaes/: Implements the Python test harness for AES with CBC/CTR/ECB, using pycryptodome so test code can focus on inputs/outputs.
- tests/original/: Original test logic (from test.c and test_edge_cases.c) in Python/pytest.
- public_tests/: Official public/edge-case tests for public API behavior.
- requirements.txt: All required Python packages.
- run_tests.sh: Run all tests (public + original) with a single command.
