Directory Explanations:
- requirements.txt: Lists Python dependencies, including pytest (run: pip install -r requirements.txt)
- run_tests.sh: Simple one-click script; runs all tests using pytest
- tests/original/: Translations of the C tests for "examples/*.c"
- public_tests/: Translations of public "tests_public" C tests
- __init__.py: Ensures each test directory is a Python package

Test Execution:
1. Install dependencies: pip install -r requirements.txt
2. Run all tests: ./run_tests.sh
