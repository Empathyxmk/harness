Directory explanations:
- requirements.txt: List of Python dependencies (uses pytest)
- run_tests.sh: Executable bash script to run all tests with pytest in one click
- README.md: Setup and testing instructions
- tests/original/: Translated original internal logic tests from C
- public_tests/: Translated public/benchmark edge-case and pattern tests from C

Instructions:
1. `python3 -m venv venv && source venv/bin/activate`
2. `pip install -r requirements.txt`
3. `./run_tests.sh`
