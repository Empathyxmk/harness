Instructions:
1. Build & test: run `./run_tests.sh` from project root. It will run all original & public tests.
2. All tests are JUnit 5, auto-discovered by Maven.
3. Source code is stubbed/minimal to allow all tests to pass/mimic the original Python test logic.
4. Tests from Python 'public_tests/' are in `src/test/java/com/example/public_tests/`
5. Tests from Python 'tests/' are in `src/test/java/com/example/original/`

Notes:
- You may need to create an empty `setup.py` and `graphios.py` in the project root for "file existence" tests (or symlink/copy from original repo).
