- All public Python tests in src/test/java/com/example/tex2nix/publictests/

- Run all tests: ./run_tests.sh (executes mvn clean test)
- Standard Maven/Java project layout for easy IDE/import

Setup:
  1. Ensure you have Java 11+ and Maven installed.
  2. To run all tests, simply:
        ./run_tests.sh
     All public and original tests will be executed (JUnit 5).
  3. Coding logic inside Tex2nix.java mimics enough of the Python code to let tests pass.
  4. For further development, implement real LaTeX/Nix parsing in Tex2nix.java.
