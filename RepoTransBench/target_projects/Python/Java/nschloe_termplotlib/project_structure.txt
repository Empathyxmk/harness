Instructions:
-------------
- **Build & Test:** Just run `./run_tests.sh` in the root directory to compile and execute ALL tests (original & public).
- **Dependencies:** Managed by Maven via pom.xml (`mvn clean test` will work as well)
- **Adding/Organizing Tests:**
  - Original tests are under `src/test/java/com/example/original/`
  - Public tests are under `src/test/java/com/example/publictest/`
- **Stubs:** Source under `src/main/java/com/example/termplotlib/` only provides empty methods/classes as placeholders
  (critical for tests to compile).

Notes:
------
- Output and display code is NOT implemented - the `termplotlib` methods/classes here are stubs only for testing translation logic.
- To provide a working version, real plotting logic must be implemented in the main package.
