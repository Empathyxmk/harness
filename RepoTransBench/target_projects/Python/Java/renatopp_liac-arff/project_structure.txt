Explanations:

- pom.xml: Maven project file, sets Java/JUnit versions and dependencies.
- run_tests.sh: Just executes 'mvn clean test' to build and run all tests.
- src/main/java/com/example/arff/: Place for all ARFF-related Java sources.
- src/test/java/com/example/arff/original/: Java translation of 'tests/' (original) Python tests.
- src/test/java/com/example/arff/public_tests/: Java translation of 'public_tests/' Python public tests.
- README.md: Instructions, setup, and contributing guide.
- Test naming: Follows Java conventions: e.g. 'TestLoads.java', 'TestPublicLoads.java'.
- All test logic is fully translated and implemented. No placeholders.

How to run all tests:
  $ ./run_tests.sh

Tests are automatically discovered by Maven/Surefire by filename pattern (*Test.java).
