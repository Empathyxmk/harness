- pom.xml: Maven build configuration with JUnit 5.
- run_tests.sh: One-click test execution script.
- src/test/java/com/example/original/: All original test cases from the Python source.
- src/test/java/com/example/public_tests/: All translated public test cases.
- project_structure.txt: This project tree description/instructions.

To run all tests:  
  1. Install Maven (`apt-get install maven` or compatible method)
  2. Run: `chmod +x run_tests.sh && ./run_tests.sh`
All tests will be executed using Maven and JUnit 5.
