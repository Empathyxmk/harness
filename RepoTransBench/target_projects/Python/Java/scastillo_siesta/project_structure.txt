Directory explanations:
- src/main/java/.../siesta/        — Core Java implementation (API, Resource, auth methods, etc.)
- src/test/java/.../siesta/original/      — Translated original Python tests (full coverage tests)
- src/test/java/.../siesta/public_tests/  — Translated public Python tests (public test set)
- run_tests.sh                      — Single script to run all tests (mvn clean test)
- pom.xml                           — Standard Java/Maven dependency + test config
- project_structure.txt             — This explanation file.

How to setup and run:
  $ chmod +x run_tests.sh
  $ ./run_tests.sh
  # (Runs all tests in both original and public test packages)
