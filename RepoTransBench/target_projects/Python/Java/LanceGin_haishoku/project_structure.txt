Directory/Files Explanation:
- pom.xml                : Maven build file, includes JUnit 5 test dependency
- run_tests.sh           : Unix shell script for running all Java tests via Maven
- src/main/java/         : Place source implementation here (alg/, haillow/, haishoku/, etc.)
- src/test/java/com/example/original/      : Java translations of original Python tests (from tests/ directory)
- src/test/java/com/example/public_tests/  : Java translations of public Python tests (from public_tests/ directory)
- demo/                  : Contains demo.py and demo_01.png for tests referencing them
- LICENSE, README.md     : Standard documentation and legal files

To run all tests:
  $ chmod +x run_tests.sh
  $ ./run_tests.sh

This builds & tests using Maven and JUnit5. All test code is fully ported from the original and public Python tests.
