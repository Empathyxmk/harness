Build and Run Instructions:
--------------------------
1. Ensure you have Java (>=11) and Maven (>=3.6) installed.
2. Place the `setup.py` file in the project root (as these tests check for its presence and content).
3. Run all tests with one command: 
       ./run_tests.sh
   - This will invoke `mvn clean test` to discover and run ALL JUnit tests (original & public).
   - Test output will be printed to the terminal as per Maven/JUnit convention.

Test Organization:
------------------
- `original/`       : Contains tests faithfully translating the original Python logic for private/internal validation.
- `public_tests/`   : Contains tests in the public test battery, possibly with slight shifts in logic/fields (see original vs public Python).
- Each Java `*Test.java` class matches a Python test file in intent, coverage and naming, using JUnit 5.
- Both sets use file IO and content assertions to simulate Python's dynamic import and metadata checks.
