Directory Explanations:
-----------------------
src/main/java/com/example/shortuuid/         - (Optional) Place your ShortUUID Java library files here.
src/test/java/com/example/shortuuid/original - All tests ported directly from the original Python implementation.
src/test/java/com/example/shortuuid/public_tests - Public tests, equivalent to `public_tests/` in Python source.
pom.xml                                      - Maven build definition, dependencies, test config.
run_tests.sh                                 - Script to run all tests with a single command.
README.md                                    - Project and build/test instructions.
project_structure.txt                        - This project structure/readme file.

How to Run Tests:
-----------------
1. Make sure you have Java 11+ and Maven installed.
2. Run:
    ./run_tests.sh

This will build the project and run all tests.

If you want to run only a subset (e.g., just public or original tests), use Maven test filter:
    # Run only original tests
    mvn test -Dtest="com.example.shortuuid.original.*Test"

    # Run only public tests
    mvn test -Dtest="com.example.shortuuid.public_tests.*Test"
