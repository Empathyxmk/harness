    Main Java source files (implement Parser, QueryType, etc).

- src/test/java/com/example/sqlmetadata/original/:
    All original (full coverage) tests, organized by file, named *Test.java.

- src/test/java/com/example/sqlmetadata/public/:
    Public test cases only, mimicking public_tests contents in Java.

- public_tests/test.sql:
    Raw SQL file for complex alias test. Used by several tests for realistic SQL bodies.

    Maven project file. Handles dependencies for JUnit 5 and Mockito.

- run_tests.sh:
