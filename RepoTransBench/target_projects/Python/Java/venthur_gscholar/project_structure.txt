Instructions:
- Place your project root at the level of pom.xml and run_tests.sh.
- To run all tests: `./run_tests.sh`
- Project uses JUnit 5 and Mockito for test mocking (pom.xml covers all dependencies).
- "original" tests are in `src/test/java/com/venthur/gscholar/original/`.
- "public" tests are in `src/test/java/com/venthur/gscholar/public_tests/`.
- All core production logic stubs are in `src/main/java/com/venthur/gscholar/`. Tests should use Mockito to mock results as per original Python test monkeypatch logic.
- No source implementation required; all logic is inside test files using mocks.
