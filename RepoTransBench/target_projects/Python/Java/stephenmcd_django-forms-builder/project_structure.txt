- pom.xml: Maven build configuration including JUnit and Mockito for all test execution.
- run_tests.sh: Single-command execution, runs all tests (chmod +x).
- src/main/java/com/stephenmcd/formsbuilder: Main Java source, mimicking only the logic minimally needed for tests.
- src/main/java/com/stephenmcd/formsbuilder/fields: Contains logic/utility classes to allow tests to function and match test coverage (Fields, BooleanField, SelectField, Tuple).
- src/main/java/com/stephenmcd/formsbuilder/utils: Utility logic as needed for translation.
- src/test/java/com/stephenmcd/formsbuilder/original: All converted original test files (one class per test file).
- src/test/java/com/stephenmcd/formsbuilder/publictests: All public test files (converted from public Python tests).
- project_structure.txt: This file.
