Key:
- All *Test.java files under original/ or publictests/ are complete JUnit 5 test classes translated from Python.
- Source code (core classes you want to test) should be implemented under src/main/java/com/peritus/bumpversion/
- Tests will be automatically discovered/run by Maven.

To run all tests:
$ ./run_tests.sh

To run only public or only original tests:
- By default, all are run. For subsets, use Maven includes/excludes or add CLI options as needed.
