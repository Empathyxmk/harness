Explanations:
- pom.xml: Maven build/configuration file, declares project and dependencies
- run_tests.sh: Executes all tests using `mvn test`
- src/main/java: Place to implement any ported or stubbed libraries needed for tests
- src/test/java/com/example/plop/original: All original (private) translated tests
- src/test/java/com/example/plop/public_tests: All public translated tests
- All test files follow JUnit5 and Java conventions

Running tests:
$ chmod +x run_tests.sh
$ ./run_tests.sh
