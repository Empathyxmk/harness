├── project_structure.txt       # This file, explains the structure and usage

│   │   └── java/
│   │       └── com/

│   │                   ├── Canvas.java         # Main Canvas logic
│   │                   ├── Turtle.java         # Turtle (turtle-graphics-like pen abstraction)

│   │                   └── ExtraUtil.java      # Utility functions (normalize, getTerminalSize, etc.)
│   └── test/
│       └── java/
│           └── com/
│               └── asciimoo/
│                   └── drawille/
│                       ├── original/

│                       │   ├── LineTest.java      # Line algorithms

│                           └── PublicSpeedTest.java         # Translation of public_tests/test_public_speed_test.py

Instructions:

- Source files are in src/main/java/com/asciimoo/drawille/
- All original test cases are under src/test/java/com/asciimoo/drawille/original/
- All public test cases are under src/test/java/com/asciimoo/drawille/public_tests/
- Build/run all tests: Execute ./run_tests.sh (uses Maven/JUnit 5)
- To run just one type of tests, use e.g.
      mvn test -Dtest="**/original/*Test"
      mvn test -Dtest="**/public_tests/*Test"

Notes:

- Tests are organized by source/original and public following Python structure.
- Canvas.java, Turtle.java, LineUtil.java, ExtraUtil.java are stubs/ports sufficient for the tests to pass and mimic the Python function signatures and behavior.
- All edge and error cases in the original and public Python tests are present.
