# Directory explanations
- src/main/java/com/example/serpy/      : Core minimal serpy-like Java framework with serializer, fields, and helper Obj
- src/main/java/com/example/serpy/fields: Java implementations of StrField, IntField, etc.
- src/test/java/com/example/original/   : Translations of original Python tests (strict logic/unit tests)
- src/test/java/com/example/public_tests/: Java translations of public test cases
- run_tests.sh                         : One-click CI test runner (uses Maven/JUnit 5)
- pom.xml                              : Project and test dependencies, handles builds and test running

# Setup and testing instructions:
1. Install Maven (https://maven.apache.org/download.cgi)
2. Run: chmod +x run_tests.sh
3. Run: ./run_tests.sh

All tests (original + public) will run and output results.
