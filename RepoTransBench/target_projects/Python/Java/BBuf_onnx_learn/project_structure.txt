Directory/Package Purposes:
- pom.xml: Maven build configuration (dependencies, plugins)
- run_tests.sh: Shell script for running all Java tests via Maven
- src/main/java: Project source code
  - com.example.tools.tool: Math functions and Tool class
  - com.example.onnxapi: Identity and sum utilities
  - com.example.convert2onnx: Dummy resize functionality
- src/test/java: Test code, organized by:
  - com.example.original: Original functional tests (one class per source test file)
  - com.example.public_tests: Public ("release") test cases

Instructions:
1. Ensure JDK and Maven are installed.
2. Make sure run_tests.sh is executable (`chmod +x run_tests.sh`)
3. Run `./run_tests.sh` to build and run all tests.
4. All test cases (original and public) will be executed and results displayed.
