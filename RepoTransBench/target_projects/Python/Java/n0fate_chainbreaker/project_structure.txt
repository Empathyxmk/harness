# Directory explanations:
# - src/main/java/...: (Application code)
# - src/test/java/com/n0fate/chainbreaker/original/: Private/dev test logic (from tests/)
# - src/test/java/com/n0fate/chainbreaker/publictests/: Public test logic (from public_tests/)
# - pom.xml:           Maven dependencies and test setup (JUnit 5, etc.)
# - run_tests.sh:      ./run_tests.sh runs all tests (original + public)
# 
# Setup/Run:
#   $ chmod +x run_tests.sh
#   $ ./run_tests.sh
# 
# All tests under both test/original/ and test/publictests/ will be executed.
