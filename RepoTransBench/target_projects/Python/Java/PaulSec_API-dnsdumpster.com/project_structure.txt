Key Points:
- All code under the package com.example.dnsdumpster.
- Original tests live in src/test/java/com/example/dnsdumpster/original/
- Public tests live in src/test/java/com/example/dnsdumpster/publictests/
- Main class stub/skeleton in src/main/java/com/example/dnsdumpster/DNSDumpsterAPI.java is a minimum stub to satisfy imports and mocks in tests.
- All test logic is self-mocking; tests do not hit any real service.
- Run all tests using the provided run_tests.sh script, which simply calls 'mvn clean test'.
- Dependencies: JUnit 5 for testing, Mockito for mocking.
