Directory explanations:

- pom.xml: Declares dependencies for JUnit, Hamcrest, Mockito, and configure/test Java source compatibility.
- run_tests.sh: Executable shell script; simply runs `mvn clean test`, building and running all tests.
- src/main/java/com/zaproxy/zapv2/: (Placeholder) Package for Java implementation of zapv2 API and client classes.
- src/test/java/com/zaproxy/zaproxy/original/: Contains all translated original test files from tests/unit in Python.
- src/test/java/com/zaproxy/zaproxy/public_tests/: Contains publicly generated test files from public_tests in Python.
- Each test file is a full translation with identical test coverage and assertion logic from Python.
- README.md: (to be filled by user) Typical project usage/instructions.

Test Execution/Setup:

1. Ensure Java (11+) and Maven are installed.
2. Run tests via: `./run_tests.sh`
3. All original and public tests will execute, summary will be shown in terminal.
