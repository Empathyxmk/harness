# Directory explanations:
# - src/main/java/com/example/: Main code packages split into jsonrpc/, serialize/, txweb/
# - src/test/java/com/example/original/: Unit tests for original/internal logic mirroring Python "tests/"
# - src/test/java/com/example/public_tests/: Unit tests for public-facing API/logic (mirroring "public_tests/")
# - run_tests.sh: Executes 'mvn clean test' to run ALL tests (original+public)
# - pom.xml: Maven config with dependencies for JUnit 5, Mockito, Jackson (JSON)
#
# Testing instructions:
# 1. Ensure Java 8+ and Maven are installed.
# 2. Run 'chmod +x run_tests.sh' before first use if needed.
# 3. Run all tests: ./run_tests.sh
#    (builds code and runs all original and public unit tests)
# 4. Read project_structure.txt for how tests/map to Python originals/publics.
