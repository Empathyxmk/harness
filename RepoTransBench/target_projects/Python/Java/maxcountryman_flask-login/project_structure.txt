Directory Explanation:
- pom.xml: Maven configuration. Declares dependencies, Java/JUnit versions.
- run_tests.sh: One-click script to run all tests (`mvn clean test`).
- src/main/java/com/...: Production code structure (minimal - just test support classes here).
- src/test/java/com/.../original/: All test code translated from the original Python tests (tests/, test_client.py, etc).
- src/test/java/com/.../publictests/: All translated public test cases.
- project_structure.txt: This tree and description.

How to run tests:
1. Install Java 17+ and Maven.
2. Run `chmod +x run_tests.sh` if needed.
3. Execute `./run_tests.sh` - all original and public tests execute and report status.
