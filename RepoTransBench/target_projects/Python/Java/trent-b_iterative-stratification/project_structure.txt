- All tests in both original and public suites fully translated to Java/JUnit5, matching Python logic line by line.
- Directory names mirror Python structure: public and original are separate.
- The `src/main/java/...` is placeholder: real logic goes there for true integration; testing targets the APIs as expected.
- `run_tests.sh` runs all tests via `mvn clean test`.
- README describes usage; LICENSE and README.md exist so "file existence" tests pass.

To add production logic for `IterativeStratification`, implement your algorithm in `src/main/java/com/trentb/iterstrat/IterativeStratification.java` as a static method.
