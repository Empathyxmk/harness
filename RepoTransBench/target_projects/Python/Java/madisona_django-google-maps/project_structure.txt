Directory Explanations:
-----------------------
pom.xml                 - Build and dependency specification for Maven (JUnit 5 included)
run_tests.sh            - Shell script for one-command test runs (mvn clean test)
src/main/java           - Placeholder for application/main code (not needed for test-only translation)
src/test/java/com/example/original
                        - Java package for original tests, direct translation from all original Python tests
src/test/java/com/example/public_tests
                        - Java package for public tests, direct translation from Python's public_tests/
project_structure.txt   - This file, describes layout, explains mapping, setup, and how to run tests

Setup/Testing Instructions:
---------------------------
1. Ensure JDK 11+ and Maven 3.8+ are installed.
2. To run all tests, simply execute:
       ./run_tests.sh
   This will compile everything and run all translated Java tests (JUnit style).

3. Test output is available in console. All test implementations match original logic and edge/corner cases.
