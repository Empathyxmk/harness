Breakdown:
- pom.xml: Maven build config, dependencies (JUnit, dom4j for XML)
- run_tests.sh: One-click test execution
- src/main/java/org/cas/: Stubs/classes required for tests to compile/run
- src/test/java/org/cas/original/: Fully translated private/original test cases
- src/test/java/org/cas/public_tests/: Public test cases, mapped to Java and using different data

Instructions:
1. Install Java 1.8+ and Maven 3.x
2. Run all tests (original + public): ./run_tests.sh
3. View original tests under src/test/java/org/cas/original/
4. View public tests under src/test/java/org/cas/public_tests/
5. Add/replace CAS logic in src/main/java/org/cas/ if needed for production use

NOTE:
- All test logic from Python is preserved. Any logic which required network access remains @Disabled (skipped) in Java.
- CASClient, CASClientBase, etc. are partial stubs to support testing only; flesh out fully for app/library use.
