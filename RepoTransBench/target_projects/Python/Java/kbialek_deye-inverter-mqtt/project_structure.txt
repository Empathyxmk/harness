Directories:
- src/main/java/com/example/deyeinvertermqtt/ : Source Java codebase.
- src/test/java/com/example/deyeinvertermqtt/original/ : Unit tests translated from original Python 'tests/'.
- src/test/java/com/example/deyeinvertermqtt/public/ : Unit tests translated from Python 'public_tests/'.

How to run tests:
1. Install Java 11+ and Maven.
2. Run:
   ./run_tests.sh

All tests (unit + public) are discovered by Maven Surefire (JUnit). To run only original or only public tests, use:
- mvn test -Dtest="com.example.deyeinvertermqtt.original.**.*Test"
- mvn test -Dtest="com.example.deyeinvertermqtt.public.**.*Test"
