------------------------------------------------------
Directory explanations:

- pom.xml:       Maven configuration file listing dependencies (JUnit 5 for testing)
- run_tests.sh:  Execute this file to build and run *all* tests (original and public)
- src/main/java: Java package code (the 'plugin' class with metadata for tests)
- src/test/java: All test code
  - original/:    Java translations of the project's original Python tests
  - public_tests/:Java translations of the project's public test variants
- setup.py:      Must be present in project root, as tests interact with it

------------------------------------------------------
Setup and Testing Instructions:

1. Ensure Maven and Python3 are installed and 'setup.py' exists in the project root.
   - Many tests require 'setup.py' to exist; copy a minimal one if needed.

2. Build and run all tests:
   $ ./run_tests.sh

3. Test output appears in the console:
   - All original and public test cases will be executed.

4. Add your actual source logic in 'src/main/java/com/example/rdflibjsonld/RdflibJsonld.java' if needed.
