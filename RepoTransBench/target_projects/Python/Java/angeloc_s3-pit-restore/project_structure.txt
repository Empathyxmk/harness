How to build and test:
----------------------
1. Make sure Maven is installed on your system.
2. Run the following command to execute all tests:
       ./run_tests.sh

This executes ALL tests (original and public). For separation, you can use Maven's -Dtest argument, e.g.:
    mvn test -Dtest="com.angeloc.s3pitrestore.original.*Test"
or
    mvn test -Dtest="com.angeloc.s3pitrestore.publictests.*Test"

All tests are implemented and fully functional, matching original Python logic and assertions.
