Key directories/files:
----------------------
- pom.xml           : Maven dependency/build file. Includes JUnit 5, XMLUnit etc.
- run_tests.sh      : One-click test runner (chmod +x to use)
- src/main/java     : (library code - for test compilation only, may be placeholders if library not translated)
- src/test/java     : All translated Java test cases in proper package directories

Running tests:
--------------
1. Ensure you have Maven 3+ and JDK 11+ installed.
2. Run tests with: ./run_tests.sh
   This will build and run all tests and print results.

Note:
-----
- This is a Java port of the original Python test suite.
- All test names and logic are preserved.
- Library code is assumed present (may need manual code or stubs for MailMerge etc for successful test compilation/execution).
