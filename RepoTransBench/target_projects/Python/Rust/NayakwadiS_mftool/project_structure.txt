Explanations
------------

- **src/**: Contains `lib.rs`, a stub implementation. In a real project, core library logic would reside here.
- **tests/**: Contains ALL runnable integration tests as required by Rust/Cargo. This includes both original (private) and public test suites.
- **public_tests/**: Archive/record of the originally public test set. NOT run by cargo test unless copied to `tests/`.
- **Cargo.toml**: Manages dependencies, metadata, and build configuration for Rust and Cargo.
- **run_tests.sh**: A simple command to execute all tests via Cargo, so users may simply `./run_tests.sh`.
- **project_structure.txt**: This document, explaining file/directory purposes and setup.
- **README.md**: Main documentation and instructions.

Running the Tests
-----------------
Simply execute:
    ./run_tests.sh

Or run using cargo directly:
    cargo test

All private and public tests will execute and report results.
