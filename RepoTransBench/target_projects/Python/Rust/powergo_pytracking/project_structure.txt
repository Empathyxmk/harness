- tests/original/: All original Python tests, rewritten to Rust, organized as Rust integration tests.
- public_tests/:   Public test suite (per contest requirements), rewritten to Rust.
- run_tests.sh:    Runs all tests (`cargo test`) with a single command.
- Cargo.toml:      Standard Rust package manifest, lists dependencies and dev-dependencies.
- README.md:       Project overview and instructions.
- project_structure.txt: This overview file.
