## Directory explanations:

- `src/` contains the library logic and core modules for adblock parsing and rule matching.
- `tests/original/` contains the ported comprehensive tests, ensuring full parity with the original Python suite.
- `public_tests/` contains public/adapted tests for open demonstration and simple usage checking.
- `run_tests.sh` runs all tests using Rust's standard test runner.
- `Cargo.toml` configures Rust dependencies and metadata for the project.

## How to set up and test:

1. Install Rust (https://rustup.rs)
2. In the project directory, simply run: `./run_tests.sh`
3. All tests (original and public) will be executed, showing results.
