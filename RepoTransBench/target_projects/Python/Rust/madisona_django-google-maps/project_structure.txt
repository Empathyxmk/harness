Directory explanations:
- src/:         Main library root (empty for translation focus).
- tests/:       Contains translated original test suite, organized by origin.
- public_tests/:Contains public ("student visible") test translations.
- run_tests.sh: One-click script to run all tests (`cargo test --all`).

Setup and testing instructions:
1. Install Rust and Cargo (see https://doc.rust-lang.org/book/ch01-01.html).
2. Run all tests by executing:
     ./run_tests.sh
   This will automatically discover and run all tests in both tests/ and public_tests/.
