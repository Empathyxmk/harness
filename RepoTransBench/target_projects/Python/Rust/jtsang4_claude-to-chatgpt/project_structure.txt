Directory explanations:
- src/: Main project source code in Rust ("library" crate). Each .rs file is a module for main logic area.
- tests/: Original (private/internal) test suite, one per component.
- public_tests/: Public-facing tests, translated from public_tests/ in Python.
- Cargo.toml: Package manifest and dependency manager for Rust.
- run_tests.sh: Run all tests quickly (`chmod +x run_tests.sh`).
- project_structure.txt: Reference for this file and structure.

Testing instructions:
1. Install Rust (https://rustup.rs/) if not present.
2. Mark the test script as executable: `chmod +x run_tests.sh`
3. Run `./run_tests.sh`
4. All tests (including both private and public) will be run and their results shown.
5. Test logic is a 1:1 port of the Python suite (original and public) from claude-to-chatgpt.

Note: The app/modules are stubs/minimal to permit full cross-compilation of tests. Real implementation would require porting all logic.
