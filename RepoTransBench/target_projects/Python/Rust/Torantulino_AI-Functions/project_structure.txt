# Directory explanations:

src/lib.rs
    Provides the main ai_function logic, used both in production and test.
    Mocks for OpenAI/completions are injected via a stub to be overridden by tests.

tests/original/
    Contains all Rust translations of the project's "original" (i.e., internal/private) test cases.
    Uses #[test] functions and asserts equivalently to the Python originals.

public_tests/
    Contains all Rust translations of the public tests, also using #[test].

run_tests.sh
    One-click bash script; runs all tests using `cargo test`. Usage:
        chmod +x run_tests.sh
        ./run_tests.sh

Cargo.toml
    Standard Rust project manifest.
    Includes the minimal [dev-dependencies] needed for test mocking (here, lazy_static).

How to run tests:
    1. If not already, run: chmod +x run_tests.sh
    2. To run all tests (original and public): ./run_tests.sh

No manual dependency installation is required; all test dependencies are in Cargo.toml.
