--- Directory & File Explanations ---

Cargo.toml:      Rust manifest, dependencies, and test configs.
README.md:       How to build/use/run tests, etc.
src/lib.rs:      The Rust port of Flashtext (implement your algorithms here).
tests/original/: Rust test modules translated from the original Python test/ files.
tests/public/:   Rust test modules translated from the public_test suite.
run_tests.sh:    Simple helper to run all tests with a single command.

testdata/:       Holds test input/output files and JSON, used by test code.

--- How to Run ---

1. Install Rust (`rustup`, see https://rustup.rs/)
2. Run all tests with:
       ./run_tests.sh

--- How to Add More Tests ---

- Add new test modules (.rs) to tests/original/ or tests/public/
- Include them in the corresponding mod.rs
- All tests auto-discover with `cargo test`.
