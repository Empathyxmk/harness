Directory Details:
- src/lib.rs: Exposes pymsteams as main library crate
- src/pymsteams/mod.rs: Main logic, minimal business logic to support all test scenarios (structs, methods, errors)
- tests/: All original test case translations, Rust style, using cargo test
- public_tests/: All public test case translations, with the same test logic but using public sample data
- run_tests.sh: Simply runs `cargo test` (all tests in /tests and /public_tests get run)
- Cargo.toml: Declares dependencies and crate config (uses serde, thiserror for error and JSON mock logic)
- README.md: (stub)

## How to test

1. Install Rust (if not already): https://rustup.rs
2. In repo root, run:

    chmod +x run_tests.sh
    ./run_tests.sh

All internal and public tests will run with output and errors.
