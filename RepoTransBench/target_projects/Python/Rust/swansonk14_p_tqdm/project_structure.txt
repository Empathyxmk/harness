Directory explanations:
- src/lib.rs: Entry point for all library and test symbols.
- tests/original/: Contains the original/private test suite in Rust (mirroring Python's "tests").
- public_tests/: Contains the public test suite in Rust (mirroring Python's "public_tests").
- run_tests.sh: Run all tests with a single command.
- Cargo.toml: Rust build configuration.

How to run all tests:
    ./run_tests.sh

How to run only original or only public tests:
- You may filter with cargo args, e.g.
    cargo test --test test_p_tqdm    # for one original test
- But by default, ./run_tests.sh runs all.
