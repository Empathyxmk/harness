└── project_structure.txt       # This file, documents the layout and instructions

Directory Explanations:
- src/: All source code, including stubs required by test code
- tests/original/: Complete translations of all 'tests/' from Python (original tests)
- public_tests/: Translations of all 'public_tests/' from Python (public test set)
- tests/common/: Reserved for any shared helpers/utilities (currently empty)
- run_tests.sh: One-step test runner script (see below)

Setup & Testing:
1. Ensure Rust is installed (https://www.rust-lang.org/tools/install)
2. Run all tests (original and public): ./run_tests.sh

This layout follows standard Rust conventions, ensures clarity between original and public test sets, and provides a simple workflow.
