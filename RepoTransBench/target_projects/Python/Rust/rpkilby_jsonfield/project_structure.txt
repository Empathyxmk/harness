└── project_structure.txt  # This file

**Directory and File Purposes:**

- Cargo.toml: Defines dependencies (serde, serde_json, indexmap for "typed dict", etc).
- src/lib.rs: Exports all library code for tests.
- src/jsonfield.rs: Implements most required logic/mocks to exercise test cases, includes dummy form/json API for tests.
- tests/: Original/private tests from Django version (translated as Rust tests).
- public_tests/: Public/provided tests, as Rust modules.
- run_tests.sh: One-click test runner (`cargo test --all`)
- project_structure.txt: Project/structure explanation and files
