Directory explanations:
- src/                   : Main library code (empty/stub, as logic is in tests)
- tests/                 : All logic/coverage test cases (original and public variants). Run with `cargo test`.
- Cargo.toml             : Rust/cargo manifest.
- run_tests.sh           : One-click test execution for *all* tests.
- project_structure.txt  : This documentation.

Setup and test instructions:
1. Prerequisites: Rust 1.60+ (install from https://rustup.rs/)
2. Run all tests (original + public):  
       ./run_tests.sh
   Or (manually):  
       cargo test
3. See `tests/` for complete coverage translation of Python test scenarios.
