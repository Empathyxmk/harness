# Directory Explanations:

src/
    lib.rs      - Main library with Rust analogs for core components (stubs, for test wiring)
    main.rs     - Binary entrypoint; not used by tests

tests/original/
    test_core_basic.rs, test_pfmq.rs, ... - Integration tests translated from original Python tests

public_tests/
    test_public_*.rs - Public test translations

Cargo.toml
    - Describes project, dependencies, and test/development dependencies

run_tests.sh
    - One-click script for running ALL tests via Cargo (unit, integration, public).
      Usage: ./run_tests.sh

# Setup and Testing Instructions
1. Ensure Rust and Cargo are installed (`rustup` recommended)
2. From project root, run:
    chmod +x run_tests.sh
    ./run_tests.sh
3. All tests in tests/original/ and public_tests/ will execute.
4. Test success/failure will be reported on CLI output.

# NOTE:
- Helpful/documented _stubs_ for Graph, Operation, util, etc. exist in src/lib.rs for compilation;
  these must be replaced with real implementations for full logic validation.
- All test logic, structure, and cases as in Python source are preserved, but some
  (esp. involving "pfmq" or graph algebra) are structure-only unless source code is ported.
