# Directory explanations:
# src/                -- Main Rust library source code (lib.rs, modules, etc.)
# tests/original/     -- All tests translated from the original Python (original, non-public) tests
# public_tests/       -- Public test cases corresponding to the Python public_tests/ (separated as a Rust test module)
# run_tests.sh        -- Run all tests (simply calls “cargo test” for all test modules)
# Cargo.toml          -- Rust package configuration (dependencies, build settings)
# README.md           -- Project-level documentation (setup instructions, usage)
# project_structure.txt -- This file (explains all directories and roles)

# Setup and Running:
#   1. Run: chmod +x run_tests.sh (if not already executable)
#   2. Run all tests: ./run_tests.sh
#   3. To run a specific file, use: cargo test --test file_name
#   4. To run a specific test function, use: cargo test test_function_name

# Note: All test logic is translated from the google_latexify_py Python repository and preserves test coverage and function.
