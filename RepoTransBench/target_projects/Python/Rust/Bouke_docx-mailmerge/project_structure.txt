**Setup and Testing Instructions**
1. Install Rust: https://rustup.rs/
2. In the repo root, run `./run_tests.sh` to compile and run ALL tests.
3. All Rust integration tests are under `tests/original/`, auto-discovered by Cargo.
4. Add your implementation code in `src/lib.rs`.

**Directories**
- src/: Rust library code (actual mailmerge logic should be here for full port)
- tests/original/: Complete and faithful Rust translations of original Python unittests
- public_tests/: For public/minimal tests if/when needed
- run_tests.sh: Run all tests (uses `cargo test`)
- Cargo.toml: Project manifest and dependencies
- project_structure.txt: This project tree and explanatory guide
