### Explanations:

- **src/**: Rust "library" code, mirrors the Python API for testing.
- **tests/original/**: Each file is a faithful translation of its respective original Python file.
- **public_tests/**: Each file is a faithful translation of its respective public Python file.
- **run_tests.sh**: Simple bash script. Run all tests via cargo (`cargo test --all -- --nocapture`).
- **Cargo.toml**: Declares package and dependencies.
- **README.md**: Documentation and instructions.
- **project_structure.txt**: This reference/document.

### Running the tests

From the project root, run:

    ./run_tests.sh

All original and public tests will execute. All error and edge cases are covered.
