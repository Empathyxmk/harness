Directory/Files explanation:
- Cargo.toml: Rust dependency and metadata management.
- src/lib.rs: Main library file, required by Rust for tests to build; contains business logic in real migration.
- tests/original/: All original/hidden test cases ported from Python.
- public_tests/: All public test cases ported from Python.
- run_tests.sh: One-click script to execute ALL public and original tests using cargo test.
- project_structure.txt: This documentation and project organization summary.

To run ALL tests (original and public):
    $ ./run_tests.sh

All test logic from the original Python suite is ported to Rust. No logic is omitted.
