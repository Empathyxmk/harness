# Directory explanations:
# - src/                : Rust library source code (stubbed for test logic)
# - tests/original/     : Rust files containing tests translated from "original" Python tests
# - public_tests/       : Rust files containing tests translated from "public" Python tests
# - run_tests.sh        : Simple script to run all tests using cargo test
#
# Setup and testing instructions:
# 1. Install Rust (see https://www.rust-lang.org/tools/install)
# 2. Run tests:        ./run_tests.sh
#    (or directly:     cargo test)
# 3. Place real logic in src/redbeat/* to replace stubs as needed.
