Setup & Testing Instructions:
-------------------------------
1. Install Rust toolchain (https://rustup.rs) if not already installed.
2. Run all tests with:
   $ ./run_tests.sh

- All project logic is in src/lib.rs.
- All test files are implemented using Rust's #[test] framework.
- Original tests are in tests/original.
- Public tests are in public_tests.
- Add additional modules or tests as needed in this Rust structure.
