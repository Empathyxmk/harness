---
Directory Explanations:
- src/: Main source files for the Rust library (only stubs/mocks for test dependencies here).
- tests/original/: Rust translations of all original (private) Python test cases, preserving their logic.
- public_tests/: Rust translations of all public test cases, organized by `integration`/`unit`.
- run_tests.sh: Run `chmod +x run_tests.sh` and then `./run_tests.sh` to execute all tests.
- Cargo.toml: Cargo/Rust dependency configuration and package meta.
- project_structure.txt: This file, for documentation and navigation.

---
Test and Build Instructions:
1. Ensure you have Rust (and Cargo) installed.
2. Make sure `run_tests.sh` is executable: `chmod +x run_tests.sh`
3. Run all tests: `./run_tests.sh`
   - This will compile the project and run all tests (including both original and public).
   - Everything uses the built-in Rust test framework; no further dependencies needed beyond what's in Cargo.toml.
