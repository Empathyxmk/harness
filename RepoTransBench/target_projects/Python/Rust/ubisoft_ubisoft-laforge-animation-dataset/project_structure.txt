# Directory explanations:

src/: Source code modules implementing library functionality.

tests/original/: Original test suite, fully translated from Python. Each test file directly maps to and covers the same logic as its Python counterpart.

public_tests/: Public test suite translated from public Python tests, provides additional verification and re-use logic but with only public/whitebox coverage.

Cargo.toml: Rust package manifest — lists dependencies and library metadata.

run_tests.sh: One-click script to run all tests in both test locations (original + public).

project_structure.txt: Documents this structure.

# Setup and Test Instructions:
1. Install Rust and Cargo (https://rustup.rs/)
2. From the repo root, run:
   $ chmod +x run_tests.sh
   $ ./run_tests.sh
3. This executes all tests (original and public) via cargo test.
4. Add your own modules/functions into src/, and re-use tests as templates for new ones.
