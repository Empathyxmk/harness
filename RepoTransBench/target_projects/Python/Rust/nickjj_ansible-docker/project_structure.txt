Directory Explanations:
- src/: All application/library Rust code.
- tests/original/: Translations of all private/original Python tests.
- public_tests/: Translations of public test suite.
- run_tests.sh: Simple test runner, runs *all* tests and exits on failure.
- project_structure.txt: This file.

Setup/Testing Instructions:
1. Install Rust toolchain (`rustc`, `cargo`) if not already present.
2. Make the test script executable: `chmod +x run_tests.sh`
3. Run all tests with: `./run_tests.sh`
   - This runs *both* original and public tests.

Notes:
- No explicit test discovery config is needed; all `tests/` and `public_tests/` test files are found by Cargo.
- Source code and test code are fully Rust-native.
