# Directory Explanations

src/:
    - Core Rust crate logic, translated from original Python source (foobar.py, sushi.py, etc.)

tests/original/:
    - Full translation of original Python test suites to Rust

public_tests/:
    - Translation of public Python test suites to Rust, same structure as provided

run_tests.sh:
    - Executable script to run *all* tests with standard Rust command

Setup and Testing Instructions:
1. Install Rust (https://www.rust-lang.org/tools/install)
2. cd into the repo root
3. Run all tests: ./run_tests.sh
