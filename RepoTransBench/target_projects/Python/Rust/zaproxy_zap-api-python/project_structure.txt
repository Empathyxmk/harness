Directory explanations:
- src/                : Contains all rust library code and API adapter modules (test harness mocks).
- tests/original/     : Translated, functionally equivalent unit tests for original Python suite.
- tests/public/       : Fully functional translations of public_tests from Python in Rust.
- run_tests.sh        : One-step shell script to run *all* tests using cargo.
- Cargo.toml          : Rust/cargo build and dependency configuration.
- README.md           : Add user/developer notes and usage as desired.

How to run all tests:
- Grant execution permission if needed: `chmod +x run_tests.sh`
- Run: `./run_tests.sh`
or
- Directly: `cargo test`

All tests (original and public) will be run automatically and must pass.
