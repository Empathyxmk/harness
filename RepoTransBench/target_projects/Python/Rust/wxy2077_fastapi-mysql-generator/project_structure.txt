Directory explanations:
- src/: Rust crate source. Empty unless business logic ported. main.rs is a stub.
- tests/original/: Rust modules for original (private) test cases, one file per conceptual area.
- public_tests/: Rust modules for public test cases, mirroring the Python public_tests folder.
- run_tests.sh: One-click script to run all tests using Rust's built-in framework.
- Cargo.toml: All Rust and test dependencies. Add more as needed if business logic expands.

Setup and Testing instructions:
1. Install Rust and Cargo (https://rustup.rs/)
2. Run tests with: ./run_tests.sh
3. To run only specific test(s): cargo test test_name
4. To run all original or all public: cargo test --test test_file_name (files are auto discovered)
5. Source and tests are decoupled for clarity; replace mock logic with real API/server code as needed.

This repo is a faithful Rust translation of the Python FastAPI-mysql-generator test set;
all test logic/data/coverage follows the original, but with idiomatic Rust, mocks and test frameworks.
