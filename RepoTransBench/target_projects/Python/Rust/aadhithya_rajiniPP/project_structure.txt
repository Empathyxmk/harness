Directory Explanations:
- src/: Core library code (stubbed out). In a real port, replace with actual implementation.
- tests/original/: Full port of the original Python test files. Logic mirrors the behavior of the Python code.
- public_tests/: Translations of public test cases as in the original project.
- run_tests.sh: Simple script to execute all Rust tests.
- Cargo.toml: Declares the Rust crate, manages dependencies.

Instructions:
1. Install Rust and Cargo (https://www.rust-lang.org/tools/install)
2. Run tests:  `chmod +x ./run_tests.sh && ./run_tests.sh`
All unit and integration tests (original + public) should execute.
