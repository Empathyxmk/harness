├── project_structure.txt # This file: documentation of the project structure
└── README.md           # Project documentation

This structure follows Rust conventions:
- Source code is in src/.
- Tests are in tests/, subdivided into original and public_tests to mirror the Python structure.
- run_tests.sh allows one-click test execution using 'cargo test'.
- All tests are fully implemented with identical logic from the source Python tests.
