Directory explanation:
- src/                : Rust source code; stubbed so tests compile.
- tests/original/     : All original Python tests, ported to Rust.
- public_tests/       : All public Python tests, ported to Rust.
- run_tests.sh        : Run all tests with a single command.
- Cargo.toml          : Build & dependency config for Rust/cargo.
- project_structure.txt: (this file) Project structure description.

Setup and usage:
1. Ensure Rust and Cargo are installed.
2. Run `chmod +x run_tests.sh`.
3. Run all tests (original + public) with: `./run_tests.sh`
   - This runs all tests under tests/original/ and public_tests/.
   - Output will list all test pass/fail.
