- `src/underscore.rs`  
  Contains the Rust port of the core underscore-like functions. 

- `tests/original/`  
  Contains all full coverage, original test cases ported from Python.

- `public_tests/`  
  Contains public, smaller version of tests ported from public example Python test suite.

- `run_tests.sh`  
  One-liner to compile and run the tests.

- `Cargo.toml`  
  Cargo setup with dependencies.

To run all tests, just:  
    ./run_tests.sh
