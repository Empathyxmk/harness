## Directory Purpose

- src/           : Crate/library implementation (left as placeholder for now)
- tests/original/: All original/internal test cases, fully translated from Python
    - handlers/: Handler-specific logic tests
    - middleware/: Middleware/context integration tests
- public_tests/  : Public-facing test cases, fully translated from Python's public_tests/
- run_tests.sh   : One-click script to execute the entire test suite (`cargo test`)
- Cargo.toml     : Rust project/build/dependency settings
- project_structure.txt: Explanation of all directories and major files

## Running Tests

1. Ensure [Rust](https://www.rust-lang.org/tools/install) is installed.
2. From the project root, run:
       ./run_tests.sh

This will run all tests in both tests/original and public_tests (via cargo).

## Notes

- Internal (original) and public tests are logically separated.
- All Pythonic pytest/skipped or dummy/placeholder assertions are faithfully represented in Rust.
- No test left as a placeholder; logic and intent are translated or simulated idiomatically.
- See README.md for additional usage and contribution guidance.
