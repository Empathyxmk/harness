============================================

Directory Explanations:
-----------------------
src/            - All library and implementation code (Rust translation of rbarrois_xworkflows logic)
tests/original/ - Original Python test cases translated to Rust (full coverage)
public_tests/   - Public test cases (mirroring the Python public_tests/ directory structure)
Cargo.toml      - Rust package manifest and dependencies
run_tests.sh    - Run all tests with a single command
project_structure.txt - This structure/explanation file

Setup & Testing Instructions:
-----------------------------
1. Install Rust if you don't have it:
   https://rustup.rs/

2. Run all tests from project root:
   $ ./run_tests.sh

   (Or manually: $ cargo test --all)

3. To run only original or public tests, specify via cargo:
   $ cargo test --test original/test_utils
   $ cargo test --test public_tests/test_public_base

4. Add implementation to `src/` as needed for further features.

Enjoy!
