**Explanation**:
- `src/`: Rust source files organizing all main code modules for ai_models. Each logical area from Python is represented as a module.
- `tests/original/`: All original test logic translated from `tests/` in Python (unit tests, edge cases, internal).
- `public_tests/`: Public test cases, generally lighter, confirming basic logic or public API, not requiring deep internals.
- `Cargo.toml`: Rust build and dependency manager (equivalent to pyproject.toml).
- `run_tests.sh`: Simple script which runs *all* Rust tests via `cargo test`.
- `project_structure.txt`: Documents organization, aids navigation and new user onboarding.

**Test Organization**:
- Both original and public test cases are included and clearly separated.
- All test logic is implemented with assertions and full logic—no placeholders or missing logic.
- You can run all tests using `./run_tests.sh`, which will execute both original and public-facing tests via Rust's test harness.
