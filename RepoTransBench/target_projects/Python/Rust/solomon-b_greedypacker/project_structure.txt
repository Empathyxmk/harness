Directory Explanations:
- Cargo.toml: Rust project configuration and dependency declarations.
- src/: All source files for the greedypacker ported library.
- tests/original/: Translated "original" Python tests as Rust integration tests.
- public_tests/: Public API and basic functional tests, also translated to Rust, can be run with `cargo test`.
- run_tests.sh: Bash script for easy one-click Rust test execution (runs `cargo test`).
- project_structure.txt: Structure overview and instructions.

Setup and Testing:
1. Install Rust (https://rustup.rs/)
2. Run: `./run_tests.sh` to execute ALL tests (original and public_api).
3. Add the actual implementation code for greedypacker in `src/` modules as you port it.
