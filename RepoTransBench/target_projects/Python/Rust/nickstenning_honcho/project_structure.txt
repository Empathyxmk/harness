# Directory and File Explanations

- `src/`: Rust source code. `lib.rs` is the crate root. Main modules ported from honcho.
- `src/export/`: Submodule for export formats (systemd, upstart, supervisord, runit, base).
- `tests/`: All original (internal) unit/integration tests.
- `tests/integration/`: Integration-style tests ported from Python's.
- `public_tests/`: "Public" black-box-style tests, matching the public tests set.
- `Cargo.toml`: Rust project/package metadata with dependencies.
- `run_tests.sh`: Executable test script (`chmod +x run_tests.sh`).
- `.gitignore`: Version control ignore rules.
- `README.md`: Documentation and how-to-run info.
