Directory explanations:
- src/: Rust library code, intentionally written for testing, providing a minimal dummy version so tests compile.
- tests/: ALL original (hidden) tests from the Python codebase, translated and using the library.
- public_tests/: ALL public tests, for public validation, also using the library.
- Cargo.toml: Rust package manifest with dependencies used (ndarray, lazy_static, etc.).
- run_tests.sh: Simple runner; just runs `cargo test --all` to execute everything.
- README.md: Brief overview and usage.
