# Directory/Files Purpose:
# - src/: All (minimal mock/stub) implementation modules (lib.rs, util.rs, etc).
# - tests/original/: All test cases ported from original Python tests.
# - tests/public/: All public test cases copied for Cargo test discovery.
# - public_tests/: Reference location for public tests, not executed by Cargo (only .rs files matter).
# - Cargo.toml: Declares dependencies and crate metadata.
# - run_tests.sh: Run all the tests via cargo test.
# - project_structure.txt: This documentation.

SETUP & RUNNING:
1. Install Rust (https://rustup.rs/)
2. In the project directory, run: chmod +x run_tests.sh
3. Run all tests: ./run_tests.sh
4. Both original and public test cases will be executed (Cargo runs all .rs in tests/original/ and tests/public/).
