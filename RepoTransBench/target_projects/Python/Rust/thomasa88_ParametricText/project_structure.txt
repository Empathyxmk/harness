Directory explanations:
- src/:      Rust source code, library modules for paramparser/paramformatter.
- tests/original/: Rust unit tests directly ported from original test suite.
- public_tests/:  Rust unit tests ported from public test suite, (as integration tests).
- Cargo.toml:  Project manifest, configure dependencies and version.
- run_tests.sh:  Run all tests (original and public) with one command: ./run_tests.sh
- project_structure.txt:  This document. Outlines layout and purpose.

Test/integration running:
    ./run_tests.sh
No additional dependencies are required; default Rust testing via cargo is used.

Original tests are in `tests/original/`.  
Public ("open" or summary) tests are in `public_tests/`.
