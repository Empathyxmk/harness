# Directory explanations:
#  - include/:          All project headers.
#  - src/:              Project C++ source files.
#  - tests/original/:   Original (private) test cases, directly translated from Python.
#  - public_tests/:     Public test files (translated from Python).
#  - run_tests.sh:      Script to configure, build, and run both test suites.
#  - project_structure.txt: This file.

# Setup and Testing Instructions:
# 1. Install GoogleTest and CMake (standard packages).
# 2. Run: `chmod +x run_tests.sh`
# 3. Run: `./run_tests.sh`
