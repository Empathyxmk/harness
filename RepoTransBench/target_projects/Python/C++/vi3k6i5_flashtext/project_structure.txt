Explanations:
-----------
- include/: C++ header files; main library header here.
- src/: The main source implementation of KeywordProcessor in C++ (to be implemented/filled).
- tests/original/: Original in-depth test coverage, translated from Python using GoogleTest.
- public_tests/: Translated public tests (sample/coverage-style).
- tests/keyword_extractor_test_cases.json, tests/keyword_remover_test_cases.json, tests/keywords_format_one.txt, tests/keywords_format_two.txt: Input data required for parametric tests (tests should parse these identically to the Python originals).
- run_tests.sh: Builds everything with CMake, runs all tests (both original and public).
- CMakeLists.txt: Sets up the build for everything, includes GoogleTest & configures all test suites.
- test_main.cpp/test_main_public.cpp: Entrypoints for running tests in each group.
Instructions:
1. Install dependencies (see README or run_tests.sh will auto-provision with CMake).
2. To build & test, run: `./run_tests.sh`
Notes:
- The main C++ implementation (KeywordProcessor class, etc.) must provide all methods as expected by the test cases. The test logic and datasets match the original Python repo.
