# Directory explanations:
# - src/          : All C++ source implementations
# - include/      : For headers (not strictly needed, but recommended for larger codebases)
# - tests/        : Original tests from the Python suite, ported to C++ (uses GoogleTest)
# - public_tests/ : Public tests as per the reference Python suite, ported C++
# - CMakeLists.txt: Build config; links all tests, builds test_runner from src + test files
# - run_tests.sh  : One command to build and run all tests
# - test_main.cpp : Entry point for GoogleTest test_runner

# Usage:
#  1. Install cmake, g++, and make (and internet for first build to download GoogleTest)
#  2. Run: chmod +x run_tests.sh && ./run_tests.sh
#  3. All tests (original+public) will be built and executed with GoogleTest.
# 
# To run only public_tests/ as a separate executable, rebuild linking only those, or run ./test_runner and filter with --gtest_filter
