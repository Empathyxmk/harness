Explanations:
- src/: Contains C++ "dummy" logic used for test translation, simulating the behaviors needed for tests.
- include/: Placeholder for future public API headers.
- tests/original/: C++ versions of the original Python tests; test only internal/standard behaviors.
- public_tests/: C++ versions of public-facing tests, per requirements.
- tests/test_main.cpp: The entry point aggregates all test cases for running with Google Test.
- CMakeLists.txt: Configures building, testing, and downloads GoogleTest automatically.
- run_tests.sh: Script for building and running all tests (`./run_tests.sh`)
- project_structure.txt: Describes all project files and directories.
