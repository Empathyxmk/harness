- include/haishoku/ : Header files for the haishoku C++ library.
- src/haishoku/     : Library source files.
- demo/             : Demo (sample) code and sample image for tests.
- tests/original/   : Full translations of the original Python unit tests.
- public_tests/     : Public-facing tests as per public_tests in project.
- tests/test_main.cpp : Main GTest launcher for running all tests.
- run_tests.sh      : Minimal shell script to build and run tests.
- CMakeLists.txt    : Project's build and test configuration for CMake.
