Directory Explanations:

- `include/`:
    - Contains all API/public headers, class & function declarations for use by tests and other code.

- `src/`:
    - Implementation of all classes and functions declared in headers. Kept simple and stubbed only to allow all tests to pass.

- `tests/original/`:
    - Fully functional translations of the original (private) Python test suites.

- `public_tests/`:
    - Publicly released test cases (verifying similar logic, but as public interface validation).

- `CMakeLists.txt`:
    - Configures the C++ project for compilation, links Google Test, and builds a `test_runner` executable.

- `run_tests.sh`:
    - Cleans/builds the project and runs *all* tests in one step.

Build artifacts will be in `build/`.

To build/run/test:
    $ ./run_tests.sh
