DIRECTORY/FILE EXPLANATIONS
---------------------------
CMakeLists.txt            = Project config for CMake. Handles build, GTest fetch, adds all test executables.
run_tests.sh              = Build and run all tests (original & public) in one click.
src/                      = C++ source code(s), stubs or actual implementation.
include/                  = C++ public headers (if present).
tests/                    = Original test cases (translated from Python).
public_tests/             = Public test suite for "public" test scenarios.
README.md                 = Standard project readme.

SETUP & TEST INSTRUCTIONS
-------------------------
1. Install CMake and a modern C++ compiler.
2. Mark 'run_tests.sh' as executable if needed: chmod +x run_tests.sh
3. Run all tests: ./run_tests.sh
   - This will build in ./build/, compile, and run both test executables.
4. Add your source/module code in src/ and headers to include/ as needed.
