### Directory Explanation
- **src/**: Source code for ShortUUID and its modules.
- **include/**: Public headers.
- **tests/original/**: Tests faithfully ported from original Python repo; full private/internal coverage.
- **public_tests/**: Public or "limited-coverage" tests as in source.
- **tests/test_main.cpp**: Test main for original tests.
- **tests/test_main_public.cpp**: Test main for public tests.
- **run_tests.sh**: *Builds and runs all tests (original+public)* with a single command.
- **CMakeLists.txt**: Standard C++ build configuration (requires gtest).
