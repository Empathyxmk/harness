Directory Explanations:
- src/lib/           : Contains core C++ implementation and stub logic to allow tests to link/compile and pass (matches the tested API).
- include/           : Placeholder for public headers (could be used in a real project for API headers).
- tests/             : All test harness code and translated original tests. 'test_main.cpp' launches all GTest tests. tests/original/ holds original repo-only tests.
- public_tests/      : Tests visible to/used for public assessment (translated from `public_tests/` Python).
- run_tests.sh       : One-command test build and execution script.
- CMakeLists.txt     : Top-level build definition using GoogleTest.
- README.md          : Instructions/documentation (if provided).

How to build and run tests:
1. Install CMake and a C++ compiler (e.g., g++, clang++).
2. Run: ./run_tests.sh
   - This will build the project and run all tests. Output will indicate test results.
