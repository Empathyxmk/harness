Directory Explanations:
- include/: Contains project headers. All library/external symbols are declared here.
- src/: Contains implementation (.cpp) files for project code.
- src/CMakeLists.txt: Builds project library "fernet_fields".
- public_tests/: Contains public (releaseable) test cases in C++/GoogleTest. Mirrors Python public tests.
- tests/original/: Contains original (full coverage) test cases in C++/GoogleTest.
- tests/test_main.cpp: Test runner's main() for both original and public tests.
- CMakeLists.txt: Configures building, includes GoogleTest, collects all test files, builds the test runner.
- run_tests.sh: One-click script to configure, build, and run all tests.
- project_structure.txt: This file - explains project layout and instructions.
- README.md: Project quick start, notes, test running info.

Setup and Testing Instructions:
1. Prerequisites: CMake 3.10+, a C++14 compiler, internet for GoogleTest download.
2. To build & run all tests:
   $ chmod +x run_tests.sh
   $ ./run_tests.sh
   This will build all original and public tests and run them, reporting results.
3. For adding new tests, place them in tests/original/ (for private/original) or public_tests/ (for public).
