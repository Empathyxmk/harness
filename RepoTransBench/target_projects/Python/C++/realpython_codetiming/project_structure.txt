Directory explanations:
- src/lib: Implementation of code timing logic in C++
- include: Public headers for Timer and Timers
- tests/: All translated original (private) tests, grouped as in source project
- public_tests/: All translated public tests
- CMakeLists.txt: Configure GoogleTest, build and link all sources/tests
- run_tests.sh: Builds and runs all tests automatically
- test_main.cpp: Standard GTest main()
- README.md: User guide and doc

To build and run all tests:
$ ./run_tests.sh
