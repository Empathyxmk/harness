Directory explanations:
- include/: Header files for library and helpers.
- src/:      Implementation of library/config loader.
- tests/:    All original ("private"/developer) test cases, using GoogleTest.
- public_tests/: Public-facing test cases (mimicking the Python public_tests structure).
- configs/:  Mock configuration files encoded as JSON for testing (replace with production as needed).
- run_tests.sh: Simple build-and-test script.
- CMakeLists.txt: Standard build configuration for C++ using GoogleTest and nlohmann_json.
