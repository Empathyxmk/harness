Directory and File Descriptions:
- src/                -- C++ implementation source files (library code, not included in this translation if not provided)
- include/            -- Project header files (interfaces, class definitions)
- tests/original/     -- Original full unit and integration test cases, fully translated from Python to C++
- public_tests/       -- Public test cases, fully translated from Python to C++
- run_tests.sh        -- Simple script: builds project and runs all tests with one command
- CMakeLists.txt      -- CMake configuration to build tests and link Google Test
- project_structure.txt-- This overview and documentation

To run all tests:
    $ ./run_tests.sh

Requires:
    - CMake >=3.10
    - Google Test available (system package or via CMake's FetchContent)
    - C++17 compiler

All test cases are fully ported; all test logic, data, edge cases, and helpers are included. Simply build and run. If modifying source/library files, re-run the script to test changes.
