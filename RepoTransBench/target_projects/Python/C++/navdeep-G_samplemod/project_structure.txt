Directory explanation:
- include/sample/: Public headers for library functions used by all code/tests
- src/: Implementation of core logic and helpers; CMakeLists creates libraries for linking
- tests/: All translated original (private) tests, form test_runner
- public_tests/: All translated public test cases, form public_test_runner
- run_tests.sh: Build and runs both original and public tests in one step

Build and test instructions:
1. Make sure you have CMake and gtest (GoogleTest) installed.
2. Run: `chmod +x run_tests.sh`
3. Run: `./run_tests.sh`
   - This will build everything and run both private and public tests.
