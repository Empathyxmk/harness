Notes:
- All real header/source/implementation files (src/lib/, include/overholt, etc.) must provide the minimal API/stubs required for the tests to compile and link to Google Test.
- All original tests are located in tests/original/.
- All public tests are located in public_tests/.
- All API/Frontend tests and helpers are under tests/api/ and tests/frontend/.
- tests/test_main.cpp boots all test cases (Google Test standard).
- To add application/library sources: place them in src/lib/ and headers in include/overholt/.
- Edit CMakeLists.txt to add any sources/headers as necessary.
- See README.md for details.

How to build and run tests:
  $ chmod +x run_tests.sh
  $ ./run_tests.sh

Dependency: Google Test (GTest). If not installed, install via your system package manager, or build from source.
