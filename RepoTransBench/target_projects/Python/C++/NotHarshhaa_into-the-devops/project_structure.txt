Directory Explanations:
- include/: All public C++ headers for project utilities and shared symbols.
- src/: All implementation source code needed to run the logic being tested.
- tests/: Original test cases, matching logic/coverage from Python repo.
- public_tests/: Translated public test cases for public verification.
- run_tests.sh: Build and test C++ project with GoogleTest, all at once.
- CMakeLists.txt: Build and test definition using CMake and GTest.
- project_structure.txt: This overview.

Setup/Testing Instructions:
1. Make sure cmake and a C++ compiler are installed.
2. Run: chmod +x run_tests.sh
3. Run: ./run_tests.sh
   (This will build and run all original and public tests with GoogleTest. All results/summary will be printed.)
