# Directory explanations:
# - src/: Main source code (stubs provided to allow all tests to build/link)
# - include/: Public headers, for modular linking
# - tests/: All original (private) tests, matching Python test logic
# - public_tests/: All public-facing tests, matching public_tests from Python
# - run_tests.sh: One-click script for building and running both test suites
# - CMakeLists.txt: Standard build configuration, integrates Google Test

# How to build & run tests:
# 1. Ensure you have CMake and Google Test installed (on most Linux: `apt install cmake libgtest-dev`)
# 2. Make run_tests.sh executable with `chmod +x run_tests.sh`
# 3. Run `./run_tests.sh`
#    - This builds everything in 'build/', and then runs both test executables.
