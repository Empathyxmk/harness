- public_tests/: Translated public Python tests as C++ GoogleTest files.
- tests/test_main.cpp: Single entry point for all tests.
- run_tests.sh: Bash script to configure, build, and run the tests with a single command.
- CMakeLists.txt: CMake build configuration.
- project_structure.txt: This file.
- README.md: Setup and general usage documentation.
