Instructions:
-------------
1. Build and run all tests with:
   $ ./run_tests.sh
   (will build to ./build/ and run all tests from both tests/original/ and public_tests/ with Google Test)

2. All code is separated for clarity:
   - All C++ sources are in src/ and include/
   - Internal tests (from original repo) are in tests/original/; public tests in public_tests/

3. Add or adapt src/ headers for actual implementation. Current test coverage uses mock/stub logic and covers interface/behavior only.

4. The provided tests are complete translations of the Python tests. All logic and edge cases are preserved.
