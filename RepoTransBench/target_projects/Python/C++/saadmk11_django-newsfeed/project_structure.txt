Explanations:

- include/: C++ headers for domain/test objects shared across tests or modular code.
- src/: Library modules, app logic (here, dummy for testing). `CMakeLists.txt` builds library for test linkage.
- tests/: All translated test files (unit/integration) using Google Test.
    - test_main.cpp: Test runner main().
    - original/: All "original" Python tests, fully translated to C++/GTest.
- CMakeLists.txt: Top-level build targets, finds GoogleTest, compiles all tests.
- run_tests.sh: Simple one-click script: builds and runs all tests.
- project_structure.txt: You are here! Overall tree document.

Setup/Testing Instructions:

1. Install CMake and GoogleTest development headers (`libgtest-dev`).
2. Run: `chmod +x run_tests.sh && ./run_tests.sh`
3. All tests compile, then run automatically.
