# Directory and File Purposes:

- include/: Project header files, including the main interface to be used by all tests and implementations.
- src/: Actual implementation of the codebase (minimal/stub for compilation here; should be expanded for real use).
- tests/original/: All tests directly from the original Python test files (unit, functional, edge cases).
- public_tests/: Public tests designed to validate submission correctness/compatibility.
- tests/test_main.cpp: Singleton entry point for running GoogleTest in all test binaries.
- CMakeLists.txt: CMake configuration for building/testing the project, including gtest integration.
- run_tests.sh: Build and run all tests with a single CLI command; minimal and user-friendly.
- project_structure.txt: THIS file; maps/explains the project structure.

# Setup and Testing Instructions:

1. Ensure cmake and a C++17 compiler are installed.
2. Run: `chmod +x run_tests.sh`
3. Execute: `./run_tests.sh` from the root directory.
4. Both original and public test suites will build and run; results printed to terminal.
