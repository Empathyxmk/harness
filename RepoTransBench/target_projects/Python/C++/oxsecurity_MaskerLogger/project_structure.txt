Key Points:
- All tests based on Google Test (gtest)
- All testable logic implemented in src/ and include/
- tests/original/ holds translations of original Python tests
- public_tests/ holds translations of "public" test files
- All tests runnable with ./run_tests.sh
- Batch translation tracked via test_translation_progress.json
