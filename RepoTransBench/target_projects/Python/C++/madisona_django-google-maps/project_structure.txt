# Directory and file explanations:
# - src/lib/: C++ code for all mimicked data structures needed by the tests.
# - tests/original/: translation of all original python tests, 1:1 logic in C++/GTest.
# - public_tests/: all public test cases in C++/GTest.
# - run_tests.sh: builds and runs all tests in one step.
# - test_main.cpp: entry for all Google Test cases.
# - CMakeLists.txt: builds `test_runner` including all test sources and test dependencies.
