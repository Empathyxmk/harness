KEY COMPONENTS:
- CMakeLists.txt: configures build, includes GoogleTest, builds/runs all test files
- run_tests.sh: builds and executes tests (one-click)
- src/: source implementation (MUST match interface expected by tests)
- tests/original/: all original Python tests, 100% logic-preserving
- public_tests/: all public "sample" test cases, logic preserved
- examples/: rpp program source files used to test the interpreter
- test_helpers.h: helpers for file loading, simulated output
- Each test uses GoogleTest (gtest), e.g., TEST(Suite, Name).

USAGE:
  chmod +x run_tests.sh
  ./run_tests.sh

REQUIREMENTS FOR CORRECTNESS:
- All test cases are fully implemented in C++
- All assertions and output checks match original test intent
- Interpreter engine (rpp_exec, rpp_eval, RppRunner, etc.) must be implemented to pass all tests.
