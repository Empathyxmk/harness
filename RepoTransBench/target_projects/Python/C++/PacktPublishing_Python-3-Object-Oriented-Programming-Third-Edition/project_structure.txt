# Directory Explanations:
# - include/:        Put reusable C++ header (.h) files here for all modules/classes.
# - src/:           Place application / library C++ code here.
# - tests/:         Contains C++ GTest original tests, organized as above; see test_main.cpp as entry point.
# - public_tests/:  Contains C++ GTest public tests, one file per logical test suite.
# - CMakeLists.txt: Project build system, configures src/, tests/, and public_tests/.
# - run_tests.sh:   Minimal script to build and run all tests.
# - README.md:      Documentation and setup instructions.
# - build/:         Temporary build output directory.

# How to Build and Run Tests:
#  1. Run:  ./run_tests.sh
#     - This will build all sources and tests, and run all test suites (original and public) using Google Test.
#
# All test translation is in C++ and test files use Google Test conventions.
# See README.md for additional details.
