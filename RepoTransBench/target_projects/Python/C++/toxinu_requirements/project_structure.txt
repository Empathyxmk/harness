Directory explanations:

- include/: All public headers (requirements.h defines Requirement, Requirements interface for tests)
- src/: Implementation code (requirements.cpp is a stub for making tests compile, fill this with real implementation as needed)
- src/lib/: Placeholder for future submodules
- tests/: Translated original tests in C++ (GoogleTest)
- public_tests/: Translated public test suite in C++ (GoogleTest)
- run_tests.sh: One-click script to build and run all tests
- CMakeLists.txt: Build configuration, auto-discovers and builds both public and original tests into single runner

SETUP INSTRUCTIONS:

1. Install GoogleTest and CMake (on Ubuntu: `apt install libgtest-dev cmake g++`)
2. Place your production Requirement/Requirements implementation into src/ and include/
3. Run `chmod +x run_tests.sh`
4. Execute all tests:
       ./run_tests.sh

All test logic mirrors the Python versions, including error checks, requirement parsing, file structure handling, and edge case coverage.

To add more source/test files, expand `src/` and `tests/`/`public_tests/` as needed, and CMake will build/run automatically.
