Key Components:

- include/: 
    C++ library headers for greedypacker algorithms and objects.

- src/: 
    C++ implementation files for greedypacker functionality.

- tests/original/: 
    C++ translations of original Python test files (unit/regression, developer-facing).

- public_tests/: 
    C++ translations of public test files (for API/examples/public validation).

- CMakeLists.txt: 
    Build system configuration for library and tests, using Google Test.

- run_tests.sh: 
    One-command build and test runner script.

- README.md: 
    Top-level documentation and setup help.

Instructions:
1. Install CMake and g++/clang++ (and GoogleTest if not bundled with CMake).
2. Run `chmod +x run_tests.sh` if needed.
3. Execute all tests using: `./run_tests.sh`
