**Directory explanations:**
- `src/` and `src/lib/`: Library implementation (not provided—place .h/.cpp as needed).
- `include/`: Common header files (keep empty if not used; provide if desired for public APIs).
- `tests/original/`: Translated "original" test cases from the original Python repository.
- `public_tests/`: Translated public test cases.
- `tests/test_main.cpp`: Main driver for Google Test.
- `CMakeLists.txt`: Configures build, links Google Test, finds and compiles all tests and sources.
- `run_tests.sh`: Builds and runs all tests with a single command.
- `project_structure.txt`: This documentation.
