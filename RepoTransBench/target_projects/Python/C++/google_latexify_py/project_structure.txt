Directory explanations:
- include/:        All public header files for the latexify C++ library (API surface).
- src/:           All implementation code for latexify functionalities.
- tests/original/: All C++ test files corresponding to the original Python test suite.
- public_tests/:   All C++ test files corresponding to the Python public test suite.
- run_tests.sh:    Simple shell script to build and run the full test suite.
- CMakeLists.txt:  Build configuration using CMake and GoogleTest.
- README.md:       Usage and contribution instructions.
