EXPLANATION:
- tests/original/: All C++ test files translated from the original Python tests (full logic, coverage, edge cases preserved).
- public_tests/: All C++ public tests translated from Python public_tests/ directory, same structure. (Example below.)
- CMakeLists.txt: CMake configuration for dependency fetching (GoogleTest), test building and test discovery.
- run_tests.sh: Just run ./run_tests.sh in project root for full test build and execution.
- src/: Can be used if porting implementation classes (optional--tests above are self-contained for demonstration).

USAGE:
1. Install CMake and a C++ compiler
2. Run: ./run_tests.sh
3. All original and public tests will build and run!
