Explanations:
- CMakeLists.txt: Top-level cmake configuration, sets up Google Test, project, and subdirectories.
- include/: Public headers for core library (exceptions, utils, config, etc.).
- src/: Source code implementation for Tiddl core library (add real code as needed, CMake expects suitable headers).
- tests/: Original/internal/unit test translations, built as 'test_runner'.
- public_tests/: Public tests, built as 'public_test_runner'.
- build/: cmake build output directory (auto-generated).
- run_tests.sh: Script to build and run *all* tests (both internal and public).
- README.md: Usage, build, and documentation notes.
