Structure Explanation:

- include/: C++ public API headers. iterative_stratification.hpp defines the C++ interface used in all tests.
- src/lib/: (Empty placeholder) Where actual algorithm implementation source would reside.
- tests/: All original test files, named for each Python test file and containing equivalent logic in C++. test_main.cpp provides Google Test main entry point.
- public_tests/: All public test files. These validate the interface and observable behaviors, including existence checks (README.md, LICENSE).
- CMakeLists.txt: Complete build config, including GoogleTest automatic fetch & integration.
- run_tests.sh: Simple script to configure, build, and run every test in one step.
- README.md, LICENSE: Carried over from the Python repo. Used for test existence checks.
