-----------------------------------------------
Directory/Files Explanation:

- CMakeLists.txt: Root CMake project config. Adds all test source and links to GTest.
- include/: Place header files (must be included by both library & tests).
- public_tests/: All public (student-facing) test cases, one .cpp per suite, for GTest.
- run_tests.sh: One-click script: builds in ./build, runs all tests via Google Test.
- src/: C++ source implementation. Place your main modules here (main.cpp optional).
  - src/lib/: Keep class implementations and sources logically organized (e.g., Signer, Serializer, etc.).
- tests/test_main.cpp: GTest test main for all tests.
- tests/original/: All translated original test cases, one .cpp per suite.
- README.md: General project documentation.
- project_structure.txt: This file.

-----------------------------------------------
SETUP & RUNNING INSTRUCTIONS:

Prerequisites:
  - CMake (>=3.10)
  - A C++17 compiler (g++ or clang++)
  - Google Test (gtest) development libraries

To build and run all tests:

  $ chmod +x run_tests.sh
  $ ./run_tests.sh

This will:
  - Build everything in ./build/
  - Run *all* tests (both original and public) via test_runner (GTest)
  - Output results to the terminal

Test Structure:
  - All tests use Google Test (`TEST`, `EXPECT_*`, etc).
  - Keep new test cases in the appropriate directory (`tests/original/` or `public_tests/`).
  - If adding new library code, put implementation in src/ and headers in include/.

See README.md for more information.
