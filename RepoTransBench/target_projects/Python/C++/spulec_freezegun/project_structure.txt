Directory Explanations:
- include/freezegun/    : Contains public headers for C++ freezegun logic and config
- src/freezegun/        : Implementation files for core logic (dummy/freezegun replacements as needed)
- tests/original/       : C++ translation of original Python test cases; full internal/functional validation
- public_tests/         : Publicly visible/targeted tests; C++ translation of Python provided public tests
- tests/test_main.cpp   : All test files and GTest main registration
- CMakeLists.txt        : Project build/test config—discovers and builds all tests and sources
- run_tests.sh          : Rebuilds and runs all tests with a single command
- README.md             : C++ project build and usage instructions

Instructions:
- Install CMake and GoogleTest for your platform.
- Run: `./run_tests.sh` from the repo root to build and execute all tests.
