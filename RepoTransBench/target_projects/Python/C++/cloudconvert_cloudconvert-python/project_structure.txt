- CMakeLists.txt: CMake configuration file specifying test/executable targets and GTest usage.
- include/: Place for your project headers; use for C++ equivalents of Python cloudconvert modules.
- src/: Place for your main source implementation files for the library/code under test.
- public_tests/: Public test cases translated from Python, named with test_public_ prefix for clarity.
- tests/original/: Original (non-public) test cases, direct logic translation from the Python source.
- tests/test_main.cpp: Entrypoint for running all tests via GoogleTest.
- run_tests.sh: Simple one-click build and test execution script.
- README.md: Place documentation and setup instructions here.
- project_structure.txt: This documentation.

To run all tests (original and public):
    $ ./run_tests.sh

Dependencies:
- C++17 or later compiler
- GoogleTest (gtest) library and headers (install via your package manager)
- CMake >= 3.10
