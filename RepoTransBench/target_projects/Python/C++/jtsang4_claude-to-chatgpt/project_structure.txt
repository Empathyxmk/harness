-----------------------------------------------------------------------------------
Directory/Files explanation:

- include/claude_to_chatgpt/      - C++ headers for core functionality
- src/claude_to_chatgpt/          - Corresponding C++ implementation files (.cpp)
- tests/                          - All original translated tests from Python,
                                   each matching test_* file implementing
                                   complete test logic with Google Test.
                                   test_main.cpp runs all.
- public_tests/                   - All public-translated tests, preserved logic,
                                   for public releases. test_public_main.cpp runs these.
- run_tests.sh                    - Build-and-run script. Just run: ./run_tests.sh
- CMakeLists.txt                  - Top level CMake config. You need CMake >= 3.14
- project_structure.txt           - This documentation file.
-----------------------------------------------------------------------------------
Instructions:

1. Install dependencies:
   - Requires C++17, CMake >= 3.14, Google Test (added via FetchContent or package).

2. To build and run all tests:
   $ chmod +x run_tests.sh
   $ ./run_tests.sh

   - This will build everything in ./build, then run both original and public tests.

3. Add/Modify tests:
   - Add new C++ test cases in tests/ (original) or public_tests/ (public).
   - Source logic in src/ and headers in include/ as needed.

4. To clean build:
   $ rm -rf build
