Directory Explanations:
- include/: All exported public headers for main library components.
- src/: Implementation .cpp files for main modules.
- tests/original/: C++ translations of original (private) Python tests.
- public_tests/: C++ translations of public Python test suites.
- tests/test_main.cpp: Unified Google Test main entrypoint for all tests.
- run_tests.sh: Simple script to configure, build, and run all tests in one call.

Setup & Testing Instructions:
1. Ensure you have CMake >=3.14 and GoogleTest installed, or have CMake download it as needed.
2. To build and run all tests, simply execute:
      ./run_tests.sh
   from the repository root.
3. All test results are shown in the terminal upon execution.
