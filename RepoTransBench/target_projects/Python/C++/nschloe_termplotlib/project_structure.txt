Directory and file explanation:
- CMakeLists.txt      : Configures CMake project, fetches Google Test, builds test_runner from both original and public tests.
- include/            : Placeholder for any public C++ headers (not needed for these tests but included for completeness).
- src/                : Placeholder for C++ library implementation; would contain translation of termplotlib.
- tests/              : Contains all original test cases, translated from Python to C++/Google Test.
- public_tests/       : Contains all public tests (like those for open evaluation).
- run_tests.sh        : Minimal shell script to build everything and run all tests (no arguments needed).
- project_structure.txt: This file; overview of the layout and instructions.
- README.md           : Human-readable instructions (optional; usually included).

Test commands:
  $ ./run_tests.sh

Dependencies:
- Requires CMake and a C++17 compiler (GCC, Clang, or MSVC).
- Google Test is automatically downloaded/built via CMake.
- No other dependencies.

To run all tests (original and public), simply execute:
    ./run_tests.sh
from the project root.

All test logic is included, no test code has any stubs or placeholders.
