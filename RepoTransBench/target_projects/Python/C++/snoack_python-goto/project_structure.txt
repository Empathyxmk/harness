Directory explanations:
- include/: C++ headers needed by source/tests.
- src/: Source code; here just gateways to dummy stubs for tests.
- tests/original/: Translated original Python test cases.
- public_tests/: Translated public Python test cases.
- run_tests.sh: Build and run script (use `chmod +x run_tests.sh`).

How to build and test:
1. Install CMake and a C++17 compiler (e.g. g++ or clang++).
2. `chmod +x run_tests.sh`
3. `./run_tests.sh`
All tests (original and public) will compile and run via Google Test, with results shown in terminal.
