Directory explanations:
src/         - Main source files; library code for the project.
include/     - Public header files for the project.
tests/original/ - C++ translations of "original" tests from the Python repo.
public_tests/   - C++ translations of "public" tests from the Python repo.
CMakeLists.txt  - Configures build and test with GoogleTest.
run_tests.sh    - Builds and runs all tests with one command.
README.md       - Project/documentation info.

How to build and run all tests:
$ ./run_tests.sh

This will:
- Build the project using CMake and make.
- Run all tests using GoogleTest.

No additional dependencies (other than CMake, Make, a C++14+ compiler) are required;
GoogleTest is fetched automatically as part of the build.
