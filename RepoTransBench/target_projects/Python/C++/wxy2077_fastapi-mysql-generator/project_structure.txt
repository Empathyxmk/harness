# Directory Explanations:
#
# CMakeLists.txt: Configures all builds and dependencies. Discovers all test files automatically.
# run_tests.sh:   One-step build and test (chmod +x, then ./run_tests.sh).
# src/:           Place for core C++ app logic (optional/stubbed here; not used for pure test translation).
# include/:       Headers for main source (optional).
# tests/original/:Contains all unit tests converted from the original Python test suite.
# public_tests/:  Contains all public/visible test cases, translated to C++.
#                 Folders/filenames match Python hierarchy, but with _test.cpp suffix for C++.
#                 All logic, test data, and assertions fully implemented with Google Test.
#
# To Build & Run All Tests:
#   1. Install CMake and a C++17 compiler.
#   2. (Let CMake fetch GoogleTest automatically.)
#   3. Run: ./run_tests.sh
#
# Output: Tests will compile and run, printing a summary of all passed/failed cases.
