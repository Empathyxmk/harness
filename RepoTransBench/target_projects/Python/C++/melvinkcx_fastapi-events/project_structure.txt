Description:

- `src/` and `include/`: Placeholders for implementation, not needed just for running tests, but included for C++ conventions.
- `tests/original/`: Full translation of core/original Python tests to C++. Split in subdirectories for `handlers/` and `middleware/` as in Python.
- `public_tests/`: C++ versions of public-API tests only. Mirror structure of Python's `public_tests/`.
- `CMakeLists.txt`: Handles fetching Google Test, scanning all test .cpps, and setting up test binaries.
- `run_tests.sh`: One-command build and test execution.
