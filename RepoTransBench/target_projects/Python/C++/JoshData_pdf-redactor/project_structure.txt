Directory/Files Explanations:
- include/: Header file(s) for all public/project-visible C++ APIs (pdf_redactor.hpp).
- src/: Implementation for main source library (pdf_redactor.cpp).
- tests/: All original ("private") tests from Python ported to C++/gtest.
- public_tests/: Public test suite (as per "public_tests" in Python), same logic and API coverage.
- test-ssns.pdf: PDF fixture needed for some tests (copy from original).
- run_tests.sh: Top-level script for CMake+gtest-driven one-command build/run.
- CMakeLists.txt: Main project config, finds GoogleTest, builds src+tests and sets up test execution.
- README.md: How to build/test and brief notes.
