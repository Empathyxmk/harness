Directory/Files Explanation:
- CMakeLists.txt: Tells CMake how to build all test code and where tests are located.
- tests/: For original test cases.
- public_tests/: For public versioned test cases.
- src/, include/: Standard C++ project source layout for main code (not strictly required in this minimal repo).
- build/: CMake puts build output here (not source-controlled).
- run_tests.sh: One-click script for building and running all tests using CTest and GoogleTest.
- README.md: Explains setup, dependencies, and how to run tests.

Instructions:
  1. Install Google Test (libgtest-dev) and CMake (>=3.10) on your system.
  2. Place your setup.py file in this directory.
  3. From project root, run:  chmod +x run_tests.sh
  4. Execute tests with:      ./run_tests.sh

Both original and public variant tests will be built and run automatically.
