--- Directory Explanations ---
include/:      Public headers for the OAuth library.
src/:          C++ source files implementing the library.
tests/:        Original tests, translated from Python, using GoogleTest.
public_tests/: Public tests, using GoogleTest, separated as in the source repo.
build/:        Out-of-source CMake build directory (created at build time).
run_tests.sh:  Builds and runs all tests with a single command.

--- Setup and Testing ---
1. Ensure C++17 or newer and CMake, and gtest installed or let CMake fetch it.
2. Run tests:
   $ chmod +x run_tests.sh
   $ ./run_tests.sh

This builds both the library and all tests. Both original and public tests are built and run, and results are printed.
