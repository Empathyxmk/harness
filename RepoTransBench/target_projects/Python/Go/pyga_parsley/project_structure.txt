Directory Explanations:
- internal/: Contains the Go source implementations needed for the test suites (parsers, grammars, runtime, etc.)
- tests/: All original (non-public) tests, ported from Python's full test suite.
- public_tests/: Publicly generated tests, ported from the public_tests Python suite.
- go.mod/go.sum: Go module files for dependency and version tracking.
- run_tests.sh: One-click script to run ALL Go tests recursively.
- README.md: Setup instructions, usage, project notes.

Setup & Test Instructions:
1. `go mod tidy` (once, to fetch dependencies)
2. `chmod +x run_tests.sh`
3. `./run_tests.sh` to run all tests (original and public).
4. All tests use Go's standard testing package and are discovered recursively.

Notes:
- Test coverage matches original Python suite: both original/unittest/pytest and public_tests are ported.
- Packages in `internal/` expose all public APIs for tests.
- All dependencies are standard library or specified in go.mod.
