Directory explanations:
- go.mod: Go module definition and dependency versions.
- run_tests.sh: Runs all the Go tests in `tests/` (original) and `public_tests/` using `go test`.
- main.go: (Optional) Main entrypoint for application (not needed for pure library).
- tests/: Contains all translations of the original Python test cases, organized with one Go file per original Python file. Keeps structure and naming as in Python for clarity.
- public_tests/: Contains public test case translations, fully implemented in Go, simulating public API and minimal reproducible cases.
- Each `*_test.go` is a standard Go test file and can be run with `go test ...`.
