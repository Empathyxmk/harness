Directory Explanations:
- go.mod: Declares the Go module.
- run_tests.sh: Simple script to execute all tests for the project.
- public_tests/: Contains all public test cases, directly translated from the source's public_tests/*.py.
- tests/original/: Contains original (non-public) test cases, directly translated from the source's tests/unit/*.py and tests/coq/*.py.
- tests/testutil.go: Helper functions shared across tests.
- README.md: Documentation of setup instructions, directory purpose, and usage.

Setup/Testing Instructions:
1. Make sure you have Go installed (version 1.21 or higher).
2. Run `chmod +x run_tests.sh` if necessary to ensure the script is executable.
3. Run all tests with:
   ./run_tests.sh

This will recursively execute all tests in tests/ and public_tests/.
