README:
- All original and public test cases are translated under 'tests/original' and 'public_tests' respectively.
- Place all '.rpp' files from examples/ for source test compatibility.
- Main implementation code should go in rajinipp/, organized by functionality.
- To run all tests: `./run_tests.sh`
- To add dependencies, use `go mod tidy` and import in go.mod as needed.

All test helpers are in tests/testutil.go. If you further port the interpreter to Go, hook up all testutil stubs and adapt accordingly.
