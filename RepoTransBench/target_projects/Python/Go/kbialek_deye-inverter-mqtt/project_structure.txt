Directory Notes:
- src/: Main Go implementation ("src" mirrors Python source usage, not Go standard but kept for transition). Consider re-exporting with canonical Go package paths once stable.
- plugins/: Go translation of plugin samples, to mirror Python plugins.
- tests/original/: Complete translations of all original Python unit/integration tests, named with *_test.go and using Go's testing package.
- public_tests/: Complete translations of all public sample/coverage/demo tests, for external validation, education, and compliance.
- run_tests.sh: Standard single-command test script – no arguments, just ./run_tests.sh
- go.mod: Required for Go package and dependency management (run "go mod tidy" as needed).
- README.md: Usage, development, build, and test instructions for new Go repo users.

Quick Start:
1. `go mod tidy` – download dependencies.
2. `./run_tests.sh` – runs all unit, integration, and public tests with Go's standard test runner.

All tests (`*_test.go`) in `tests/original/` and `public_tests/` will be discovered automatically by `go test ./...` and run.
