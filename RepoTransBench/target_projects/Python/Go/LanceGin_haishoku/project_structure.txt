## Directory Explanations

- `go.mod` - Module and dependency configuration for Go.
- `README.md` - Simple usage and test instruction guide.
- `run_tests.sh` - Run `go test ./...` on all test files.
- `project_structure.txt` - This file. Describes structure and intent.

#### Source Code
- `haishoku/` - Implementation of Haishoku color extraction and related algorithms, ported to Go.
  - (NOTE: Only skeletons needed for tests to build—see test files for test logic.)

#### Test Suites
- `tests/original/` - Original functionality and edge-case tests, ported from Python `tests/`.
- `public_tests/` - Public sample/coverage/edge-case tests, ported from Python `public_tests/`.

All tests conform to Go's standard testing practices: filenames end in `_test.go` and test functions start with `Test`.

## How To Extend

- Implement missing functions in the `haishoku/` directory to make all tests pass.
- Add new test files under appropriate test directories.
