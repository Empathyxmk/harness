# Directory and file explanations:
# - go.mod: Defines the Go module for dependency management.
# - run_tests.sh: Runs all tests in the project with `go test ./...`.
# - tests/original/: Contains Go translations of the Python project's original test suites.
# - public_tests/: Contains Go translations of the project's Python public test suites.
# - Each *_test.go file implements Go test cases matching the logic of its Python counterpart.

# Setup and testing instructions:
# 1. Ensure you have Go installed (version >= 1.20).
# 2. Run tests: `./run_tests.sh` (give execute permission if necessary: `chmod +x run_tests.sh`)
# 3. All test suites (original and public) will be discovered and run by Go's standard tooling.
