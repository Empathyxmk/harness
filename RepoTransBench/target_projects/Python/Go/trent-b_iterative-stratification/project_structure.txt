# Directory explanations:
# - go.mod:         Declares the module and its dependencies (here, only testify for assertions)
# - run_tests.sh:   Main entrypoint; runs all Go tests for both tests/* and public_tests/*
# - README.md:      Project documentation (mirrored from original if desired)
# - LICENSE:        License file (mirrored from original if desired)
# - tests/:         Directory for original, internal project test logic (ported from Python)
# - public_tests/:  Directory for public-facing test logic (ported from Python)
# - *_test.go:      Go convention for test files (recognized by `go test`)

# Setup and Testing Instructions:
# 1. Ensure Go is installed (v1.20+ recommended).
# 2. Install dependencies: `go mod tidy`.
# 3. Run all tests (original and public) with: `./run_tests.sh`.
# 4. To run tests for a specific package: `go test ./tests/...` or `go test ./public_tests/...`
