Directory explanations:
- sample/: Go implementation of the module's functionality.
- tests/original/: Original (private) test cases, fully translated from Python's unittest suite.
- public_tests/: Publicly visible/auto-generated tests, translated from provided Python.
- run_tests.sh: Bash script, just run `./run_tests.sh` to execute all original and public tests.
- testutil.go: Utility to patch helpers during testing (simulated "monkeypatching" a global function).

Setup:
1. Run `go mod tidy` if needed (dependencies are standard library only).
2. Run tests: `./run_tests.sh`
3. All tests (original and public) are included in the proper folders using Go's testing conventions.

No extra dependencies needed; just requires Go toolchain.
