# Directory Explanations
# ----------------------
# go.mod            : Declares Go module, language version, dependencies.
# run_tests.sh      : Runs all tests in the project (./public_tests and ./tests/original).
# public_tests/     : Go translations of public-level test cases.
# tests/original/   : Go translations of original/internal test cases (full coverage).
#
# All *_test.go files: Contain properly organized, complete Go test functions.

# How to Run Tests:
# -------------
# 1. Make sure you have Go installed (version 1.20+ recommended).
# 2. From project root, just run:
#      ./run_tests.sh
# 3. Test results for all suites will display with standard Go output.

# Adding New Tests:
# --------------------------
# - Stick to Go's naming conventions (MyFeature_test.go for files, TestMyFeature for test funcs).
# - Place public-facing tests in 'public_tests/', and internal/full-coverage tests in 'tests/original/'.
