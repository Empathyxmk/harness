# Directory/filename explanations:
# go.mod                : Declares Go module, required for dependency management/startup.
# run_tests.sh          : Script to run all tests in the codebase via go test (one command).
# public_tests/         : All public test cases placed here, equivalent to Python's public_tests/ folder.
# tests/original/       : Contains all "original" (non-public) tests translated from the original Python suite.
# ..._test.go           : All unit/integration test files in Go are named *_test.go for test discovery.

# To run all tests, simply invoke:
