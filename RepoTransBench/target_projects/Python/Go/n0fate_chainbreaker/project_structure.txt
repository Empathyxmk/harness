Project Structure Explanation:
-----------------------------
- go.mod:            Declares dependencies and Go module for the project.
- run_tests.sh:      Bash script to run all Go tests with one click (`./run_tests.sh`).
- tests/original/:   Contains original (non-public) test suite, translated from Python source.
- public_tests/:     Contains public-facing tests, as generated and intended for public verification.
- project_structure.txt: This documentation file.

Test Execution Instructions:
---------------------------
1. Ensure you have Go installed (v1.18+ recommended).
2. Make the test script executable: `chmod +x run_tests.sh`
3. Run all tests: `./run_tests.sh`

All tests will run and results print to stdout as per `go test` conventions.
