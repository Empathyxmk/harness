Directory/Files Explanation:
--------------------------------------
- jsonrpc/:         Go package source code (converted from .py to .go)
- tests/original/:  All legacy/original tests from Python ported to Go
- public_tests/:    All public user-facing tests ported from Python's public_tests
- go.mod:           Declares the Go module and dependencies
- run_tests.sh:     Runs all Go tests in the workspace (across original/public)
- README.md:        Project explanation, setup usage, testing instructions

How to Test:
--------------------------------------
1. Ensure you have Go installed (`go version`)
2. From project root, run:
   $ chmod +x run_tests.sh
   $ ./run_tests.sh

This will execute all unit tests (from tests/original and public_tests folders).

Custom test organisation preserves both internal and public verification coverage.
