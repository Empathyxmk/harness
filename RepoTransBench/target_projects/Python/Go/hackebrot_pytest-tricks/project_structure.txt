Directory explanations:
- tests/original/                                 : All original Go test translations, mirrors original Python test logic.
- public_tests/                                   : All public test translations. Follows Python public test logic and structure.
- go.mod                                          : Go module definition, required for dependency resolution.
- run_tests.sh                                    : Execute all tests in the project with a single command.
- project_structure.txt                           : This file explaining the structure.
- README.md                                       : Setup and execution instructions.

How to run tests:
1. Ensure Go 1.20+ is installed.
2. Execute: chmod +x run_tests.sh
3. Then: ./run_tests.sh

All tests in both original and public directories will be executed.
