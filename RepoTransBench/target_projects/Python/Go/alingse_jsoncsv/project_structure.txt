- go.mod: Declares the Go module and manages dependencies.
- run_tests.sh: Simple test runner script, executes all Go tests in all packages.
- README.md: Documentation and usage instructions for the Go port.
- tests/original/: Original function and CLI tests, translation from Python 'tests' directory.
- public_tests/: Public/fairness tests, mirroring public_tests/ from Python, prefixed for Go convention.
- jsoncsv/: Source implementations (migrated core logic from Python to Go).
- fixture/files/: Reused test fixtures (data files), accessible to both test sets.
- project_structure.txt: Describes layout, structure, and file purpose.
