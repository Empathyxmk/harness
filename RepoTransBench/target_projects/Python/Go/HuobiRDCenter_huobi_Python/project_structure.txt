Directory Explanations:
-----------------------
huobi/           - Minimal stubs for imported modules/functions/classes (mocked for tests, as source not translated)
tests/           - "Original" SDK test cases (full translation from Python's tests/)
public_tests/    - "Public" SDK test cases (full translation from Python's public_tests/)
run_tests.sh     - Simple shell script, runs all Go tests in project tree

Setup & Run:
------------
1. Install Go >=1.18
2. From project root: chmod +x run_tests.sh
3. Run all tests: ./run_tests.sh

No external dependencies required. All mocks/stubs in place for test logic coverage.
