# Directory explanations:
# - claude_to_chatgpt/: Main application code. Each .go file corresponds to a former .py module.
# - tests/original/: All original (private) test files, directly ported from Python
# - public_tests/: Public test equivalents, ensuring open test coverage
# - run_tests.sh: Runs both private and public tests with one command.
# - go.mod: Go modules definition, with 'testify' as a test helper assertion package

# Setup and test instructions:
# 1. Clone repo and install Go (1.20+)
# 2. Run `go mod tidy` if dependencies are missing
# 3. Run `./run_tests.sh` from project root to execute all tests
# 4. New test files should follow Go suffix (_test.go) and reside in their respective test dirs
