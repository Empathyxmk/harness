Directory explanations:
- go.mod: Go module dependencies and project info.
- run_tests.sh: Simple, one-command test runner.
- project_structure.txt: Overview and explanation.
- tests/original/: Original "private" (non-public) translated test cases.
- public_tests/: Public test cases (for open testing/assessment).
- tests/testutil.go: Shared utilities among all tests.
- us/: Main package with core library source code, types, constants, mappings.
- README.md: Explains usage, build, test, and contact info.

Setup and testing:
1. Install Go 1.20+ (https://golang.org/dl/)
2. Clone this repo; run `go mod tidy` to fetch dependencies.
3. Run all tests: `./run_tests.sh` (ensure it is executable).
4. Both original and public tests will run and report results.
