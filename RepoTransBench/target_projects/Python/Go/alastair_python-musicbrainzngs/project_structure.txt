### Directory/Files Explained

- `go.mod`: Standard Go module descriptor; manages module imports and versions.
- `README.md`: Project overview, how to run tests, summary.
- `run_tests.sh`: One-click script to run all Go tests in every package/subdir.
- `tests/original/`: All original test files, one per original Python test (translated).
- `public_tests/`: All public test files, mirroring the public Python tests. Standalone/public logic only.
- `project_structure.txt`: This file, documents the directory tree and file purposes.

### How to Run

1. Make sure you have Go installed (`go 1.21` or later).
2. From the project root, run: `./run_tests.sh` to execute all tests.
3. All test output will be displayed in standard Go test format.
