Directory Explanations:
- underscore/: Main package with utility functions, all the logic you would call from tests.
- tests/original/: Original (private) test cases directly mapped from Python source.
- public_tests/: Public test cases; mapped for public/visible testing as in the Python version.
- run_tests.sh: Minimal script to run all tests via 'go test ./...'
- go.mod: Go module management.

Setup/Testing Instructions:
1. Install Go 1.18+.
2. To run all tests, just:
      ./run_tests.sh
3. All test cases in both tests/original/ and public_tests/ will be run.
