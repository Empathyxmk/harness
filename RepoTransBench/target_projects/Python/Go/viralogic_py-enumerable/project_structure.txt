Structure explanations:

- `tests/original/`: All private (original) Go test files, one per source test, with full logic.
- `public_tests/`: All public Go test files, following source public test structure.
- `go.mod`: Go modules build/dependency file.
- `run_tests.sh`: Simple test runner, executes all Go tests.
- `project_structure.txt`: (This file) Project documentation & structure tree.
- `testutil.go`: Any necessary test helper/util functions, shared by tests.
- `tests/files/`: Test data files.
- `docs/`: User/developer documentation.
- `README.md`: General project and usage/readme.

How to run tests:
1. Install Go 1.20+.
2. From the project root, run:
   $ chmod +x run_tests.sh
   $ ./run_tests.sh

All original and public tests will be run, and all results shown.
