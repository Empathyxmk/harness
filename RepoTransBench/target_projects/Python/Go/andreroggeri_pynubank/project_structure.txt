# Directory and file explanations:
# - tests/original/: All source Python "original" tests, translated and fully implemented using Go's testing and testify packages.
# - public_tests/: All public Python test equivalents, with relevant test logic and scenarios, Go translated and self-standing.
# - run_tests.sh: Runs *all* tests detected by `go test ./...`.
# - go.mod: Declares required Go packages (including testify for rich assertions).
# - README.md: Guidance for project usage, test running, background info.
# 
# To execute all tests:
#    1. Make sure you have Go 1.18+ installed.
#    2. Run `chmod +x run_tests.sh` if needed.
#    3. Run `./run_tests.sh`
# 
# All test cases (original and public) will run, reporting all assertion failures and coverage like in Python.
