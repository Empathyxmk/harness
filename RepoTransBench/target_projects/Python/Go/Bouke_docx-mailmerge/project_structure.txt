Directory/Files Explanations:

go.mod
    Standard Go modules file. Declares this as a Go module and allows `go test ./...` or importing dependencies.

run_tests.sh
    Simple bash script to execute ALL tests with `go test ./...`. Make sure it's executable: `chmod +x run_tests.sh`.

tests/original/
    All tests originally found in Python (one .go for each .py). All logic has been faithfully translated and unit tested here. 
    Each test is self-contained and follows Go's testing conventions.

-------------------------------------------------------
Setup & Testing Instructions:

1. Install Go (>= 1.20).
2. Run tests with: ./run_tests.sh
   - This executes all Go tests.
3. No external dependencies are required for these tests.
