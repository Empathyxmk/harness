Directory Overview:
-------------------
- shortuuid/:      Go implementation of the package (to be implemented).
- tests/original/: All "original" (full-coverage/internal) test cases from Python, translated to Go.
- public_tests/:   All public-facing test cases, translated to Go.
- run_tests.sh:    Runs all tests (Go standard). Make executable with `chmod +x run_tests.sh`.

Setup:
------
1. Make sure Go is installed (Go >= 1.21 recommended).
2. Install dependencies with `go mod tidy`.
3. Run all tests with: `./run_tests.sh`

All test logic translated 1:1 from the original Python source. Some "Django field" tests are skipped or simulated/mocked as appropriate for Go.
