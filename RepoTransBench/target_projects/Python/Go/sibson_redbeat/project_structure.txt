### Directory Explanations:

- `redbeat/`:
    Core stubs implementing types, methods, and test helpers so the tests will compile and run, even if the actual business logic is not implemented (as source is not available).

- `tests/`:
    Full translation of the "original" Python tests, covering all tested logic (decoder, entry, config, scheduler, etc.). Replicates results and checks of the Python suite.

- `public_tests/`:
    Lighter "public" test cases — mirror the logic of their Python public counterparts.

---

## Setup and Test Instructions

1. Install [Go](https://golang.org/).
2. Install dependencies (automatically via `go mod download`).
3. Run `./run_tests.sh` to execute all tests.

---

> NOTE: If modifying stubs under `redbeat/`, ensure public and original test logic remains valid.
