# Directory Explanation:

- tests/original/:
    Contains complete ports of all original Python test files,
    translated and organized as *_test.go for Go's `testing` package.
- public_tests/:
    Contains the public version of tests (sample/test-case driven).
- main.go:
    A stub entrypoint; you may place the library/logic code there if building a real implementation.
- go.mod:
    Manages modules and dependencies.
- run_tests.sh:
    Test runner script; executes `go test ./...` across all packages.
- testutil.go:
    A place for any shared test utilities if needed for cross-file test helpers.

# Setup & Testing Instructions

1. Ensure Go is installed (version 1.20+ recommended).
2. Run: `./run_tests.sh`
   This will discover and run all tests.
