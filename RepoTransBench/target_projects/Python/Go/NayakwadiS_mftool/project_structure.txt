Directory explanations:
- tests/original/: Contains the direct translations of "original" (not public) Python tests.
- public_tests/:   Contains test cases that serve as alternate/public-facing tests.
- run_tests.sh:    One-click script to run all tests recursively via `go test ./...`.
- go.mod:          Go package/module requirements.
- README.md:       Overview and usage guide for this Go project.
- (src):           Your Go source files (e.g., mftool.go, utils.go) should be placed at root or organized further.

How to Run:
  1. Ensure Go 1.18+ is installed.
  2. Run `chmod +x run_tests.sh` if not already executable.
  3. Execute `./run_tests.sh` from the project root to run all tests.
