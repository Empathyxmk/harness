## Directory explanations:
- go.mod: Go module & dependency declaration (using testify for asserts, yaml.v3 for YAML)
- public_tests/: Public-facing test cases, clean-room logic, suitable for end-user samples
- tests/original/: Original repository engineering tests closely mapping Python source
- run_tests.sh: Simple script to run all tests (`go test ./...`)
- main.go: Placeholder app entrypoint (empty for now)
- testutil/: Utility helpers for tests (e.g., YAML file helpers if needed)

## Running tests:
1. Make sure you have Go >=1.20 installed.
2. Make the test script executable: chmod +x run_tests.sh
3. Run all tests: ./run_tests.sh
