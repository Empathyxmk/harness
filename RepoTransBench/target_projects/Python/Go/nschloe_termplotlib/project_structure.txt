Directory Explanations:
- go.mod: Declares Go module, required for all dependencies and package management.
- run_tests.sh: Simple script to run all tests (uses go test ./... so all packages and tests are discovered automatically).
- tests/: Contains all original private tests, exactly translated from Python unittest.
- public_tests/: Contains all public (released) test cases, exactly translated from the public_test_summary listing.
- project_structure.txt: You are reading it! Overview of folders, test suites, and quick start guide.

Setup & Testing Instructions:
1. Ensure you have Go (>=1.20) installed.
2. Run: `chmod +x ./run_tests.sh` (if needed).
3. To run ALL tests: `./run_tests.sh`
4. All tests run using standard Go test runner. Both original and public_tests suites are discovered.
