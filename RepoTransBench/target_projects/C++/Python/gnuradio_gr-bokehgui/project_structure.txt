Directory explanations:
- public_tests/: Contains full implementations of public test cases.
- requirements.txt: Only needs pytest (you can install with `pip install -r requirements.txt`).
- run_tests.sh: Runs all tests with a single command. Run with: `chmod +x run_tests.sh && ./run_tests.sh`
- tests/: Main test directory. "original/" holds private test logic.
  - test_* files at top-level import from original/ to support multiple runners
- project_structure.txt: This structure/documentation.
