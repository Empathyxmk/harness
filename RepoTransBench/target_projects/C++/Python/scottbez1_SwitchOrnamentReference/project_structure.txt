Directory explanations:
- tests/original/ : Canonical/original test suite for full coverage, directly translated from json11_test.cpp and json11_extra_test.cpp.
- public_tests/   : Public test suite with alternate data and cases as published for external verification.
- requirements.txt: Declares project dependencies (pytest for testing).
- run_tests.sh    : Minimal test runner; execute `./run_tests.sh` to run all tests.
- __init__.py     : Included to mark directories as Python packages as per best practice.

Setup and Usage:
1. (Optional but recommended) Create a Python virtual environment.
2. Run `pip install -r requirements.txt` to install test dependencies.
3. Run `./run_tests.sh` to execute all original and public test cases.
