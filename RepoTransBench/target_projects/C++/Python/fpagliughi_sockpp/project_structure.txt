## Directory Purpose

- **src/**: (Optional, for code/mocks if any; not mandatory for test-only conversion)
- **tests/original/**: Translated C++ unit tests (one-to-one mapping of C++ files).
- **public_tests/**: Translated public test suite (from C++ auto/public tests).
- **requirements.txt**: Python requirements (pytest, etc).
- **run_tests.sh**: Simple shell script; runs all tests via `pytest`.
- **README.md**: Instructions, project overview.

## To run

1. `pip install -r requirements.txt`
2. `chmod +x run_tests.sh`
3. `./run_tests.sh`
