Directory Explanations:
- src/vmpilot/: Placeholder for production Python source files (empty or minimal here).
- tests/: Root tests package.
  - tests/original/: Python translations of all "original" private test cases.
- public_tests/: Python translations of all "public" test cases and their helpers.
- requirements.txt: Lists all required Python dependencies for running the tests.
- run_tests.sh: Runs all test suites (both original and public) using pytest.
- project_structure.txt: This file, listing & describing structure.
- README.md: Project setup and test execution instructions.

Setup/Testing Instructions:
1. Install dependencies: `pip install -r requirements.txt`
2. Run all tests:      `./run_tests.sh`
3. All original tests are under tests/original/, all public tests are in public_tests/.
