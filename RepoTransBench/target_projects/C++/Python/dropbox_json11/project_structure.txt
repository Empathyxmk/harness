### Directory Descriptions

- `src/` -- (Library source, or test target. Here: a json11 shim to enable running the test translations.)
- `tests/original/` -- Translated original (non-public) C++ tests
- `public_tests/` -- Translated public test set C++ tests
- `requirements.txt` -- Declares `pytest` dependency needed to run the suite
