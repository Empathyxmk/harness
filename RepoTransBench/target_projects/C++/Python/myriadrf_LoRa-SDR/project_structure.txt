# Directory Explanations:

# - tests/original/: Contains basic link/construction tests from the original suite (Google Test style), now in pytest format.
# - public_tests/: Contains the public Catch2-based test logic, translated to pytest. These are minimal, self-contained, and do not require LoRa-SDR internals to execute.
# - requirements.txt: Declares test environment dependencies.
# - run_tests.sh: Runs all test suites in both directories.
# - README.md: Provides project/test usage/structure instructions.

# How to use:

# 1. Install dependencies with: pip install -r requirements.txt
# 2. Run all tests with:        ./run_tests.sh

# Both test sets are discovered and run by pytest.
