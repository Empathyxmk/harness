README:
---
To run all tests:
    $ chmod +x run_tests.sh
    $ ./run_tests.sh

- All tests will be run (`pytest` discovers tests in both tests/ and public_tests/ by default).
- The requirements.txt covers all dependencies needed for running the tests.
- Both internal (original) and public tests are included and clearly separated.
- Dummy implementations for C++-side functions are included in the test files to ensure tests are runnable and logic is preserved exactly as per the original tests.
