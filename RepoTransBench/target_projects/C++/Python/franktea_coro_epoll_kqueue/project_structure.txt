Directory/Files Explained:
--------------------------

src/                - (Optional, not included in this translation) Place your actual source implementation here.
tests/original/     - Full translations of all original private test cases (from C++).
public_tests/       - Translations of all public test cases (from C++ logic-only public tests).
tests/__init__.py   - Python package marker for test discovery.
requirements.txt    - Lists all dependencies. Run `pip install -r requirements.txt`.
run_tests.sh        - Minimal script: runs all tests (public and original).
project_structure.txt- This file: describes structure and usage.

Setup/Testing Instructions:
--------------------------

1. Install dependencies:
   $ pip install -r requirements.txt

2. Run tests:
   $ ./run_tests.sh

   (You can also run `pytest tests/original` or `pytest public_tests` separately.)

All tests are self-contained and run with pytest (no source implementation needed for logic-only translation).
