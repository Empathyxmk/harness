**Directory & File Notes**

- `requirements.txt`: Lists required test dependencies (pytest).
- `run_tests.sh`: Single command to run ALL tests (original + public).
- `tests/original/`: Contains all tests that correspond to C++'s original private/internal tests.
- `public_tests/`: Contains tests corresponding to C++'s public tests.
- `__init__.py`: Makes directories Python packages for test discovery.
- `project_structure.txt`: Explains overall file structure and how to run tests.
