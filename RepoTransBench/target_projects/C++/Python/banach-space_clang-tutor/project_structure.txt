Directory Explanations:
- requirements.txt: Lists dependencies (pytest).
- run_tests.sh: One-click script, creates venv, installs dependencies, runs all tests.
- tests/: All original project tests, placed under tests/original/.
- public_tests/: Placeholder for public tests, to hold Python translations of public test scenarios.
- project_structure.txt: This overview document.

Instructions:
1. Run `chmod +x run_tests.sh` if not already executable.
2. Execute all tests using `./run_tests.sh`.
3. All test results will be printed to stdout by pytest.
