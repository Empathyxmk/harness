├── public_tests/
│   ├── __init__.py                 # Makes "public_tests" a Python module

Directory explanations:
- src/anitomy/: Minimal Python "mock" API so public/original tests can import and run.
- tests/original/: Direct translation of original private C++ tests (now as pytest Python tests).
- public_tests/: Direct translation of public C++ test cases, as pytest Python tests.
- requirements.txt: All required dependencies (pytest).
- run_tests.sh: Simple bash script to invoke all tests via pytest.
- project_structure.txt: This documentation file of the project layout.
