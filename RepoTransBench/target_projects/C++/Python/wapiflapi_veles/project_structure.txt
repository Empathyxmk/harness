NOTES:
------
1. The original C++ tests are nearly all "dummy" tests with `SUCCEED()` in Google Test (i.e. confirming build only).
   In Python, these are translated to simple presence tests (with `assert True`).
2. All meaningful logic is in the public_tests files, which actually implement and check swapEndian, reverseBytes, PNG signature, and CreateChunkDialog logic.
3. The C++ file test_veles.cc is not mapped to a Python test as it is an integration/CLI test dependent on C++ object model, file IO, and project internals not available in this translation scope. It will be included as a placeholder with explanation.
4. The run_tests.sh script runs both public and original tests using pytest.
5. All __init__.py files are to enable package discovery by pytest.
6. requirements.txt specifies pytest as the only dependency (feel free to add further requirements as needed).
