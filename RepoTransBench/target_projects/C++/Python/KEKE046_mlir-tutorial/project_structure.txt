Description of directories:
- requirements.txt: Lists dependencies for Python (pytest)
- run_tests.sh: One-click script to install deps+run all tests (original and public)
- README.md: Basic information, how to run, and test separation notes
- project_structure.txt: This file, showing organization
- tests/original/: All original tests, directly mimicking C++ logic (including subprocess checks)
- public_tests/: Public (alternative/smoke) tests per assignment
- All tests are auto-discoverable with pytest. No manual test runner required.

Setup & Running:
----------------
1. Run: `./run_tests.sh`
   → This installs dependencies and runs all tests (original and public).
2. To run only original or public tests:
   - `pytest tests/original/`       # Only original tests
   - `pytest public_tests/`         # Only public tests
   - `pytest`                       # All tests

Testing conventions:
--------------------
- All test files/functions use pytest standard naming.
- All subprocess calls mimic C++ `system()` exit code logic and check for non-crash (exit >= 0) or exit==0 as in original.
- Tests are self-contained, no placeholders or dummy stubs except where source logic was also dummy/no-logic.
- Directory __init__.py files for test module discovery.
