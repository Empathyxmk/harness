Description of Structure:
- public_tests/: Contains all public test cases translated from C++ (.cpp) to Python using pytest.
- requirements.txt: Lists Python dependencies (pytest needed for running tests).
- run_tests.sh: Minimal script to execute all Python tests (with pytest). Run with "./run_tests.sh".
- project_structure.txt: This documentation file.

Test Instructions:
1. Ensure Python 3.6+ is installed.
2. Install requirements: `pip install -r requirements.txt`
3. Run all tests: `./run_tests.sh`
