Directory explanations:

src/msckf_mono/:          Python source code modules (translated from C++ msckf_mono)
tests/original/:          Original test cases (direct analogues of the C++ tests)
public_tests/:            Public test cases (translated from C++/generated test cases)
requirements.txt:         Python dependencies for test frameworks (pytest)
run_tests.sh:             Simple script to run all tests (pytest for both test roots)
project_structure.txt:    This documentation of the project tree

Setup and testing instructions:

1. (Optional) Ensure python3 and pip are available.
2. Install dependencies (pytest) with: pip install -r requirements.txt
3. Run all tests via: ./run_tests.sh
4. Both original and public tests will be discovered and run by pytest.
