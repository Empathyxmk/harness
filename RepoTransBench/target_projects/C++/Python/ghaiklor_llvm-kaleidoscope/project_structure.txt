Directory explanations:

- `src/` — Room for implementation code (optional if only running pre-existing test logic)
- `tests/original/` — Full logic tests corresponding to original C++ test scenarios (all coverage and assertions)
- `public_tests/` — Public/educational tests only, translated from provided C++ public tests
- `requirements.txt` — Lists Python test dependencies (here: pytest)
- `run_tests.sh` — Runs all tests with a single command
- `README.md` — Describes repo structure and use
