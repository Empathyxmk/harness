# Directory Explanations
# - requirements.txt : Lists Python dependencies. Install using `pip install -r requirements.txt`
# - run_tests.sh     : Executable script. Run `./run_tests.sh` to execute all tests (requires pytest installed).
# - tests/original/  : All original logic/coverage test translations from C++ source.
# - public_tests/    : All public test case translations from C++ source public test files.
# - __init__.py      : (empty) Standard for Python test/package directories.
#
# Running All Tests:
#   $ pip install -r requirements.txt
#   $ chmod +x run_tests.sh
#   $ ./run_tests.sh
#
# All tests from both "tests/" and "public_tests/" will be discovered & executed by pytest.
#
# To run only original/coverage tests:
#   $ pytest tests/original/
#
# To run only public tests:
#   $ pytest public_tests/
