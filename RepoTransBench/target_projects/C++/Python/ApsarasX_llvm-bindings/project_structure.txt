Directory/Module Explanations
-----------------------------
tests/original/          Original test suite translated from C++ GTest test files.
public_tests/            Publicly released test suite (smaller variant, similar logic but different values).
requirements.txt         Declares project dependencies (pytest for running tests).
run_tests.sh             Simple script to run ALL tests in both suites at once.
project_structure.txt    This template/file.

Instructions
------------
1. Set up a Python environment (optionally: `python3 -m venv venv && source venv/bin/activate`)
2. Install dependencies:
    pip install -r requirements.txt
3. Run all tests:
    ./run_tests.sh
4. You should see all tests from both original and public suites passing.
