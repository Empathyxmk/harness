Directory Explanations:
- src/aes/:         Python implementation of AES logic (if reimplemented)
- tests/original/:  All tests translated from original C++ and Python test suite
- public_tests/:    Public test suite (open test scenarios)
- requirements.txt: Install Python dependencies (`pip install -r requirements.txt`)
- run_tests.sh:     One command to run all tests (`./run_tests.sh`)
- README.md:        Project info and instructions

Testing Instructions:
1. pip install -r requirements.txt
2. ./run_tests.sh

This will run both the original and public tests using pytest.
