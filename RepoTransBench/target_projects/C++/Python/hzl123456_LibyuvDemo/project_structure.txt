Description:
- `requirements.txt`: Declares Python dependencies (pytest)
- `run_tests.sh`: Executable script to run all tests with a single command
- `tests/original/`: Contains all tests translated from the original C++/Java codebase
- `public_tests/`: Contains all public tests translated from C++/Java public cases
- All tests are runnable by executing `./run_tests.sh` from project root

Setup & Usage:
1. Install dependencies: `pip install -r requirements.txt`
2. Run tests: `./run_tests.sh` (ensure it is executable: `chmod +x run_tests.sh`)

Each test file corresponds to an original C++/Java test file from the source layout as explained above.
