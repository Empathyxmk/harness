Description:
- src/: Contains (optionally) main algorithm implementations. May be empty for pure-test translation.
- tests/original/: Contains original translated tests from C++ ("_test.cpp" => "test_*.py"). One file per functionality.
- public_tests/: Contains public-facing test cases (translated).
- run_tests.sh: One-click script; runs "pytest tests/ public_tests/" for all tests.
- requirements.txt: Contains pytest test dependency.
- README.md: General documentation and project intro.

Instructions:
1. Install requirements: `pip install -r requirements.txt`
2. Run all tests (original + public): `./run_tests.sh`
   - Confirm all tests pass and output is as expected.
