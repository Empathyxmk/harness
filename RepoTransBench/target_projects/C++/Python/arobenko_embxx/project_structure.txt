# Directory explanations & usage:

# requirements.txt          - Lists test dependencies (pytest)
# run_tests.sh              - Make executable ("chmod +x run_tests.sh"). Runs all tests with pytest.
# tests/original/           - All original, full-coverage tests directly translated from C++
# public_tests/             - Public showcase/test files directly translated from C++, safe for external users

# Setup:
# 1. pip install -r requirements.txt
# 2. ./run_tests.sh

# Test organization:
# - Original full/coverage tests: tests/original/
# - Public/externally-facing tests: public_tests/
