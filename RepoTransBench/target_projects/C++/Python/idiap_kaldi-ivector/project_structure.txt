# Directory explanations and usage:

requirements.txt          : Lists dependencies needed to run tests (`pytest`)
run_tests.sh              : Run `chmod +x run_tests.sh` to make it executable; runs all tests with a single command
tests/original/           : Contains translations of all *original* C++ test files (preserved organization)
public_tests/             : Contains all *public* C++ test files, fully translated
test_* files              : Each file is a fully implemented Python test corresponding to the C++ version; logic preserved
__init__.py               : Allows `pytest` and Python to recognize the folders as packages; helps test discovery

# Setup and testing instructions

1. (Recommended) Create a virtualenv:
      python3 -m venv venv
      source venv/bin/activate
2. Install dependencies:
      pip install -r requirements.txt
3. Run all tests:
      ./run_tests.sh

All tests are self-contained; both original and public checks are run in a single pass.
