Description:
- requirements.txt: Lists Python dependencies. Just `pytest` for this project.
- run_tests.sh: One-click test execution. Installs dependencies and runs pytest over all tests.
- README.md: Usage, running, and project description.
- src/: (Optional) Python source files/modules needed for tests. For translation, only test files are included.
- tests/original/: All original (private) test translations from C++ GTest etc. to Python/pytest.
- tests/original/drivers/: Driver-layer test translations.
- public_tests/: Publicly visible Python tests (from CalculatorPublicTest.cpp).
- project_structure.txt: This file.

How to run tests:
-----------------
1. Make sure you have Python 3.x installed.
2. Make the test runner script executable: `chmod +x run_tests.sh`
3. Execute: `./run_tests.sh`
   - This installs dependencies (`pytest`) and runs ALL tests including both original and public suites.

Test organization:
- All original test cases are under `tests/original/`
- Public test cases (Calculator public API) are under `public_tests/`
- No source implementation of Calculator is translated, only test logic. For full test execution, provide equivalent src/ modules.

Notes:
- All test logic preserves the structure, assertions, edge cases, and expected results as in the original C++ repository.
- The test translation uses idiomatic Python/pytest constructs.
