# GreenLightning_gpu-font-rendering (Python Testing Adaptation)

This Python package is a translation of the original C++ test suite for GreenLightning_gpu-font-rendering. 
The tests mimic header inclusion checks and compilation succeeds for minimal C++ files.

## Directory Structure

- `requirements.txt`: Python testing dependencies (pytest).
- `run_tests.sh`: One-click test execution. Runs all tests.
- `tests/original/`: "Original" test conversion from C++, minimal existence checks.
- `public_tests/`: Public ("unobfuscated") test equivalents, as per supplied public tests.
- Each directory has an `__init__.py` for Python package recognition.
