Directories:
- public_tests/: Contains all public, non-solution-revealing tests to check API and basic contract without revealing implementation details.
- tests/original/: Contains all tests resembling the structure and coverage of the original C++ tests, meant for internal/complete correctness.
- Each test follows the pytest convention: test_*.py files, test_* functions.
- requirements.txt: Python dependencies, including pytest for all test execution.
- run_tests.sh: Simple script to run all tests with one command.
- README.md: Project summary and usage instructions.
- project_structure.txt: This file, showing structure and explanation.

Usage:
- Run `pip install -r requirements.txt` to install dependencies.
- Run `./run_tests.sh` to execute all tests (both public and original).
