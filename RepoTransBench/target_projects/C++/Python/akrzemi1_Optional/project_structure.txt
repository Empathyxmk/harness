# - public_tests/: All auto-generated public tests, clearly separated.
# - __init__.py: Required for package/module recognition.
# - project_structure.txt: Overview and instructions.
# - README.md: For instructions to set up and test (add more as needed).

# Setup:
#   pip install -r requirements.txt
# Testing:
#   chmod +x run_tests.sh
