README:
-------

- To install dependencies (pytest): `pip install -r requirements.txt`
- To run all tests: `./run_tests.sh`
- Original test results and coverage simulated by `tests/original/`
- Public/CI-facing tests are in `public_tests/`
- Executable SYCL-based tests are "simulated" in Python; if missing the native binaries, the related public tests will skip or print notice.

Notes:
- All test logic fully implemented; all asserts present as in the C++ sources.
- This layout is pytest-native (all test files and functions discovered by `pytest`).
- This translation does **not** include any SYCL or DPC++ functionality in Python; all tests are "host-only" logical/coverage equivalents.
