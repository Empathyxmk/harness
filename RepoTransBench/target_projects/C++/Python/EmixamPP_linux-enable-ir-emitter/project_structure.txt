Directory Explanations:
----------------------
public_tests/         - Contains all tests translated from provided public test cases (*.test.cpp) for external/public verification
tests/                - Contains all tests translated from original/internal test cases (*.test.cpp)
requirements.txt      - All Python dependencies (add your non-stdlib requirements here)
run_tests.sh          - Simple bash script for running all tests via pytest; run with `./run_tests.sh`
project_structure.txt - This description file

To set up and test:
-------------------
1. Install Python (3.7+ recommended)
2. Install dependencies:
      pip install -r requirements.txt
3. Run all tests:
      ./run_tests.sh

All tests in public_tests/ and tests/ will be discovered and executed by pytest.
You do not need to run separate commands for public vs original tests; all are run together.
