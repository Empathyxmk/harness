# Directory explanations:
#   requirements.txt      - Specify that pytest is required for running the tests
#   run_tests.sh          - Run all tests (original and public) using pytest
#   tests/original/       - Contains direct translations of "original" C++ test files
#   public_tests/         - Contains direct translations of "public" C++ test files
#   __init__.py           - Marks folders as Python packages for import/discovery
#
# Instructions:
#   1. (optional) Install dependencies: `pip install -r requirements.txt`
#   2. Make sure run_tests.sh is executable: `chmod +x run_tests.sh`
#   3. Run all tests: `./run_tests.sh`
#   All tests from both original and public sources will execute and report via pytest.
