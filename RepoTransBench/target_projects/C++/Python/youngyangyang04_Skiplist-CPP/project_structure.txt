# Directory/Files Legend:

src/:              Core skiplist implementation.
tests/original/:   Original (private/internal) C++ test suite translated to Python.
public_tests/:     Public C++ test suite translated to Python.
requirements.txt:  PyPI dependencies (pytest for test discovery).
run_tests.sh:      Shell script to execute *all* tests with one click.
README.md:         Documentation, quickstart, and usage instructions.

How to run:
1. pip install -r requirements.txt
2. ./run_tests.sh

All tests (original & public) will execute together, with success/failure reported by pytest.
