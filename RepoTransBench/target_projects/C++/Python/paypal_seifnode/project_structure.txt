Directory explanations and setup/test instructions:

- requirements.txt: Specifies Python testing dependencies (pytest).
- run_tests.sh: Executable script. Runs all tests with one-click: `./run_tests.sh`
    * Installs dependencies and runs all tests (original and public).
- tests/original/: Contains minimal original C++ tests (header-compile checks).
- tests/: Contains complete translations of all JS logic tests for aesxor, rng, ecc, sha3.
- public_tests/: Public version of header checks, for public testing purposes.
- project_structure.txt: Structure documentation.

Instructions:
1. Ensure you have Python 3.7+ and pip.
2. Run `chmod +x run_tests.sh` if necessary.
3. Run all tests and auto-install dependencies:
       ./run_tests.sh

All tests (original and public) are run with pytest.
