# Usage Instructions
1. Install dependencies: pip install -r requirements.txt
2. Run all tests:      ./run_tests.sh
   (or simply:         pytest)

# Notes
- All original tests are under tests/original/
- All public tests are under public_tests/
- The tests fully simulate the C++ type trait behavior using Python types and custom wrappers.
