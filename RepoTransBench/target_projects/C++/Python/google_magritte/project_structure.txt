Directory Explanations:

requirements.txt       - Lists all required Python dependencies (pytest for testing).
run_tests.sh           - Executable shell script to run all tests via pytest.
project_structure.txt  - This file, describing the folder layout and purpose.

public_tests/          - Contains Python translations of "public" C++ tests (as guided by public_test_summary.json). Use `pytest public_tests/` to run only public tests.
tests/original/        - Contains translated "original" C++ tests. Use `pytest tests/original/` to run only original tests.
tests/                 - Root tests directory. Running `pytest` at project root finds everything.

How to Set Up & Run:

1. Install dependencies
   $ pip install -r requirements.txt

2. Run all tests (one-click)
   $ ./run_tests.sh

3. Run just public tests:
   $ pytest public_tests/

4. Run just original/functional tests:
   $ pytest tests/original/
