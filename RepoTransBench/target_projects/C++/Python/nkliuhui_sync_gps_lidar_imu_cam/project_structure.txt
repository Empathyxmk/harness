├── public_tests/

│   ├── test_gps_resolve_public.py    # Public tests for GPS resolve edge cases
│   └── test_calibration_public.py    # Public tests for velodyne calibration file logic

Instructions:
-------------
1. Install dependencies:
   pip install -r requirements.txt
2. To run all tests:
   ./run_tests.sh

- src/ contains Python implementations of all logic needed by the test cases.
- tests/original/ contains translations of the C++ original tests.
- public_tests/ contains translations of the C++ public test cases.
- Each test file is fully implemented and runs independently with pytest.
- All code and test logic is self-contained and follows Python standards.
