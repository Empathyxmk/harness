Directory Explanations:
- requirements.txt: Lists Python dependencies required to run tests (here, pytest).
- run_tests.sh: One-click script to run all Python tests using pytest.
- README.md: Documentation about the project, setup, and running tests.
- project_structure.txt: This file, documents the project structure.
- tests/: Test suite directory.
    - original/: Translated versions of original C++ tests with 1-1 logic.
- public_tests/: Translated public test cases, for public user validation.
- __init__.py: In both test dirs, to ensure Python recognizes them as packages.
