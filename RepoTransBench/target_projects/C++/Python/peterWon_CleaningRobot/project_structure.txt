Directory/Files Purpose:
- src/: Main source code modules and interface/shim "ROS" message mocks
- tests/original/: Original private test cases (from C++ tests named without 'public')
- public_tests/: Public test cases (from *_public.cpp files)
- requirements.txt: Python dependencies (pytest)
- run_tests.sh: Runs both original and public tests using pytest
- project_structure.txt: This file - structure map & explanations
- README.md: Short project usage/readme (create as needed)

Setup & Testing Instructions:
1. Install dependencies: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`
   (Or run individually: `pytest tests/`, `pytest public_tests/`)
