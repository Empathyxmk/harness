Directory & File Explanations:
  src/                 - Contains Python implementations or stubs for tested functions.
  tests/original/      - Original ("private") Matlab tests, fully translated to Python.
  public_tests/        - Public/assignment-oriented test cases, fully translated.
  requirements.txt     - Lists all required Python packages/dependencies.
  run_tests.sh         - Single-command test runner for all tests.
  project_structure.txt- Overview/explanation of the project layout and each area's purpose.

Test Execution Instructions:
1. (Optional) Create a virtualenv and activate it.
2. Run `pip install -r requirements.txt` to install dependencies.
3. Execute all tests with `./run_tests.sh`
   - This script will run both original and public tests using pytest; output will show all results.
