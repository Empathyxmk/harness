EXPLANATION:
- src/: All main implementation files for core functions (translated from MATLAB).
- tests/: Full set of original (non-public) Python test cases for core/library code.
- public_tests/: Publicly released (usually simplified or restricted) test cases only.
- requirements.txt: All dependencies needed for testing/running code.
- run_tests.sh: One-click test runner, runs ALL tests (original + public).
- README.md: Documentation for the repository.
- project_structure.txt: Tree view and explanation of repo.

INSTRUCTIONS:
1. Install dependencies: 
   pip install -r requirements.txt

2. Run all tests:
   ./run_tests.sh
   # or directly with: pytest

3. Structure intentionally mirrors MATLAB separation (original/public tests).
