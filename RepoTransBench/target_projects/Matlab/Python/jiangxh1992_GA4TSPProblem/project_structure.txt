Directories:
- src/:        Place for all source Python modules (logic to be tested).
- tests/original/:  All original translated test cases from Matlab.
- public_tests/:    All public test cases, using public test data scenarios.
- run_tests.sh:     Runs pytest, automatically discovers and runs all tests from both test directories.
- requirements.txt: Declares required Python dependencies (pytest, numpy, pillow).
