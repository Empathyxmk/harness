Structure Explanation:
- `src/`: Core implementation of neural network, including generate_neural_net, apply_neural_net, and both training methods.
- `tests/`: Original tests translated from Matlab to Python using pytest, covering all features and edge cases.
- `public_tests/`: Public sample tests, separated for transparency and as extra examples.
- `requirements.txt`: Required pip packages for running project and tests.
- `run_tests.sh`: Bash script to execute all tests with one command.
- `README.md`: Usage instructions and documentation.

How to run tests:
1. Install Python 3.8+ and pip.
2. Run `pip install -r requirements.txt`
3. Execute `./run_tests.sh` from the project root to run all tests.
