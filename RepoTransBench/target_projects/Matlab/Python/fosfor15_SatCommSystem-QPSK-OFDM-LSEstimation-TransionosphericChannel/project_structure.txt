Directory Details:
------------------
src/
    Contains the main implementation source files. Each .py file corresponds to a Matlab script/function.
    Functions MUST be implemented for the tests to work (see docstrings for expected signatures).
tests/original/
    Original Matlab tests – simply check the respective script runs without failing (sanity/coverage/trigger).
    Do NOT test with varying parameters.
public_tests/
    Public behavioral/parameterized tests – check specific input/output requirements and functional correctness with various arguments.

How to Run:
-----------
1. Install dependencies:       pip install -r requirements.txt
2. Run all tests:              ./run_tests.sh

To run only original tests:    pytest tests/original/
To run only public tests:      pytest public_tests/

All test logic is complete and ready for test implementation work on the src/ modules!
