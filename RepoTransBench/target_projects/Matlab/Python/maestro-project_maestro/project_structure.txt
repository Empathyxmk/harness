Directory Explanations:
- requirements.txt: Python dependencies for running tests
- run_tests.sh: One-click shell script to run all tests using pytest
- project_structure.txt: Project structure and guide (this file)
- tests/original/: Contains original (private) test translations from Matlab to Python
- public_tests/: Contains public test translations from Matlab to Python
- data/: Contains .m data and mapping files (used in smoke tests, not translated)
- validation/: Contains network config files referenced for syntax tests (not translated)

Setup & Testing Instructions:
1. Create a Python (>=3.7) virtual environment (optional).
2. Install dependencies: `pip install -r requirements.txt`
3. To run **all tests** (original + public): `./run_tests.sh`
   - This will use pytest to discover and run all test files.
4. To run just original or public tests, use:
   - `pytest tests/original/` for original tests,
   - `pytest public_tests/` for public tests.

All test code is fully native Python and does not require Matlab or Octave.
