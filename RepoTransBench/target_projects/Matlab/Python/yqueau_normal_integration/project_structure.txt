Explanations:
- requirements.txt:        Python dependencies (NumPy, pytest).
- run_tests.sh:            Run all tests (original & public) with one command.
- README.md:               Setup, usage, and test running instructions.
- src/normal_integration:  Main source code package (placeholder functions here for test harness).
- tests/:                  Original (internal) converted test suite.
- public_tests/:           Public test suite (translated and adapted from Matlab public tests).

Setup & Testing Instructions:
1. Install dependencies:      pip install -r requirements.txt
2. Run all tests:             ./run_tests.sh
3. Tests will be discovered and run via pytest for both original and public_tests
