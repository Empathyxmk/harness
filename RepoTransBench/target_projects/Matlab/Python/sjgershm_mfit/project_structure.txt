Explanations:
-------------------
src/             - All core source modules translated from Matlab (.m) to Python (.py)
tests/original/  - Original (private/internal) test cases (fully translated)
public_tests/    - Public (student/consumable) test cases (fully translated)
requirements.txt - Lists dependencies for pip install
run_tests.sh     - Simple bash script, just run `./run_tests.sh` after installing requirements
README.md        - Usage, install, and test docs

Test discovery:
- All tests in tests/original/ and public_tests/ are found and run automatically by pytest.

Setup instructions:
1. python3 -m venv venv && source venv/bin/activate
2. pip install -r requirements.txt
3. ./run_tests.sh

You must implement logdet, logsumexp, mfit_opts, mfit_summary (and any used helpers) in src/ for the tests to pass.
