Directory explanations:
- requirements.txt:         Python dependencies (install via pip install -r requirements.txt)
- run_tests.sh:             One-click script to run all tests (chmod +x run_tests.sh; then ./run_tests.sh)
- src/:                     (Placeholder) for source logic to be ported/implemented in Python
- tests/original/:          All original (internal) test cases translated from Matlab
- public_tests/:            All public translated test cases for users
- README.md:                Placeholder documentation
- project_structure.txt:    This file

To run all tests:
$ pip install -r requirements.txt
$ chmod +x run_tests.sh
$ ./run_tests.sh
