Directory explanation:
- src/: Main source module containing all core algorithm implementations.
- tests/: Original test cases (derived from Matlab's tests/) using pytest.
- public_tests/: Public-facing test cases (derived from Matlab's public_tests/) using pytest.
- requirements.txt: Dependencies (numpy, scipy, pytest, matplotlib for colormap).
- run_tests.sh: Run all tests (both tests/ and public_tests/) with one-click.
- README.md: Documentation and setup instructions.

Setup & Testing Instructions:
1. pip install -r requirements.txt
2. ./run_tests.sh
All tests will be discovered and executed via pytest.
