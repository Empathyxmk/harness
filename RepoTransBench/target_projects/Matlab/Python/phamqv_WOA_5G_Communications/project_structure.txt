Instructions:
- Run "pip install -r requirements.txt" to install dependencies.
- Run "./run_tests.sh" to execute all tests (original + public).
- Source code is in "src/phamqv_woa_5g_communications/".
- Original/private tests are in "tests/original/".
- Public/visible tests are in "public_tests/".
