Directory Descriptions:
- src/lips/: All main Python implementations of the lips functions to be tested.
- src/cursorloc/: Contains implementation of cursorLocation if required for modularity.
- tests/original/: Contains translations of original (non-public) Matlab test files, using pytest.
- public_tests/: Contains translations of public test files, as required for open/public validation of the library. Also uses pytest.
- requirements.txt: Python dependencies (pytest, numpy).
- run_tests.sh: Minimal bash script to run all tests.
- project_structure.txt: This documentation file.

Test/Run Instructions:
1. Install dependencies:
    pip install -r requirements.txt
2. Run all tests (original and public):
    ./run_tests.sh
