# Directory Explanations:
src/ukfmanifold/        - Place for the main library code ported from Matlab. (Stubs or real code, as needed.)
tests/original/         - Python translations of original (private) Matlab tests. (pytest-based.)
public_tests/           - Python translations of public Matlab tests. (pytest-based.)
requirements.txt        - All dependencies needed to run tests (install via pip).
run_tests.sh            - One-click test runner, launches all tests.
README.md               - Project documentation, usage.
project_structure.txt   - This structure and explanation.

# To install and run tests:
pip install -r requirements.txt
./run_tests.sh
