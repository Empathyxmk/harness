Directory explanations:
- src/combining/: Contains Python implementations of combining functions needed for public tests.
- tests/original/: Contains original tests (from Matlab tests/unit), translated to pytest.
- public_tests/: Contains all public tests, directly translated from Matlab public test files, using pytest.
- requirements.txt: List of dependencies for Python environment (install via pip).
- run_tests.sh: One-click script to run all tests (sets -e for safety, runs original and public tests).
- project_structure.txt: Project structure and testing instructions.

Setup & Testing instructions:
1. Install Python 3.x.
2. (Optional, recommended) Create a virtual environment and activate it.
3. Install dependencies: `pip install -r requirements.txt`
4. Run all tests: `chmod +x run_tests.sh && ./run_tests.sh`
5. Tests in both tests/original and public_tests will run under pytest.
