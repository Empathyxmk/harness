├── go.mod                       # Go module definition

├── tests/

│       ├── app_test.go
│       ├── app_module_test.go

Directory explanations:
- go.mod                : Declares Go module and Go version. No external dependencies required beyond stdlib.
- run_tests.sh          : Runs all tests in both tests/original/ and public_tests/ using `go test ./...`.
- tests/original/       : Translated "original" test cases from Java source.
- public_tests/         : Translated "public" test cases from Java public test files.
- project_structure.txt : This project structure and instructions documentation.

Setup and testing instructions:
1. Ensure [Go](https://golang.org/dl/) (version 1.20+) is installed.
2. From the project root, run: `chmod +x run_tests.sh`
3. Execute all tests with: `./run_tests.sh`
