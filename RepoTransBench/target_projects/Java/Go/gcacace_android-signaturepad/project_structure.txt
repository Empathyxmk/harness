# Directory explanations:
# - tests/original/: Contains complete translations of Java original test files. Helper structs used for self-containment.
# - public_tests/: Public test cases, logic/coverage is a translation of corresponding *PublicTest.java files.
# - go.mod: Go module declaration, required for Go project.
# - run_tests.sh: One-click test execution, runs all tests recursively (unit, public, etc.)

# Setup instructions:
# 1. Install Go (version 1.20 or later)
# 2. Clone/download the repository
# 3. To run all tests, execute:
#      ./run_tests.sh

# No additional dependencies are required (all logic is self-contained).
