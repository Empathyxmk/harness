Directory Descriptions:
- `greeter.go`: Main Greeter implementation ("Hello, <name>!")
- `tests/original/`: Contains the translated original (private) test cases.
- `public_tests/`: Contains the translated public (student-visible) test cases.
- `run_tests.sh`: Bash script for one-click test execution.
- `go.mod`: Declares module and go version.
- `README.md`: How to set up and use the project.

How to run:
- Make sure Go is installed.
- Execute `chmod +x run_tests.sh && ./run_tests.sh` to run all tests.
