Directory Explanations:
- go.mod: Declares project dependencies and Go module.
- run_tests.sh: Runs every test in the project with a single command.
- project_structure.txt: Explains project layout and setup.
- tests/original/: Contains translations of original (private) Java test cases in Go.
- public_tests/: Contains public test cases (translated from Java) for public test verification.

Setup and Testing Instructions:
1. Install Go (version 1.18+ recommended).
2. Run 'go mod tidy' to download dependencies (testify).
3. To run all tests, use:
   ./run_tests.sh
   or
   go test ./...

Both public and original tests will be detected and run automatically by Go tooling.
