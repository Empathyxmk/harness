**Descriptions:**
- `tests/original/`: Contains Go translations of all "original" test cases
- `public_tests/`: Contains Go translations of all public tests
- `testutil.go`: Helper utilities and mock simulating Java/Android/mockito behaviors
- `run_tests.sh`: One-click script to run all Go tests (using `go test ./...`)
- `go.mod`: Go module for dependency management

**Instructions:**
1. Run `go mod download` to fetch dependencies (if not already).
2. Use `./run_tests.sh` to execute all tests at once.
