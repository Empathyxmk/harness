DIRECTORY EXPLANATIONS:
- tests/original/: Contains original tests translated from Java. Structure and logic preserved.
- public_tests/: Contains public tests translated and slightly altered per public test logic.
- run_tests.sh: One-click script for running all unit tests (`go test ./...`).
- go.mod: Go module file.

USAGE:
1. Ensure Go (>=1.20) is installed and in your PATH.
2. To run ALL tests (original & public): `./run_tests.sh`
   - Or directly via: `go test ./...`
3. Tests are organized following Go best practices; each test file is a `_test.go` and tests are `Test...` functions.

No additional build configuration is necessary for standard Go tests.
