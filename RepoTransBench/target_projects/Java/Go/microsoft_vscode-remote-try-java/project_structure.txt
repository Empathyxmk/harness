# Structure Explanation

go.mod:
    - Go Module definition (use your VCS path if published)

    - Implements the functions under test

tests/original/app_test.go:
    - Translated original test suite. Imports `app` code using Go module path.

public_tests/app_public_test.go:
    - Translated public test suite. Imports `app` code using Go module path.

run_tests.sh:
    - Minimal script to execute all tests with one command: `./run_tests.sh`
