Directory explanations:
- tests/: All original test translations from the Java project. Kept under 'original/'.
    - testutil.go: Minimal test double/stub for LoadingButton (since no prod code ported).
- public_tests/: All public test translations. Kept separate for clarity and one-to-one mapping.
    - testutil.go: Same as in tests/ but for public test imports/namespacing.
- run_tests.sh: Runs both tests and public_tests with a single command.

Setup & Usage:
1. Install Go 1.20+.
2. From this directory: `chmod +x run_tests.sh && ./run_tests.sh`
   - Executes all tests in tests/ and public_tests/ automatically.

Test package structure matches the original Java project separation of original and public tests.
