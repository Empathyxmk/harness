Directory Explanations:
- `tests/original/`: All original (private) test cases, named *_test.go per Go convention.
- `public_tests/`: All public-facing tests, as derived from the source.
- `testutil.go`/`testutil_public.go`: Minimal stubs/mocks to provide test isolation for types/functions (since production code is not provided).
- `run_tests.sh`: Script to run all tests recursively.

How to Run:
    ./run_tests.sh

No app/business logic is included: only the test harness and mocks to exercise the original tests.
