File/Directory explanations:
- `vasco/`: Contains minimal implementations and type definitions (in Go) for the project, providing just enough API/fields to make all tests build and work according to logic. No functional dataflow analysis is re-implemented.
- `tests/original/`: All converted tests from Java's `src/test/java/vasco/` hierarchy, grouped to match original logic and paths.
- `public_tests/`: All public tests from `src/test/java/vasco/*PublicTest.java`.
- `run_tests.sh`: One-click Go test runner (recurses all test dirs).
- `go.mod`: Module file for Go dependencies.
