├── contacts/                             # (expected) Go implementation for contacts library
│   ├── (Address.go, Email.go, ...)       # Go implementation code (not included - to be coded)
└── README.md                             # Project info, usage, and instructions

Directory explanations:
- go.mod:         Go module/dependency config, required for Go builds/tests.
- run_tests.sh:   Simple test script (chmod +x, run by ./run_tests.sh).
- tests/original: Go test translation of all original (non-public) Java test cases.
- public_tests:   Go test translation of all public Java test cases.
- contacts/:      Your Go code package (types, logic, etc.), importable by test files.
- README.md:      Documentation and usage instructions for the Go implementation.

Test running:
- To run all tests: `./run_tests.sh` (runs both original and public tests).
- All source and test code lives in idiomatic Go project subdirectories.

Setup:
- Ensure you have Go installed.
- Place implementation code in `contacts/`. Tests expect `contacts` to be importable as a Go module.
