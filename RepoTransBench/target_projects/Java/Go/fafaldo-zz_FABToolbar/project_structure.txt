# Directory Explanations:

go.mod               - Go module config (dependencies managed here)
run_tests.sh         - One-click script to execute ALL unit & public tests
tests/original/      - Translations of all original (internal/private) Java test logic
public_tests/        - Translations of all public (publicly generated or shared) Java test logic

# Setup and Testing Instructions

1. Make sure you have Go installed (version >= 1.20).
2. Fetch dependencies and run all tests:
    chmod +x run_tests.sh
    ./run_tests.sh

This will run ALL tests (original and public) and print results.
For more verbose output, change run_tests.sh to: go test -v ./...
