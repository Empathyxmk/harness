Directory and File Purpose:

- go.mod: Basic Go module setup, needed for dependency management.
- run_tests.sh: Simple executable shell script to run all Go tests at once.
- tests/original/: Holds all tests translated from original Java test suite. Mirrors precise logic, ensures private/internal expectations.
- public_tests/: Holds all tests translated from public Java test suite. May have assertions/logic suitable for public code assessment/coverage.
- project_structure.txt: This document for reference.

Setup/Testing Instructions:

1. Install Go (https://golang.org/doc/install) if not present.
2. (Optional) Run `go mod tidy` if dependencies added to go.mod.
3. Run tests: `./run_tests.sh`
   - This script will execute all Go tests found in tests/ and public_tests/ recursively.
