**Legend:**

- `tests/original/`: Fully-implemented Go tests for all original test scenarios from the Java codebase.
- `public_tests/`  : Fully-implemented Go tests for all public test scenarios, as per public_test_summary.json.

**How to run**:  
Execute `./run_tests.sh` from the project root; it will discover and run all Go test files recursively.

**Adding code**:  
When translating Nexmark logic, add Go code (types, methods, utilities) in `src/` and import into tests as needed.

**Test dependencies and helper function stubs**  
If some dependencies are missing and require minimal implementation for tests to build/run, provide minimalistic stubs in `src/` or local test files (`_test.go`).
