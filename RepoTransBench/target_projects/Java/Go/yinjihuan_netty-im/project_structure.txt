Directory Explanations:
- tests/original/: Go translation of the project's original/internal Java test suite.
- public_tests/: Go translation of the *public* Java test suite.
- tests/testutil.go: Utilities, mocks, and stubs required for the tests to compile/run.
- go.mod: Module file with dependencies (use 'go mod tidy' to manage dependencies).
- run_tests.sh: Runs all tests recursively (from project root) with `go test ./...`.
