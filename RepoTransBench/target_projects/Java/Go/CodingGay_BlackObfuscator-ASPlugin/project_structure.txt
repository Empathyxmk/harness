# Directory explanations:
# - tests/original: All translated "original" test cases from the Java source (mirrors coverage, edge cases, and input/output of Java tests)
# - public_tests: All translated "public" test cases, covering distinct scenarios/inputs as per the original public test suite
# - testutil.go: Intended for test helpers or shared code, kept in original for compatibility/future expansion
# - go.mod: Sets Go module, makes 'go test' work across all folders
# - run_tests.sh: Minimal script to run all test cases with one command

# Setup and testing instructions:
# 1. Install Go 1.18 or newer.
# 2. From the project root, run:
#       chmod +x run_tests.sh
#       ./run_tests.sh
# 3. All tests in both 'tests/original' and 'public_tests' will be executed.
# 4. There are no external dependencies.
