# Directory explanations:
#   tests/original/      : Private/original test cases fully emulating the original Java test logic.
#   tests/test_resources/: Supplemental resources (XML, etc) used for testing.
#   public_tests/        : Public test cases derived from public Java tests.
#   go.mod               : Go module file, manages dependencies.
#   run_tests.sh         : One-click shell script to run all Go tests.
#
# To run all tests:
#   1. Install Go (https://golang.org/dl/)
#   2. Ensure you are in the repo root.
#   3. Make the script executable: chmod +x run_tests.sh
#   4. Execute: ./run_tests.sh
#
# This will discover and run all tests in both tests/original/ and public_tests/.
