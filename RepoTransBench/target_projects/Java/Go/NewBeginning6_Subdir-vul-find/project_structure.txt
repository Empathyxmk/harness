Directory Explanations:
- org/example/      : Go implementation of all core app logic and mock equivalents for testing
- tests/original/   : Translated original tests from Java (full coverage)
- public_tests/     : Translated public test cases (safe for publication)
- tests/testutil.go : Shared helper funcs for tests (expand if needed)
- run_tests.sh      : One-click script: EXECUTE ALL TESTS via 'go test ./...'

Setup & Testing Instructions:
1. Install Go (https://golang.org/doc/install)
2. In project root, run: `go mod tidy` (if needed)
3. To execute all tests, simply run:
   ./run_tests.sh
or
   go test ./...
