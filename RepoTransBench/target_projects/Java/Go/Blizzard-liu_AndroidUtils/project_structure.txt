Structure Explanation
---------------------
- `tests/original/` contains Go test files corresponding to internal/original Java tests.
- `public_tests/` contains Go test files for all public tests (from *_PublicTest.java).
- `go.mod` manages module requirements, such as testify (optional, but included for Go best practice).
- `run_tests.sh` is a single script for executing all tests.
- All test code uses idiomatic Go and the `testing` package.

How to Run:
-----------
1. Install Go if not already installed.
2. (Optional) run `go mod tidy` to ensure dependencies are downloaded.
3. Run all tests with `./run_tests.sh`
