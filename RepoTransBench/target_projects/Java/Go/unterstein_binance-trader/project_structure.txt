# Directory explanations:
# tests/original/      - Contains the original Java test translations covering connection, trade, and main launch logic.
# public_tests/        - Contains the public test case translations as required for open testing and challenge validation.
# run_tests.sh         - Run all tests with: ./run_tests.sh
# go.mod               - Go module management file, no extra dependencies required for testing.
# testutil.go          - Stubs for possible future utility/test helpers (currently not required).
# To run all tests:    - From root, run: chmod +x run_tests.sh && ./run_tests.sh
