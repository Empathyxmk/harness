- `tests/testutil.go`: Mocks and helpers needed for all (original/public) tests
- `public_tests/`: Go translations of Java public test suite, logic mirrors public variants
- `main.go`, `module.go`: Place actual core logic here (`Blacklist`, `Crawler`, ...)
- `go.mod`: Manages Go module/dependency versions (`testify` for assertions in tests)
- `run_tests.sh`: One-click script to run all tests with `go test ./...`
