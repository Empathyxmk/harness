Directory Explanations:
- go.mod: Declares Go module and dependency info.
- run_tests.sh: Run all tests via `go test ./...`
- tests/original/: Contains Go translations of all original (private) test cases from Java source.
- public_tests/: Contains Go translations of all public-facing test cases.
- project_structure.txt: This document.

Testing Instructions:
- Install Go 1.20+.
- Run `chmod +x run_tests.sh` (if not already executable).
- Execute all tests: `./run_tests.sh`
