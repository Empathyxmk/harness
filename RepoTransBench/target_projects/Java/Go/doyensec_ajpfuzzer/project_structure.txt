# Directory explanations:
# - ajpfuzzer/: All production (translation of src/main/java) Go code.
# - tests/original/: Original internal test cases, used for internal/test suite coverage.
# - public_tests/: Public test set. Each test file matches a *PublicTest.java in source.
# - go.mod: Go module requirements.
# - run_tests.sh: One-click test execution. Runs all tests in all packages.
# - project_structure.txt: Overview of project file structure (this file).

# Setup and running tests:
#   1. Install Go (>= 1.20)
#   2. Run `./run_tests.sh`
