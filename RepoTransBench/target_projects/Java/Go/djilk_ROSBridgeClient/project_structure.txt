Directory explanations:
- calculator.go: main calculator implementation (migrated based on usage in tests)
- main.go: optional application entrypoint (not required for tests)
- tests/original: contains all original tests, exactly matching Java `CalculatorTest.java` logic and data
- public_tests: contains all public test cases, exactly matching Java `CalculatorPublicTest.java` logic and scenarios
- run_tests.sh: simple runner that executes all tests using `go test ./...`
- go.mod: module/dependency configuration for Go
