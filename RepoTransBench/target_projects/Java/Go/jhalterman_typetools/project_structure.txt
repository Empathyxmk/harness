**Directory/Files explanations**:
- `typetools/`: Core logic (must be implemented or stubbed for tests to run)
- `tests/original/`: Original comprehensive tests, translated from Java, for general coverage
- `public_tests/`: Public subset of tests, matching public/exam requirements
- `run_tests.sh`: run all tests with one command
- `go.mod`: go modules/deps
- `README.md`: User guide and documentation

**How to run tests**:
- Just run: `./run_tests.sh`
