Directories:
- tests/original/      : All tests translated from original Java source (private/internal).
- public_tests/        : All public tests, from Java source with 'PublicTest' suffix.
- tests/testutil.go    : Shared helpers (could be empty if unused).
- run_tests.sh         : Minimal script to execute all tests.

Top-level Go files are placeholders for the ported application and can be extended/replaced.

To run all tests: `./run_tests.sh`
