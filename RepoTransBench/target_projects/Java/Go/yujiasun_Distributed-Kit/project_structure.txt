Explanation:

- `tests/original/`: Contains translations of all internal/original Java test cases. Each Go file corresponds to a Java test class.
- `public_tests/`: Contains translations of all Java public test cases. Those maintain their public visibility.
- `tests/testutil.go`: Provides shared helpers and mocks for use in both types of tests (especially for mocking Redis/ZK).
- `run_tests.sh`: The recommended entry point for running all tests.
- `go.mod`: Sets up dependencies - Go modules are used, and testify is included for rich assertions.
- `README.md`: Overview, instructions, and usage notes.
- `project_structure.txt`: This documentation.

To add new tests, follow Go's convention:
- Name test files `*_test.go`
- Use `TestXxx` functions
- Place originals under `tests/original/`, publics under `public_tests/`
