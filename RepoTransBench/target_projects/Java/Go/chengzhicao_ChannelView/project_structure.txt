## Directory Explanations

- `tests/original/` - All unit and logic tests ported from Java's original test sources.
- `public_tests/`   - Ported public/acceptance tests as defined by public_test_summary.json.
- `go.mod`          - Module dependencies for Go.
- `run_tests.sh`    - One-click script for running all tests (executable).
- `README.md`       - Overview and test instructions.

## Setup & Testing

1. [Install Go 1.21+](https://golang.org/dl/)
2. Run: `./run_tests.sh`
