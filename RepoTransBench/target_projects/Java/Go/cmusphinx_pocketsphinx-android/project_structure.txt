Directory structure:
- go.mod: Go module definition.
- tests/original/: All tests translated from original Java test files. Each *_test.go file corresponds to a Java test class.
- public_tests/: All tests translated from public Java test files. Each *_public_test.go corresponds to Java *PublicTest.java.
- run_tests.sh: Simple bash script running all Go tests. Use it with `./run_tests.sh`.
- project_structure.txt: This document, describes structure and usage.

To run tests:
1. Make sure you have Go installed.
2. Run: ./run_tests.sh
All tests (both original and public) will execute.
