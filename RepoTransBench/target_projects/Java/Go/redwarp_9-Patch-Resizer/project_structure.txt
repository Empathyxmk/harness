Directory Overview:
- tests/original/: All original Java JUnit test translations, mapped to Go's `testing` package.
- public_tests/: Public (open) test cases, mapped from *PublicTest.java files in Java.
- go.mod: Go module/dependency file.
- run_tests.sh: Minimal shell script to execute all tests across the repo.

How to run tests:
1. Ensure you have Go 1.20 or later and `github.com/stretchr/testify` installed (done automatically via `go mod tidy`).
2. Run `./run_tests.sh` from project root.
3. Both `tests/original/` and `public_tests/` suites will be discovered and run by Go's test tooling.

Test logic:
- All file/image tests create and clean up temporary files.
- All error and edge cases from the Java tests are implemented in Go.
- All original and public test separation is preserved.
