Directory explanations:
- tests/original/: Original (internal/private) test cases, as directly ported from the Java suite.
- public_tests/: Public/candidate-facing tests as directly ported from the Java suite.
- tests/testutil.go: Place for helper functions to reduce code duplication across both suites.
- go.mod: Declares the module name and dependencies.
- run_tests.sh: Shell script to execute all tests with a single command using Go's built-in test runner.

Run all tests with: `./run_tests.sh`
