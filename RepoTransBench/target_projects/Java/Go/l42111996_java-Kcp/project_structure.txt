# Directory explanations:
#  - go.mod: specifies Go module (dependencies) for project; run 'go mod tidy' to update
#  - tests/original/: all tests directly translated from original Java tests
#  - public_tests/: all translated public test cases
#  - run_tests.sh: run with './run_tests.sh' to execute all tests in every package
#  - project_structure.txt: this document, describes the structure

# To set up and run:
# 1. Ensure you have Go installed.
# 2. Run `go mod tidy` to fetch dependencies (if needed).
# 3. Execute all tests: `./run_tests.sh`
