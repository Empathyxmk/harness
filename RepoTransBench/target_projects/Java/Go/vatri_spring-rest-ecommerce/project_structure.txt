**Directory explanations:**
- `public_tests/`      - Publicly visible test cases (student-accessible)
- `tests/original/`    - All full/private/teacher/original tests
- `tests/testutil.go`  - Contains test-only stubs/mocks for interfaces, helpers, custom error types etc.
- `main.go`, `module.go` - Not implemented/empty, placeholders
- `go.mod`             - Specifies Go module and needed dependencies (`testify`, `gomock`)
- `run_tests.sh`       - Simple script to run all tests

#### To run ALL tests (original + public):

    $ ./run_tests.sh

#### To run only public tests:

    $ go test ./public_tests/...

#### To run only original tests:

    $ go test ./tests/original/...
