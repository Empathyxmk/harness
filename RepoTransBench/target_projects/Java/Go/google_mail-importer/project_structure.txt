Directories:
- `tests/original/` contains all original non-public (full) tests from Java.
- `public_tests/` contains the public test suite.
- All tests use Go's standard testing framework (and testify/mock when needed).

Setup/Run:
- Install Go 1.20+. Clone repo. `chmod +x run_tests.sh` if needed.
- Run tests: `./run_tests.sh`
- Or: `go test ./...`
