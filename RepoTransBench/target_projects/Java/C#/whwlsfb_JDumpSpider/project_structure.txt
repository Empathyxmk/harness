# Build and test instructions:
# 1. Run `dotnet restore` in the project root to restore all dependencies.
# 2. Use `dotnet build whwlsfb_JDumpSpider.sln` to build all projects.
# 3. Run all tests with `./run_tests.sh` or `dotnet test whwlsfb_JDumpSpider.sln`.
# 4. Or test individual suites:
#    - `dotnet test tests/original/OriginalTests.csproj`
#    - `dotnet test public_tests/PublicTests.csproj`

# Directory explanations:
# - src/whwlsfb_JDumpSpider/: Core business code (interfaces, main logic, spidery classes).
# - tests/original/: Full original tests, one-for-one translated from existing Java tests.
# - public_tests/: Public tests, translated from the `*PublicTest.java` Java files, suitable for public validation or samples.
# - run_tests.sh: Simple script to execute all test projects.
# - whwlsfb_JDumpSpider.sln: Main solution file tying all projects together.
