Directory/File Explanations:
- easygcm/: Source code and all necessary stubs to build/run the tests.
- tests/original/: Translated C# versions of all original test cases.
- public_tests/: Translated public test cases (for public-facing correctness).
- *.csproj: C# project files for src, original tests, public tests.
- inloop_easygcm.sln: Solution file tying all projects together.
- run_tests.sh: Simple script to execute all tests.
- README.md: Project description and instructions.
- project_structure.txt: This structure/documentation file.

Build & Test Instructions:
1. .NET 6.0+ SDK is required.
2. Restore dependencies: `dotnet restore`
3. Run all tests: `./run_tests.sh`
