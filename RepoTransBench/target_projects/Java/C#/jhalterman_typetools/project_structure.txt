Directory/Files:
----------------
- src/TypeTools/           -- Library source code (to be implemented or referenced)
- tests/original/          -- Translated private/internal tests
- public_tests/            -- Translated public/visible tests
- jhalterman_typetools.sln -- .NET Solution file tying it all together
- run_tests.sh             -- Simple shell script to execute all test projects
- README.md                -- Project documentation and test instructions
- project_structure.txt    -- This file: overview of all folders and their purposes

Test Projects:
--------------
- Each of 'tests/original' and 'public_tests' is a self-contained test project referencing the main src/TypeTools/ library.

How to Run:
-----------
./run_tests.sh   -- Runs all xUnit tests in both original and public test projects.

You may add your solution into src/TypeTools/ for the tests to compile.
