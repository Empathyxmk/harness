--- Setup and Testing Instructions ---

1. .NET 6.0 or higher is required (see dotnet.microsoft.com/download).
2. Restore dependencies and build:
      dotnet restore
      dotnet build
3. Run all tests:
      ./run_tests.sh
   (Ensure the script is executable: chmod +x run_tests.sh)
4. To run only original tests:
      dotnet test tests/original/
5. To run only public tests:
      dotnet test public_tests/
