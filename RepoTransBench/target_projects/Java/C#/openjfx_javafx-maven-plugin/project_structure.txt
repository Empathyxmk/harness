Directory explanations:
- src/OpenJfxJavafxMavenPlugin/: Source code (stub implementations where required for compilation)
- tests/original/: Original test cases translated from Java to C#
- public_tests/: Public test cases as per public_test_summary.json (translated)
- Model/: Namespace for runtime path enums/models
- OpenJfxJavafxMavenPlugin.sln: Solution file referencing all projects
- *.csproj files: Project definitions including references to xUnit and source project
- run_tests.sh: One-click test runner using standard dotnet CLI
- README.md: Project and test instructions

Setup and test instructions:
1. Install .NET SDK 6+.
2. From repo root: `./run_tests.sh` to build and run all tests.
