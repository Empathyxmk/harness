Directory Explanations:
- src/ArCpText: Main source code (we provide stubs if source not available)
- tests/original: Original (private) functional/unit test cases, translated from Java JUnit code
- public_tests: Public test cases (originally *PublicTest.java), also translated
- *.csproj: C#/.NET project files for build dependencies and test frameworks
- ArCpText.sln: Solution file linking all projects for unified builds and testing
- run_tests.sh: One-click script to (build and) run all tests across both original and public test sets

Setup & Testing Instructions:
1. Install .NET SDK (>=6.0)
2. Run: `./run_tests.sh`
   - This builds and tests all test projects.
3. Results for both original and public tests will be displayed.

Unit tests use xUnit for all assertions and structure.
