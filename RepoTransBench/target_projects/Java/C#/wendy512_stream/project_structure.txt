Directory Explanations:
- wendy512_stream.sln: Solution to make it easy to open/test in Visual Studio.
- run_tests.sh: Run all tests with 'dotnet test'.
- src/wendy512_stream: Placeholder for core implementation (empty, just for structure).
- tests/original: Contains ALL original test cases fully translated to C# (xUnit+Moq).
- public_tests: Contains ALL public (Open) tests, fully translated (xUnit+Moq).
- *.csproj: Test projects reference the main project, include Moq for mocking.

Setup/Testing Instructions:
1. Install [.NET 7 SDK](https://dotnet.microsoft.com/download/dotnet/7.0) if not present.
2. To restore dependencies and build everything, run:
      dotnet restore
      dotnet build
3. Run all tests (original & public) with:
      ./run_tests.sh

Test Output: All xUnit test results will display on the console.

You can also run individual test projects with:
    dotnet test tests/original/
    dotnet test public_tests/
