- src/Vatri.Ecommerce/: Main project source code. Dummy or scaffold implementations for storage and cache (since tests won't run without them).
- tests/original/: Contains C# xUnit original tests translated from the Java project.
- public_tests/: Contains the public test cases as in the Java public test suite.
- *.csproj & .sln: .NET Core project and solution files.
- run_tests.sh: Runs all tests in both original and public test projects.
