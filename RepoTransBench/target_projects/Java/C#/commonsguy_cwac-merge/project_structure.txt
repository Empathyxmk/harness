# Setup & Testing Instructions:
#
# 1. Requirements: .NET 6+ SDK (install from https://dotnet.microsoft.com/)
# 2. To build and run all tests:
#       $ chmod +x run_tests.sh
#       $ ./run_tests.sh
#    - This builds the solution if needed, then runs both original and public test projects, showing all output.
# 3. For IDEs (e.g. Visual Studio, Rider, VS Code with C# plugin), open 'CommonsGuy.Cwac.Merge.sln'
#    and run test explorer.
#
# All tests are discovered and executed using xUnit and the Microsoft.NET.Test.Sdk.
# No manual test registration is needed; simply add new [Fact] or [Theory] methods.
