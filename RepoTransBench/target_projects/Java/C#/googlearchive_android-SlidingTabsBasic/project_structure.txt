Directory/Files Explanation:
---------------------------
- src/SlidingTabsBasic/           : Main code base for the project (contains dummy C# code for compatibility).
- tests/original/                 : All "original" test files (exact translations of Application/src/test/ and Application/tests/src/...).
- public_tests/                   : All "public" test files (from Application/src/test/.../PublicTest.java).
- run_tests.sh                    : Simple script to run all tests (dotnet test SlidingTabsBasic.sln).

How to run tests:
-----------------
$ chmod +x run_tests.sh
$ ./run_tests.sh

This will compile all code and run xUnit tests in both original and public test projects.

Project has standard .NET 7.0 structure and uses xUnit + Moq for all tests.

All logic and test coverage mirrors the original Java source.
