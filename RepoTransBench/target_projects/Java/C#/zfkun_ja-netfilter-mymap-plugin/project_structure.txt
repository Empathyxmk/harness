# Directory explanations:

src/                  - Source code for the main project
  Models/             - Data models (enums and POCOs)
  Core/               - Plugin config and potential shared abstractions
tests/original/       - Original (private/internal) tests translated from Java
public_tests/         - Public test suite, translated from Java "_PublicTest" test classes
run_tests.sh          - Simple executable script; run all tests in a single command
zfkun_ja_netfilter_mymap_plugin.sln - .NET solution tying all components together

# Setup & Testing Instructions:
1. Install .NET 6+ SDK: https://dotnet.microsoft.com/en-us/download
2. To build: from root, run
   dotnet build
3. To run tests:
   chmod +x run_tests.sh
   ./run_tests.sh

# All test logic is a direct translation from the provided Java test files.
