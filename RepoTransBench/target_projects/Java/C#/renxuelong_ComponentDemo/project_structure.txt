Setup & Testing Instructions:
----------------------------------------------
1. Install .NET 6+ SDK (https://dotnet.microsoft.com/download)
2. Run all tests:      ./run_tests.sh
3. To run interactively: dotnet test tests/original/     # or public_tests/
----------------------------------------------
Each test file is a 1-to-1 accurate translation of the Java/Kotlin test cases, logic preserved.
