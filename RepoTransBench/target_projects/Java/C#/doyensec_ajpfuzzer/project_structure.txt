Directory Explanations:
- DoyensecAjpFuzzer.sln : Visual Studio solution containing all projects (src, original tests, public tests)
- run_tests.sh         : Simple script to run all tests
- project_structure.txt: This documentation file (project tree and explanations)
- src/                 : Source code (.cs) for the main project
    - Doyensec.Ajpfuzzer/: Main C# project with all implementation files
- tests/original/      : Original/author internal tests (mirrored from Java's 'test/java/')
    - OriginalTests.csproj: Test project file for these tests
    - *.cs:                : Test case implementations (one class per .cs)
- public_tests/        : Public test set, corresponding to Java's public tests
    - PublicTests.csproj : Test project file for these tests
    - *.cs:                Individual public test files

Setup & Testing Instructions:
1. Ensure .NET 6.0 SDK is installed (dotnet command on PATH)
2. Restore dependencies:   dotnet restore DoyensecAjpFuzzer.sln
3. Run all tests:          ./run_tests.sh

All dependencies are managed via NuGet (.csproj files). xUnit is used for testing throughout.
