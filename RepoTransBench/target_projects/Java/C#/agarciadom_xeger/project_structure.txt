│   └── XegerPublicTest.cs                        # Public functional test

Directory Descriptions:
- src/XegerLib: Main source code library. Complete Xeger implementation should reside here.
- tests/original: Original (non-public) translated tests. Use `dotnet test tests/original/`.
- public_tests: Public version (non-proprietary) translated tests. Use `dotnet test public_tests/`.
- run_tests.sh: Simple shell script to run all tests using .NET CLI.
- project_structure.txt: This documentation file.

Setup & Testing Instructions:
1. Install .NET 6 SDK or later
2. Install dependencies (will auto-resolve with first `dotnet restore`)
3. To run ALL tests:
   $ ./run_tests.sh
4. To only run original or public tests:
   $ dotnet test tests/original/
   $ dotnet test public_tests/

Custom Notes:
- Xeger.cs includes only a minimal working stub required to make the test projects pass compile.
- For actual use, Xeger.cs should be fully implemented to match the behavior for all supported regex patterns.
