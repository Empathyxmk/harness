Directory & File Overview:
- src/Casidiablo.MultiDex/       -- Main code (minimal functional for tests)
- tests/original/                -- Original (private) test cases, fully translated from Java
- public_tests/                  -- Public (student-facing/open) test cases, fully translated from Java
- run_tests.sh                   -- Launches dotnet test on solution (all test suites)
- Casidiablo.MultiDex.sln        -- Solution binds code and both test suites
------------------------------------------------------------------------------
Setup & Usage:
1. Requires .NET 6 SDK or later.
2. Run: `./run_tests.sh` -- Restores, builds, and executes all tests.
3. All test files are runnable and fully implemented using xUnit.

Test Organization:
- "original" tests mirror original private test coverage.
- "public_tests" matches all public student-facing test cases.
