How to Build & Run Tests:
-------------------------
1. Install .NET 6.0 SDK or later (https://dotnet.microsoft.com/).
2. From the project root, run:

   ./run_tests.sh

   This will build all code and run all (original and public) tests.
   Output will indicate which tests passed or failed.

Directory Descriptions:
-----------------------
- src/FitChart/:      Business and utility code (translated library classes from Java).
- tests/original/:    xUnit test project containing the original test cases (private/internal).
- public_tests/:      xUnit test project with public test cases.
- run_tests.sh:       Runs all tests in all test projects using dotnet CLI.

Project is ready for development, editing, and CI/CD usage.
