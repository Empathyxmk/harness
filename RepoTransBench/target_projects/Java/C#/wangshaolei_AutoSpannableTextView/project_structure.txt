# --------
# Directory/Files Explanation:
#
# src/AutoSpannableTextView/            : Main source code area. Needs only minimal dummy implementation for test logic.
#   - AutoLinkStyleTextView.cs          : C# ported stub of the Android class for C# test compatibility.
#
# tests/original/                       : Original (private/internal) test suite, ported to xUnit for C#.
#   - Each *.cs file                    : One test class per file, mirroring original Java logic and coverage.
#
# public_tests/                         : Public test suite, ported to xUnit for C#.
#   - Each *.cs file                    : One test class per file, mirroring source "public" test coverage.
#
# Each test project uses xUnit and Moq for mocking (where needed).
# All tests can be run with dotnet test using the run_tests.sh script at the project root.
#
# Prerequisites: .NET 6+ SDK
# To install dependencies and run tests:
#   1. cd [project root]
#   2. chmod +x run_tests.sh
#   3. ./run_tests.sh
#
# This structure allows both Visual Studio and CLI (.NET SDK) workflows.
