-------------------------------------------------------------------------------
DIRECTORY EXPLANATIONS:

src/SuryakantBhartiImportantJavaConcepts/:
    Contains the main C# implementation files and class library for the sample project.

tests/original/:
    Contains the unit tests translated from the original, non-public ("private") Java tests.
    - All logic, assertions, and test coverage from the original suite are included here.

public_tests/:
    Contains public test cases (from AdderPublicTest.java, ExampleOverloadingPublicTest.java, etc).
    - These are designed for demonstration to users and for grading in public settings.

-------------------------------------------------------------------------------
BUILD & RUN INSTRUCTIONS:

Prerequisites:
- .NET 7 SDK+ required (install via https://dotnet.microsoft.com/download)

Steps:
1. To build and test everything, simply run:
    ./run_tests.sh

   This script builds the code and then runs both the "original" and "public" tests,
   reporting summary results for each set.

Notes:
- All test logic (assertions, test data, etc.) are identical to the original Java/JUnit suite.
- Projects use 'xUnit' for best C# testing framework compatibility.
