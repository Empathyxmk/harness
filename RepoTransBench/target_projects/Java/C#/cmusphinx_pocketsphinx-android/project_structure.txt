**Setup and Usage**

1. Install [.NET 6 SDK+](https://dotnet.microsoft.com/download).
2. Restore and build all projects:
       dotnet restore
       dotnet build
3. Run all tests with:
       ./run_tests.sh

**Directory explanation:**
- `src/PocketSphinx/`     : Main product/library code
- `tests/original/`       : Contains original (non-public) test cases, mapped from src/test/java/**/*.Test.java
- `public_tests/`         : Contains public test cases, mapped from *PublicTest.java, for public correctness validation
- Each test project references the main `PocketSphinx` code library
