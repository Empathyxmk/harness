Directory Explanations:
- src/LibxzrHorizonKernelFlasher/: Contains the .NET class library (`csproj`) with stubs for the translated Android code.
- src/LibxzrHorizonKernelFlasher/Models/: Holds mock interface representations for Android/Java types used in tests.
- src/LibxzrHorizonKernelFlasher/utils/: Assets utility bulk actions and their C# test stubs.
- tests/original/: Contains all original test translations into C# using xUnit and Moq, organized by subject (with utils subfolder).
- public_tests/: Contains all public/verification tests, separated to mimic the original repository organization.
- run_tests.sh: Simple script to run all C# tests using a single command.
- libxzr_HorizonKernelFlasher.sln: The main solution file for enabling IDE and command line builds.
- project_structure.txt: Documents directory structure and file purposes.

Setup & Testing:
1. Install the .NET SDK 6.0 or greater.
2. Run `./run_tests.sh` from project root -- this will build and test all projects, including both original and public test cases.
3. Test projects rely on the Moq and xUnit NuGet packages (already specified in csproj files).

Dependencies:
- xunit (for tests)
- Moq (for mocking Android/Java classes/interfaces)
