# Directory explanations:

src/:          All main production library code; pure C# logic for SmsRadar.
tests/original/:     xUnit tests directly ported from Java's original test set, organized per class.
public_tests/:       Translations of the public test suite, fully functional and discoverable.
run_tests.sh: Simple one-click bash script to build and run all tests.
Tuenti.SmsRadar.sln: Solution file for easy IDE/devtool use.
project_structure.txt: This file.
README.md: Project summary and usage (to be filled as needed).

# How to build and test:

1. Install .NET 6 SDK or later (https://dotnet.microsoft.com/download).
2. Run: chmod +x ./run_tests.sh
3. Run: ./run_tests.sh   (will build and run all original and public tests)
