-------------------------------------------------------------
How to Build and Run Tests
-------------------------------------------------------------
1. Install .NET Core SDK 6+ (https://dotnet.microsoft.com/download)
2. To restore dependencies:
     dotnet restore

3. To build all projects:
     dotnet build

4. To run all tests (original + public):
     ./run_tests.sh

   - This script simply runs 'dotnet test' at the solution root. Both public and original test projects will execute.
   - Test outputs and results will appear in the console.

-------------------------------------------------------------
How Projects/Tests are Organized
-------------------------------------------------------------
- All test logic is in xUnit-style C# test files.
- Each *Tests.cs correlates to one original Java test file (class).
- Public test logic is in public_tests/, original/private logic is in tests/original/.
- All required projects are tied together in the solution file.

-------------------------------------------------------------
Custom/Helper Classes & Mocking
-------------------------------------------------------------
- Since the original Java tests use extensive 'mock' objects via Mockito,
  in C# we use Moq (a standard C# mocking library for .NET/xUnit). All mock-heavy files (`*Processor*`) use Moq for mocking elements, attributes, etc.

- The solution is ready to be extended with actual core logic if needed.
