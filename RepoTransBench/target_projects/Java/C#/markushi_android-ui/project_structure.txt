# Directory/Files Description:
# - MarkushiAndroidUi.sln: Solution to coordinate building main code and test projects
# - run_tests.sh: Shell script. Run all tests (both original and public): ./run_tests.sh
# - src/MarkushiAndroidUi/: Main C# class library with dummy logic for running tests
# - tests/original/: All original test cases (1 test class per logic area)
# - public_tests/: All public (student-facing) test cases (separated)
# - *.csproj: Project and package configuration (xUnit used for all test projects)

# Setup/Build/Run instructions:
# 1. Install .NET SDK (>= 7.0)
# 2. Restore dependencies:        dotnet restore
# 3. To run all tests:           ./run_tests.sh
#    (runs both original and public tests)
