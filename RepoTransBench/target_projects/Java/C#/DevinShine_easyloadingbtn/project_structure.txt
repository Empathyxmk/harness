# Directory/Component Purposes:
# src/EasyLoadingBtn/            - Main library project (analogue to 'lib/main/java')
# src/EasyLoadingBtn/Models/     - Source classes (LoadingButton, etc.)
# tests/original/                - Original (internal) tests from source repo
# public_tests/                  - Public tests from source repo
# *.csproj                       - Project configuration files for .NET Core/Standard
# run_tests.sh                   - Shell script for running all tests in one step
# README.md                      - Project description and build/run instructions

# Setup and Test Instructions:

# Build and test all projects:
#   ./run_tests.sh

# Individual test runs:
#   dotnet test tests/original/
#   dotnet test public_tests/
