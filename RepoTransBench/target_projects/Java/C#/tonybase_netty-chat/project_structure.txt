Directory/Files Explanation:
- src/Comet/: Main codebase (core chat operation logic, interfaces, and DTOs)
- tests/original/: All original (private/internal) test cases. Mirrors Java's "original test" intent.
- public_tests/: All public test cases. Mirrors Java's public/visible tests.
- *.csproj: Standard C# project files for building source/tests with dotnet
- run_tests.sh: Run all tests (original + public) with a single `./run_tests.sh`
- project_structure.txt: Describes file layout and directory roles
- README.md: (Create as needed) Explains project build/run for new contributors

How to Build/Run Tests:
1. Make sure you have .NET 7 SDK+ installed.
2. From project_root, simply run:
   ./run_tests.sh
All tests should run (original and public). Projects use xUnit and moq for mocking.
