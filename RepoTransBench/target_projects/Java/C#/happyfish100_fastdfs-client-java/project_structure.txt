Directory/design notes:
- Original tests are in `tests/original/`
- Public tests are in `public_tests/`
- Both original and public tests are organized as their own C# test projects for modularity
- Main library code would be in `src/FastDFSClient/` (add production code here if translated/implemented)
- Each test project references the core FastDFSClient project (add as needed)
- Tests use xUnit for unit testing, Moq for mocking (install via NuGet)
- You can run *all* tests (original & public) via `dotnet test` at repo root or `./run_tests.sh`

Setup:
1. Make sure .NET 7+ SDK is installed (`dotnet --version`)
2. Restore dependencies: `dotnet restore`
3. Run all tests: `./run_tests.sh`
