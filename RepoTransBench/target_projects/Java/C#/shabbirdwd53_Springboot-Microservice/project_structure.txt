--- Directory Explanations ---

src/: Contains placeholder C# projects for each microservice. Only CloudGateway includes a demonstrative implementation file (FallBackMethodController.cs) since tests require this logic; others are stubs for structure.
tests/original/: All C# translations of the original Java test cases.
public_tests/: All C# translations of the public Java test cases.
Shabbirdwd53.Sbmicroservice.sln: C# solution file referencing all test and src projects.
run_tests.sh: Simple Bash script; runs all C# tests using dotnet test.

--- Setup and Testing Instructions ---
1. Install .NET 7 SDK+ (https://dotnet.microsoft.com/en-us/download).
2. In project root, run:
   chmod +x run_tests.sh   # (if not already executable)
   ./run_tests.sh         # Runs all tests (original and public).

--- Note ---
- All provided test logic has been ported identically.
- CloudGateway's fallback controller is implemented to allow tests to execute.
- All other application projects are present as empty SDK projects (for reference/structure).
- Public and original tests are kept strictly separated.
