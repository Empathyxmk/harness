Instructions:
1. Make sure you have .NET 6.0+ SDK installed.
2. To restore dependencies and build, run:   dotnet build BlackObfuscatorASPlugin.sln
3. To run all unit tests (original & public), run:   ./run_tests.sh

- The main library code resides in `src/BlackObfuscatorASPlugin/`.
- Original tests and public tests are split into separate test projects for clarity.
- Tests use xUnit as the testing framework.
- All test logic, data, and scenarios directly mirror those found in the Java source.
