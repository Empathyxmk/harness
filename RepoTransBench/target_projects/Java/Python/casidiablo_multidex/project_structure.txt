README/Instructions:
--------------------
- To install dependencies:      pip install -r requirements.txt
- To run all tests:             ./run_tests.sh
- Both original and public test cases are implemented using pytest in their respective folders.
- The original Java test coverage and scenarios are faithfully maintained via the Python tests.
- Running pytest will execute all tests (original and public). To run only one type, use e.g.:
    pytest tests/original/
    pytest public_tests/
