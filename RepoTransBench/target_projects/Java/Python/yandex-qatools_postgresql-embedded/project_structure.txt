Legend:
- tests/original/ : All original (private) test cases
- public_tests/   : All public, dummy-isolated test cases
- tests/resources/: Test resources (fixtures, backup .sql/.bin dumps)
- src/            : For source code if any Python port is needed (not strictly needed for translated tests)
- All dependencies listed in requirements.txt
- Full pytest compatibility; tests discoverable with `pytest`
- Run `./run_tests.sh` to execute everything

Setup:
$ pip install -r requirements.txt
$ chmod +x run_tests.sh
$ ./run_tests.sh

Note: Some original Java tests expect a full Java-based embedded postgres which may not map directly to Python. Dummy classes and simplified logic are used for portability.
