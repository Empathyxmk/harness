# Directory explanations:
# - requirements.txt: Python dependencies for running all tests (pytest)
# - run_tests.sh: One-click script to run ALL tests (original and public), using pytest
# - tests/original/: All original (private) test cases, exact Java-to-Python translation, complete logic
# - public_tests/: All public test cases, separate from originals
# - __init__.py files: For test module discovery
#
# Setup:
#   1. pip install -r requirements.txt
#   2. ./run_tests.sh
#
# All tests (original & public) runnable via ./run_tests.sh
