Directory explanations:
- requirements.txt: Python dependencies (pytest).
- run_tests.sh: Simple shell script to run all Python tests with Pytest.
- project_structure.txt: This file describing the translated project structure.
- tests/original/: All non-public ("original") tests, direct translations from Java.
- public_tests/: All "public" test files, as listed in public_test_summary.json; runnable independently.
- All test files use pytest conventions and direct assertion translation.
- __init__.py files included (even if empty) to allow package discovery.
- To install dependencies: `pip install -r requirements.txt`
- To run all tests: `./run_tests.sh`
