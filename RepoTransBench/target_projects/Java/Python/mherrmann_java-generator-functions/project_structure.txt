- requirements.txt: Lists dependencies, install with `pip install -r requirements.txt`.
- run_tests.sh: Run all tests (original and public) with `./run_tests.sh`.
- public_tests/: Contains public tests, easy to isolate for public validation.
- tests/original/: Contains original/full test suite as in Java's GeneratorTest.java.
- All test logic fully translated from Java. No placeholders, all edge cases and expected behaviours covered.
