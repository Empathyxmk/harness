# Directory Explanations:
# - requirements.txt         : Pip dependencies required for all tests
# - run_tests.sh             : Simple script to execute all tests with one click
# - tests/original/          : Translated "original" test cases from Java (all non-public tests, including context-load)
# - public_tests/            : Public test cases translated from *PublicTest.java
# - project_structure.txt    : Overview of project structure and usage
#
# Setup & Testing:
#   pip install -r requirements.txt
#   ./run_tests.sh
#
# All original and public tests will be discovered & run by pytest.
