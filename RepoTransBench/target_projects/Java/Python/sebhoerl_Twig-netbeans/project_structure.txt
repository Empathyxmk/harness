--- Directory explanations ---

requirements.txt:
    Contains Python dependencies. Only `pytest` is required for the tests.

run_tests.sh:
    Simple bash script to run all tests (original and public) using `pytest`. Executable.

tests/original/:
    Contains translations of all original/private Java test cases to Python.
    Each Java test file is mapped to a `test_*.py` file. Class/function and logic faithfully translated.

public_tests/:
    Contains translations of all public/sanitized Java test cases to Python, matching coverage and logic.

__init__.py files:
    Used to mark directories as packages so pytest can discover all test modules in complex structures.

--- Setup and Testing Instructions ---

1. Install dependencies:
    pip install -r requirements.txt

2. Make sure run_tests.sh is executable:
    chmod +x run_tests.sh

3. Run all tests:
    ./run_tests.sh

Tests in both `tests/original/` and `public_tests/` are run automatically.
