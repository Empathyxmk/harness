Directory explanations:
- src/bootloader_spoofer/:
    - Contains implementation of BootloaderSpoofer class (Python version).
- tests/original/:
    - Contains translated unit tests from the original Java project ("original" tests).
- public_tests/:
    - Contains public test cases (from BootloaderSpooferPublicTest.java).
- requirements.txt:
    - Specifies required Python packages (pytest).
- run_tests.sh:
    - One-click script: execute all tests with `./run_tests.sh`.
- README.md:
    - Overview and instructions for the Python project and its tests.

Setup/Running instructions:
1. Install requirements: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`
3. All logic for both original and public tests is covered and directly executable.
