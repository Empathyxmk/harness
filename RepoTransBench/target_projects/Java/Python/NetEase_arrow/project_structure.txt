## Directory Explanations:

- requirements.txt: Lists all Python dependencies, install with `pip install -r requirements.txt`
- run_tests.sh: Run this script to execute ALL tests (original and public).
- tests/: Main test suite folder.
  - original/: Translated original (non-public) Java tests.
- public_tests/: Public test cases only.
- project_structure.txt: This documentation.

## Setup and Usage:

1. Install requirements:
   pip install -r requirements.txt

2. Run all tests:
   ./run_tests.sh

3. Test files in tests/original/ are from original Java tests, those in public_tests/ are public tests.
