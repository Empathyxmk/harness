Directory Details
-----------------
tests/original/               - All original (non-public) test translations from the Java repo.
public_tests/                 - Publicly shareable test translations guarding no sensitive config.
requirements.txt              - List of test (and runtime, if needed) dependencies.
run_tests.sh                  - Bash script, simply run './run_tests.sh' to execute all tests.
project_structure.txt         - This documentation file.

How to run tests:
-----------------
1. Install dependencies:      pip install -r requirements.txt
2. Run tests:                 ./run_tests.sh

Each file in `tests/original/` or `public_tests/` directly corresponds to a Java test class, preserving all original logic, scenarios, data, and assertions.
