Directory Explanations:
- src/: (not included in translation) Intended for Python implementations of project logic.
- tests/: Original (non-public) test translations from Java. Organized by logical area.
- public_tests/: Public-released tests for external/public evaluation. 
- requirements.txt: All Python dependencies for test execution (pytest, mock, etc)
- run_tests.sh: Bash script to install deps and run all tests with pytest.
- README.md: Project usage, development, and test instructions.
- project_structure.txt: This file.

Test Run Instructions:
1. Ensure Python 3.x is installed.
2. Run: ./run_tests.sh
   - This installs all dependencies.
   - Executes all tests in tests/ and public_tests/ via pytest.
