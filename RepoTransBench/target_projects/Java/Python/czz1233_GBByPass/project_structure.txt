├── project_structure.txt       # This file, explains and documents the layout

Explanation and Instructions:

- src/company/main.py: The full implementation of logic and classes under test (Main and RandomUtil).
- tests/original/: Contains all Python equivalents of the original Java test files.
- public_tests/: Contains translated public test suite files.
- requirements.txt: To install dependencies (`pip install -r requirements.txt`).
- run_tests.sh: Run ALL tests (original + public) with one command (`./run_tests.sh`—ensure executable).
- project_structure.txt: This document; describes the overall structure & purpose.
- README.md: Contains instructions on running tests, installing dependencies, etc.

**How to run tests:**
1. Install dependencies:
   `pip install -r requirements.txt`
2. Run all tests with:
   `./run_tests.sh`
All original and public tests will be discovered and executed by pytest.
