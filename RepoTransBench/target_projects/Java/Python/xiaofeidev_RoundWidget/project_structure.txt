Directory Explanations:
- requirements.txt:       All Python dependencies (pytest for testing).
- run_tests.sh:           Make executable (`chmod +x`) for one-command testing: executes all tests via pytest.
- README.md:              Project readme (add usage/build info as needed).
- project_structure.txt:  This structure documentation for reference/setup.
- tests/original:         Translated original (private/internal) test cases from Java (JUnit).
- public_tests:           Translated public tests (used for public grading/demo, etc).

Running Tests:
$ pip install -r requirements.txt
$ ./run_tests.sh
  --Runs all tests in both `tests/` and `public_tests/` via pytest.
