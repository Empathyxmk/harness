How to Run Tests
----------------
1. Ensure you have Python 3 and pip installed.
2. Run `pip install -r requirements.txt` to install the required packages.
3. Make the script executable: `chmod +x run_tests.sh`
4. Run all tests: `./run_tests.sh`

- All tests in `tests/original/` are from the original Java repository.
- All tests in `public_tests/` are the public tests adapted from the original repository's public test set.
