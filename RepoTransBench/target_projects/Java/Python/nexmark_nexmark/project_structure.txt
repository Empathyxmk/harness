Directory explanation:
- requirements.txt: Lists required Python dependencies (pytest, etc.)
- run_tests.sh: Simple executable that runs all tests using pytest
- project_structure.txt: This explanation and directory tree
- tests/original/: Contains original (non-public) ported test cases
- public_tests/: Contains public ported test cases
- Each test file implements exactly the same scenarios as the original Java.
- __init__.py: Marks directory as a Python package/module.

Testing instructions:
1. Install dependencies: `pip install -r requirements.txt`
2. Make script executable: `chmod +x run_tests.sh`
3. Run all tests: `./run_tests.sh`
