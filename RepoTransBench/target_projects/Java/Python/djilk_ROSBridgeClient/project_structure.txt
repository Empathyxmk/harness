Directory Explanations:
- src/: Main Python source code. calculator.py contains the Calculator class.
- tests/original/: Original (private) test cases, translated from CalculatorTest.java.
- public_tests/: Public test cases, translated from CalculatorPublicTest.java.
- requirements.txt: Lists the required Python packages. Install with 'pip install -r requirements.txt'
- run_tests.sh: Runs all tests (original and public tests) with pytest.
- project_structure.txt: This documentation file.

Instructions:
1. Install dependencies:
   pip install -r requirements.txt
2. Run all tests:
   ./run_tests.sh
