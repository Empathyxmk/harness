Instructions:
-------------
- Install Python dependencies using: `pip install -r requirements.txt`
- To run ALL tests (original + public):   `./run_tests.sh`
- Tests under `tests/original/` are original private/internal tests.
- Tests under `public_tests/` are public tests.
- The test code mimics the original Java test logic, adapted for Python and `pytest`/`unittest` style.
