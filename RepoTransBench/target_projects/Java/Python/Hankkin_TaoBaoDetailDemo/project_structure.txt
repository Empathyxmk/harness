Explanation:
- requirements.txt         : Lists dependencies (pytest for testing)
- run_tests.sh            : Runs all tests (original and public) with one command
- tests/original/         : Contains complete translations of ALL the original/hidden test cases
- public_tests/           : Contains translations of ALL public test cases for user-facing testing
- All test logic, assertions, and behaviors are faithfully replicated from the Java original

How to set up & test:
1. Ensure Python 3 and pip are installed.
2. Install dependencies:
      pip install -r requirements.txt
3. Run all tests:
      ./run_tests.sh
   Or run only public or original tests:
      pytest public_tests/
      pytest tests/original/
