Key Directories:
- src/vulhub/: app logic module, including app.py implementing all tested features.
- tests/original/: All original, possibly-internal or solution-revealing testcases.
- public_tests/: All public, safe-for-release testcases. Mirrors Java public tests.

Setup:
1. (optional) Create virtual environment and install dependencies.
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
2. Run all tests:
    ./run_tests.sh

Both original & public tests are run by pytest.
