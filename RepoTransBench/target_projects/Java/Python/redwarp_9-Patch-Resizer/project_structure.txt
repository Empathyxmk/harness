Directory explanations:
- requirements.txt: lists all required Python dependencies (pytest for testing, Pillow for image tests)
- run_tests.sh: executable script to run all tests in one click (runs both original and public tests)
- tests/original/: direct translation of author's original Java test cases. 
- public_tests/: direct translation of all public test cases generated from the Java repo.
- README.md: you should document how to set up dependencies and run the tests.
- __init__.py: makes packages/discovery for pytest effective.

Setup and test instructions:
1. Install dependencies: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`
3. See output for test summary (pytest will report pass/fail status)
