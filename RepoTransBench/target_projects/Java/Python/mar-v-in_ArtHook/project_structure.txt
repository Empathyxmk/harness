Directory and file purposes:
- src/arthook/xposed/: Python modules for Xposed, Utils, ZygoteInit, RuntimeInit (test-accessible stubs where needed).
- tests/original/: Original test translations from Java.
- public_tests/: Public test set translations.
- requirements.txt: List of required Python packages (pytest, pytest-mock).
- run_tests.sh: Executable script to run all tests via pytest.
- project_structure.txt: This file; documents structure and file purposes.
To run all tests:
    pip install -r requirements.txt
    ./run_tests.sh
