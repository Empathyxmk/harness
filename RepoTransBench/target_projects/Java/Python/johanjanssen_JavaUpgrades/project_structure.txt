Instructions:
- `requirements.txt` lists dependencies. Install with `pip install -r requirements.txt`
- Tests are organized into:
   - `tests/original/`: All tests translated from original Java sources.
   - `public_tests/`: Translated public test suite.
- `run_tests.sh` runs all tests in both directories.
- All tests use `pytest` conventions and can be run independently or together.
