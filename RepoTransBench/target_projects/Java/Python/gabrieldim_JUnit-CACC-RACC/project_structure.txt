# Directory explanations

- src/: All source code (actual logic), translation of 'DifferenceBetweenDaysInYear' logic.
- tests/original/: Original (non-public) test cases from the Java repo.
- public_tests/: Translated public test suite, covering public problem description and sample/outlier cases.
- requirements.txt: Python dependency list. 'pytest' for all testing needs.
- run_tests.sh: Minimal script for users to run all tests with one line.
- README.md: Project usage, structure, and run guide.

# Instructions

1. Install dependencies:
   pip install -r requirements.txt

2. Run all tests:
   ./run_tests.sh
