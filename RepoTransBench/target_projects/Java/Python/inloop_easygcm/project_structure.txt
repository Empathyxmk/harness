# Directory Explanations:
# - requirements.txt: Python dependencies, install with `pip install -r requirements.txt`
# - run_tests.sh: Simple one-click script to run all tests (original & public)
# - tests/original/: Contains all translated "original" test cases from the Java project.
# - public_tests/: Contains all translated "public" test cases from the Java project.
# Each test file replicates the logic of its Java counterpart using Python & pytest.
# To run all tests: first `pip install -r requirements.txt`, then `./run_tests.sh`
