Explanations:
-------------
- src/easyloadingbtn/loading_button.py:
    The core LoadingButton class, simulating expected public API sufficient for testing in Python.

- tests/original/test_loading_button.py:
    Unit tests translated from the original private/internal Java tests.

- public_tests/test_loading_button_public.py:
    Unit tests translated from the public Java tests.

- requirements.txt:
    Lists Python dependencies (Pytest).

- run_tests.sh:
    Executable script to run all tests, installing dependencies first.

- project_structure.txt:
    Describes the file tree and what each part is for.

Setup & Usage:
--------------
1. Install Python 3.7+.
2. Grant execute permission to the test script: `chmod +x run_tests.sh`
3. Run all tests: `./run_tests.sh`

The project separates original and public tests as in the Java version. All test logic is maintained.
