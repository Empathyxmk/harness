Directory explanations:
- requirements.txt: Lists all Python dependencies needed (pytest)
- run_tests.sh: Simple shell script to run all tests in both original and public test directories using pytest
- tests/original/: Contains all translations of the original (internal) Java test files into Python
- public_tests/: Contains all translations of the public (benchmark) Java test files into Python
- __init__.py: Included as package markers to allow relative imports if needed.
- Each test_*.py: A direct translation of the corresponding Java test file, with identical logic, assertions, and structure, implemented in Python using pytest.

Setup and test instructions:
1. Install Python 3.x and `pip` if not already installed.
2. Install dependencies: `pip install -r requirements.txt`
3. Make the test script executable: `chmod +x run_tests.sh`
4. Run all tests with one command: `./run_tests.sh`
