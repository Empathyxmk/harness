# Directory Explanation
src/dns66/               : Core source code (translated modules)
src/dns66/db/            : Database and related source modules
src/dns66/vpn/           : VPN and networking source modules

tests/original/          : Complete translations of original Java test files (private/internal tests)
public_tests/            : Complete translations of all Java public tests (safe for public release)

requirements.txt         : Python dependency spec (pytest, mock)
run_tests.sh             : One-command test runner for all Python tests
README.md                : Project description, installation, and test instructions
project_structure.txt    : This structure file. Explains organization and usage.

# Test Execution
- To run *all* tests, just run:
  $ ./run_tests.sh
- To run only original/private tests:
  $ pytest tests/original/
- To run only public tests:
  $ pytest public_tests/
