# Directory/Files Descriptions
# - requirements.txt: List of required Python packages (pytest)
# - run_tests.sh: Simple script to execute all tests
# - tests/: Main test package directory
#   - original/: Contains all original (non-public) test translations from Java to Python.
# - public_tests/: Contains all public test translations from Java to Python.
# - __init__.py (in each dir): Marks directory as a Python package. Files can be left empty.
#
# Setup & Test Instructions:
# 1. Install requirements: `pip install -r requirements.txt`
# 2. Run all tests: `./run_tests.sh`
#
# All original and public tests are self-contained within their respective folders.
# All test logic and coverage is preserved from the Java originals.
