Explanations:
- src/aescrypt/aescrypt.py: Minimal implementation of AESCrypt to support tests.
- tests/original/: All original (non-public) test translations, matching the Java originals.
- public_tests/: All public test translations from the provided Java public tests.
- requirements.txt: Declares dependencies; install with `pip install -r requirements.txt`.
- run_tests.sh: Run all tests with a single command (`./run_tests.sh`). Requires pytest.
- project_structure.txt: This documentation.

How to set up and test:
1. Install dependencies:
   pip install -r requirements.txt
2. Run all tests:
   ./run_tests.sh

You should see all tests execute with results matching the Java originals and public tests.
