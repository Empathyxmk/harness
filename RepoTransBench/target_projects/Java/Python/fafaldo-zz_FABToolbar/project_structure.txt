**Instructions:**
1. Install dependencies: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`
   - This will run both original and public tests using `pytest`.
3. All test cases are implemented; no placeholder or incomplete logic.
4. Project separates original tests (`tests/original/`) and public tests (`public_tests/`).
5. `pytest-mock` is required for proper mocking (as per Mockito usage in the original Java tests).
