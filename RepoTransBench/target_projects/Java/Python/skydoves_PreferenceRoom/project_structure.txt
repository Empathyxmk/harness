Explanations:
- requirements.txt: Install Python dependencies. Run `pip install -r requirements.txt` before running tests.
- run_tests.sh: One-command test execution for all tests (original and public). Usage: `chmod +x run_tests.sh && ./run_tests.sh`
- tests/original/: Contains all original test logic as translated from Java.
- public_tests/: Contains public tests matching the public variants in the source repo.
- __init__.py files: Make Python treat directories as packages (for pytest discovery).
Test instructions:
1. Run `pip install -r requirements.txt`.
2. Execute all tests with `./run_tests.sh`.
