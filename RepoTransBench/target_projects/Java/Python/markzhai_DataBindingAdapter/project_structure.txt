Directory explanations:
- requirements.txt:     All Python dependencies (pytest).
- run_tests.sh:         One-click shell script to run all tests (pytest).
- tests/original/:      Contains the full translation of all "original" Java test cases.
- public_tests/:        Contains the full translation of all "public" Java test cases.
- __init__.py files:    Mark each test directory as a Python package (required for pytest discovery).
- project_structure.txt: Documents the structure and contents of this project.

Setup and Testing Instructions:
1. (Optional) Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. To run ALL tests, execute: `./run_tests.sh`
   - This will automatically discover and run all tests in `tests/` and `public_tests/`.
