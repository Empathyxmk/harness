README.md                            # Instructions and project overview

----------------------------------------------------------
Directory explanations:
- requirements.txt:        Specifies all Python dependencies (just pytest here).
- run_tests.sh:            Bash script to execute all tests with a single command.
- tests/original/:         Contains translated original test cases from Java.
- public_tests/:           Contains translated public tests.
- __init__.py:             Standard Python package init files (empty).
----------------------------------------------------------
To run all tests:

1. Ensure you have Python 3 and pip installed.
2. Install dependencies: pip install -r requirements.txt
3. Run all tests: ./run_tests.sh

The script runs all tests (original + public) using pytest.
