Directory explanations:
----------------------
src/fitchart/      : Contains Python translations of the source/core classes of FitChart
tests/original/    : Python translations of the original Java test cases
public_tests/      : Python translations of the public Java tests (for public use)
requirements.txt   : Declares Python dependencies (pytest, mock)
run_tests.sh       : Minimal, standard script to run ALL tests via pytest
project_structure.txt : This documentation file

Setup/Testing Instructions:
--------------------------
1. Install requirements:
   pip install -r requirements.txt

2. Run all tests:
   ./run_tests.sh
   (or: pytest)

3. Test layout:
   - All tests are discovered automatically by pytest.
   - Original project tests:  tests/original/
   - Public project tests:    public_tests/
