# 
# Directory Explanations:
# - requirements.txt: Specifies all Python dependencies needed for running the tests.
# - run_tests.sh: Shell script that runs ALL tests (both original and public) using pytest. Just `chmod +x run_tests.sh` and `./run_tests.sh`.
# - tests/original/: Contains direct translations of the original Java tests; same logic, edge cases, and parameters as upstream.
# - public_tests/: Contains translations of the public (student-facing) test cases. These avoid proprietary/private data and test logic that is suitable for public release.
# - README.md: Explains the structure, how to set up the environment, and how to run tests.
