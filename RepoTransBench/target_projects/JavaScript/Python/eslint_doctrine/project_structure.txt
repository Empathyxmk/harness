└── project_structure.txt          # This file: structure and explanation

Directory explanations:
- requirements.txt:       All Python dependencies, including pytest for testing
- run_tests.sh:           Simple executable shell script to run all tests with pytest
- public_tests/:          Directory for all public tests (each in its own Python file)
- __init__.py:            Marks public_tests/ as a Python package, allows test discovery
- test_*.py:              Translated test modules for each feature from JS source

To run all tests:
    1. Install python3 and pip if not present.
    2. pip install -r requirements.txt
    3. ./run_tests.sh

Tests are discovered using pytest conventions, mapped directly from the original JavaScript Mocha/Should.js structure.
