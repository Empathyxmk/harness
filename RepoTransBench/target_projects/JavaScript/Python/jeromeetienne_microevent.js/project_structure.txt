Directory explanations:
- src/:           Contains microevent core/event code (Python stubs for compatibility with test suite).
- tests/original/:  Fully translated original tests from JS ('tests/') covering all functional and edge paths.
- public_tests/:  Equivalent to JS 'public_tests/' - public-facing alternates, using different event/param data.
- run_tests.sh:   One-click execution; will run all tests from both public and original (pytest).
- requirements.txt: Declares pytest as the test framework dependency.

Test execution instructions:
1. (Recommended) Use virtualenv: python3 -m venv venv && source venv/bin/activate
2. Install requirements: pip install -r requirements.txt
3. Run all tests via: ./run_tests.sh
