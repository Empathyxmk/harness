Explanation:
- src/jsoncrush/jsoncrush.py     → Python implementation of JSONCrush and JSONUncrush (functionality for tests)
- tests/original/test_jsoncrush.py → Exact port of the original JS tests (test/JSONCrush.test.js)
- public_tests/test_jsoncrush_public.py → Exact port of the public JS tests (public_tests/JSONCrush.public.test.js)
- tests/test_jsoncrush_unit.py   → Port of test_jsoncrush.js with console output (and all-pass assertion)
- requirements.txt               → Declares pytest as dependency
- run_tests.sh                   → Simple one-command script for running all tests
- project_structure.txt          → This documentation

Setup:
1. python3 -m venv venv
2. source venv/bin/activate
3. pip install -r requirements.txt
4. ./run_tests.sh
