======================================================

Setup & Usage
-------------

1. Install requirements:
    pip install -r requirements.txt

2. To run ALL tests (original and public), execute:
    ./run_tests.sh

Test Folders:
-------------
- tests/         - Contains all translated original tests.
- public_tests/  - Contains all translated public test cases.

Source Code:
------------
- src/passport_local/   - Source re-implementation to enable tests to pass, modeled for test compatibility.

Adjust as needed if you plan to integrate real logic.
