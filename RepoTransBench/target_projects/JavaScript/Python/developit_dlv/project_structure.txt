Directory explanations:
- src/: Contains the Python source code for the dlv library.
- tests/original/: Contains all original (author) test cases, translated from JavaScript to Python.
- public_tests/: Contains all publicly released test cases, also fully translated.
- requirements.txt: Pin pytest as the sole dev dependency.
- run_tests.sh: One-click script to run all tests using pytest (unit, original, and public).
- project_structure.txt: This file (documentation of layout).

How to set up and test:
1. Create and activate a Python virtualenv if desired.
2. Install dependencies: `pip install -r requirements.txt`
3. Run all tests: `./run_tests.sh`
   - Or, directly: `pytest`

All test logic is ported from the original and public JavaScript tests and will fully check Python's dlv implementation for functional parity.
