Explanations:
- src/                       : Python source code, modules to be tested (expected manual/automatic translation)
- src/PureFunctions2.py      : Python translation of PureFunctions2.js
- src/parser/                : Python translation of all parser-related JavaScript modules
- tests/original/            : Original tests translated from JavaScript to Python, preserving all logic/coverage
- public_tests/              : Public-facing test cases, as per public JavaScript tests
- requirements.txt           : Python dependencies for test execution (pytest)
- run_tests.sh               : Simple, one-click test execution script (`pytest`)
- project_structure.txt      : This project tree with explanations for setup/discovery

Setup/Testing Instructions:
1. Place the Python translations of original JS source into src/ and src/parser/
2. Install dependencies: `pip install -r requirements.txt`
3. Run all tests:        `./run_tests.sh`
4. Pytest will discover and run all tests under `tests/` and `public_tests/`
5. Add/extend tests following this structure for future development
