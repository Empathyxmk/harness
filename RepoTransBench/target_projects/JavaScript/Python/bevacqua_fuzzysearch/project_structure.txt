Directory explanations:
- src/: Python source code, primary implementation of fuzzysearch in fuzzysearch.py. __init__.py exposes fuzzysearch for import.
- tests/original/: Contains the translated "original" test suite from the original repository, ensuring full test coverage and regression protection.
- public_tests/: Contains public-facing tests for distribution, verification, and educational purposes.
- requirements.txt: Python requirements file specifying dependencies (pytest).
- run_tests.sh: Simple script to run all tests using pytest.
- project_structure.txt: This documentation.
- README.md: Project overview and usage instructions.

Setup & Testing Instructions:
1. Install dependencies: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`
3. To run a specific suite: `pytest tests/original/` or `pytest public_tests/`
