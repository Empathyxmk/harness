# Directory explanations:
# - src/           : The Python source code for core and chart modules.
# - tests/original/: Full original test suite, each chart module has its own directory.
# - public_tests/  : Public tests as described in public_test_summary.json.
# - requirements.txt: Lists the dependencies (pytest for testing).
# - run_tests.sh   : Bash script to run all tests in one command.
# - project_structure.txt: This structure/documentation file.

# Setup and Testing Instructions:
#
# 1. Install dependencies:
#    pip install -r requirements.txt
#
# 2. Run all tests:
#    ./run_tests.sh
#
# Pytest will auto-discover all test files in both "tests/original/" and "public_tests/".
