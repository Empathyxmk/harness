# Directory Explanation
- src/                     : Python source code (levenshtein.py contains both class & function implementations)
- tests/original/          : All translated original test cases from JavaScript (full coverage)
- public_tests/            : All translated public test cases (distinct input scenarios for public test exposure)
- requirements.txt         : Project requirements for Python (pytest for testing)
- run_tests.sh             : Simple shell script to run all tests
- project_structure.txt    : Directory structure and file explanations

# Test Discovery
- All tests can be run at once with `./run_tests.sh`
- Both original and public tests are auto-discovered by pytest (standard naming)

# Usage Instructions
1. Install requirements:
       pip install -r requirements.txt
2. Make the test script executable (if needed):
       chmod +x run_tests.sh
3. Run all tests:
       ./run_tests.sh

- Source tests are organized as "original" and "public" to mirror JS repo separation.
- Implementation matches both direct distance function and class-based usage.
