# Directory/Files Explained:
- src/: All source code goes here. escape_html.py implements the core escape_html function.
- tests/original/: All original (internal) tests translated from JavaScript live here. Follows pytest test discovery.
- public_tests/: All generated/confirmed public tests reside here, separated from original tests.
- requirements.txt: Python dependencies (pytest required for running tests).
- run_tests.sh: Simple shell script to install dependencies and run all discovered tests.
- project_structure.txt: This file. Documents the layout and purposes.

# Setup & Testing Instructions:

1. (Recommended) Create a virtual environment:
   python3 -m venv venv
   source venv/bin/activate

2. Install dependencies:
   pip install -r requirements.txt

3. Run all tests:
   ./run_tests.sh

- This will run both original and public tests using pytest, reporting all output.
