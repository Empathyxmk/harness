Directory Explanations:
- src/alexafact/: Main Python package for the fact skill logic. Contains modules for personalization util, storage util, and main index logic.
- tests/original/: Original (internal) test translations, mapped 1:1 from JS original test suite with identical coverage.
- public_tests/: Public test suite directory. Each test preserves the public variant logic/data from JS, adapted to Python.
- requirements.txt: Python dependencies (install using: pip install -r requirements.txt).
- run_tests.sh: Run all tests. Make executable with chmod +x run_tests.sh, then run ./run_tests.sh.

Test Execution:
1. Install dependencies:
   pip install -r requirements.txt
2. Run all tests:
   ./run_tests.sh

Tests will execute both original and public test cases using pytest.
