Explanation:

- src/: Place any source modules here if converting business logic. (Not needed just for tests)
- requirements.txt: Lists 'pytest', the Python test framework required to run all tests.
- run_tests.sh: Simple shell script to run all tests using pytest.
- tests/original/: Contains Python translations of all original test files. Maintains functionality of the provided JavaScript tests.
- public_tests/: Contains Python translations of all public test files and scenarios.
- All tests are executable with one command: ./run_tests.sh

How to run all tests:
1. Install dependencies: pip install -r requirements.txt
2. Run tests: ./run_tests.sh
3. All original and public tests will be executed. Output will show pass/fail per function.
