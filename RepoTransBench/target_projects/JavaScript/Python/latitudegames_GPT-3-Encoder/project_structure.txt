Directory explanations:
- encoder.py: The main encoder/decoder Python module. Must provide 'encode' and 'decode' functions.
- requirements.txt: Lists project dependencies, including 'pytest' for testing.
- run_tests.sh: Bash script for running ALL tests with one click (runs pytest).
- tests/original/: Contains original (upstream/internal) test cases.
- public_tests/: Contains public/assessment test cases.
- __init__.py: Standard for package/module recognition in Python.
- README.md: Usage, install, and reference documentation.
- project_structure.txt: Overview of the repo structure (this file).

Setup & Testing Instructions:
1. Install dependencies:
   $ pip install -r requirements.txt
2. Run all tests:
   $ ./run_tests.sh

All test cases in 'tests/original/' and 'public_tests/' are fully implemented using pytest.
