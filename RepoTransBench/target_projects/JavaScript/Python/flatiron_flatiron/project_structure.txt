Directory/Files Explanation:
- requirements.txt: Declares all Python dependencies required to run the test suite.
- run_tests.sh: Executable bash script to launch all tests with pytest in one command.
- project_structure.txt: This file; documents root layout and file purposes.
- tests/original/: Holds all original (private/internal) translated tests. Each test_x.py mirrors a JS file from the original.
- public_tests/examples/: Holds all public test translations. Mirrors source structure and semantic logic of the JS public tests.

To run ALL TESTS:
  > pip install -r requirements.txt
  > chmod +x run_tests.sh
  > ./run_tests.sh

- All tests run via `pytest` and include both "original" and "public" (if you want to run separately: `pytest tests/original/`, `pytest public_tests/`)
- The source app modules must be converted to Python for the tests to physically run (tests gracefully skip if imports are unavailable).
