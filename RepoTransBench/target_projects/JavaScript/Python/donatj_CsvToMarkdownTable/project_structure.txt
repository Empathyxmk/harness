Directory Purposes:
- src/         - Contains the implementation to be tested (csv_to_markdown.py)
- tests/       - Main directory for test code
- tests/original/ - Contains tests derived from the original repo's own test suite
- public_tests/   - Contains public/visible tests for external/fairness checking
- requirements.txt - Declares pytest dependency
- run_tests.sh  - Easiest way to run all Python tests with one command

Setup & Testing Instructions:
1. (Recommended) Create virtual environment: python -m venv venv && source venv/bin/activate
2. Install dependencies: pip install -r requirements.txt
3. Run all tests: ./run_tests.sh
   - This will run both original and public tests using pytest.
