----
Directory explanations and instructions:
- index.py:
    The config module under test (minimal dummy Python version for testing).
- requirements.txt:
    Declares test dependencies (pytest).
- tests/original/:
    Contains Python translations of all original tests from JS.
- public_tests/:
    Python translations of all public tests.
- run_tests.sh:
    Runs all tests with `pytest`. Make executable with `chmod +x run_tests.sh`.
- To run all tests (original and public), execute: ./run_tests.sh
