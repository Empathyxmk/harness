Directory/Files explanation:
- requirements.txt: Declares dependencies (pytest).
- run_tests.sh: Runs all tests (pytest finds tests across tests/ and public_tests/).
- src/: Your main Python sources, ported from JS if/when source code is needed.
- tests/original/: Translated unit/integration tests from original JS repo.
- public_tests/: Publicly visible test cases (shell/placeholder here).
- project_structure.txt: This architectural overview.

Setup & Testing instructions:
1. Install dependencies with: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`
   - (Or manually: `pytest`)
3. Place/port your actual source code in src/.
