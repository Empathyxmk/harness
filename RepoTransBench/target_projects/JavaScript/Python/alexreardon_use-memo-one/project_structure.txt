- src/: Python source code implementations, directly ported from JS logic.
- tests/original/: All original, full-coverage tests from the JS repo, now fully translated to Python/pytest (private/internal).
- public_tests/: All public test cases, as translated from public_tests/*.public.test.js.
- requirements.txt: All Python package requirements (pytest, pytest-mock for mocking).
- run_tests.sh: One-click shell script to discover and run all tests using pytest.
- README.md: Project information and instructions (not filled here).
- project_structure.txt: This file, describing the full tree and each folder's purpose.

Instructions:
1. `pip install -r requirements.txt` to install dependencies.
2. `./run_tests.sh` to run all tests.
