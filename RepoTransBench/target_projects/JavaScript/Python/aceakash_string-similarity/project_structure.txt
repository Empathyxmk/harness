Directory explanations:
- src/: API/source code for string similarity
- tests/original/: Full translation of all original JavaScript test cases
- public_tests/: Full translation of public tests from the JavaScript repository
- requirements.txt: Python dependencies (pytest required)
- run_tests.sh: One-click test execution script

How to set up and run:
1. pip install -r requirements.txt
2. ./run_tests.sh

This configuration runs all tests (original and public) using pytest and will discover all properly named test scripts.
