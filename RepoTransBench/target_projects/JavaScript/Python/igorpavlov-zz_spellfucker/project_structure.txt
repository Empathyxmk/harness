Recommended/Expected Python Structure
-------------------------------------
src/spellfucker.py
    - Python version of spellfucker function/logic.

tests/original/test_spellfucker.py
    - Core "original" Python tests for main spellfucker behaviors.
tests/original/test_spellfucker_advanced.py
    - Advanced/edge case Python tests for spellfucker.

public_tests/
    - [If included] Python versions of public test cases.
    - Place Python test files as: public_tests/test_*.py

How to install and run tests
----------------------------
1. (Optional) Set up a virtualenv:
      python3 -m venv venv
      source venv/bin/activate

2. Install dependencies:
      pip install -r requirements.txt

3. Run all tests:
      ./run_tests.sh


Testing framework
-----------------
- Uses `pytest`. All tests use standard "test_" naming and assertions.
- Can also run directly with `pytest` command.


Extra notes
------------
- All code and test files are in pure Python (unless legacy/JS for reference).
- Only src/spellfucker.py is required for spellfucker implementation under test.
- Source coverage and JS files are legacy, retained for reference; Python users may ignore.
