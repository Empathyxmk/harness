# Directory explanations:
# - src/cookie_parser/: source code for cookie-parser-compatible interface/module
# - tests/original/: original (non-public) test cases, direct translation from JS
# - public_tests/: public test cases, direct translation from JS
# - requirements.txt: Python dependencies; just pytest needed for now
# - run_tests.sh: runs all tests (pytest finds both original and public tests)
# - __init__.py: enables package/module discovery for pytest

# To Run Tests:
#   pip install -r requirements.txt
#   ./run_tests.sh

# To Run Only Original Tests (Optional advanced):
#   pytest tests/original/
#
# To Run Only Public Tests:
#   pytest public_tests/
