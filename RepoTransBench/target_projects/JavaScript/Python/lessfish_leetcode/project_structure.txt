Directory/Files Explanation:

requirements.txt
    List of Python dependencies (pytest for tests).

run_tests.sh
    One-click script to run all tests. Installs pytest if missing, then runs pytest.

project_structure.txt
    This file. Documents the directory structure and explains project files.

tests/original/
    Contains translations of the project's original test cases (comprehensive/internal).

public_tests/
    Contains translations of the project's public test cases.

src/
    Folder where production (solution) code lives.
    - __init__.py: marks 'src' as a package.
    - Each .py file is the translated solution module for the corresponding problem.

Instructions:
1. To run all tests, simply execute:
       ./run_tests.sh

2. To install all dependencies manually:
       pip install -r requirements.txt

3. To run only "original" or "public" tests:
   - pytest tests/original/
   - pytest public_tests/

Project is designed for easy extensibility (just drop more test files in the appropriate folder).
