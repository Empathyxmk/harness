Directory explanations:
- src/: Python source implementation (core vhost logic)
- tests/: Original/internal tests from JS project, now as Python tests
- public_tests/: Public exported tests, translated to Python
- requirements.txt: Installable Python dependencies for running tests (pytest, requests)
- run_tests.sh: One-click test runner, will install dependencies and run all tests
- README.md: Setup and usage instructions for Python project
- project_structure.txt: Project overview and directory/file purpose
