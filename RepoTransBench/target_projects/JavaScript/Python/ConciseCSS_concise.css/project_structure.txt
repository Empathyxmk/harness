Setup & Testing Instructions:
1. Install requirements:
   pip install -r requirements.txt
2. Place your src/ implementation as needed.
3. Run all tests:
   ./run_tests.sh

All tests are in 'public_tests/'. No original (private) tests exist in source repo.
