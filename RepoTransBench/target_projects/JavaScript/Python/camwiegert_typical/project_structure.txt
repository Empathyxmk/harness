---- Explanation ----

- **typical.py**: Main implementation. Contains Python-equivalent `type` function for tests.
- **requirements.txt**: Lists dependencies. Install via `pip install -r requirements.txt`.
- **run_tests.sh**: One-click script to run all tests (original + public).
- **tests/original/**: Internal/original test cases, named and structured to match source test coverage.
- **public_tests/**: Public version of tests, matching provided source logic and input variations.
- **__init__.py**: All test dirs include this to ensure proper discovery for pytest/unittest.
- **project_structure.txt**: Documents structure, dirs, and usage.

---- Setup & Testing Instructions ----

1. (Optionally) Create a fresh Python virtual environment.
2. Install dependencies:
       pip install -r requirements.txt
3. Run all tests with one command:
       ./run_tests.sh
   All tests (original + public) will execute, showing summary output.

- Run only original tests: `pytest tests/original/`
- Run only public tests: `pytest public_tests/`

---- Notes ----

- All async and awaitable test code handled via pytest-asyncio and pytest's @pytest.mark.asyncio.
- The `type` function is implemented to closely simulate the behavior under test.
- Test discovery/organization mirrors the original JS project intent with clear separation of private/public tests.
