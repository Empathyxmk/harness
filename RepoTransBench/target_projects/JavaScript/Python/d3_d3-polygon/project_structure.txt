Directory explanations:
- src/d3polygon/:     All polygon library implementations (area, centroid, etc)
- tests/original/:    Full translated original JS tests (now in Python/pytest)
- public_tests/:      Public centroid test (for public/verification scenarios)
- requirements.txt:   Python dependencies (install with pip)
- run_tests.sh:       (chmod +x) then './run_tests.sh' to test everything
- project_structure.txt: This overview (structure/start info)

## Setup & Testing Instructions

1. Create virtualenv (recommended) and install packages:
    python -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt

2. Run all tests (original & public):
    ./run_tests.sh

All tests use pytest and do not require special arguments. Source is in src/d3polygon/.
