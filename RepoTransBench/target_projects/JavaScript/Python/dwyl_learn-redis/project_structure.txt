Directory/Files Explanation:
- README.md: General documentation, setup, how to run tests, requirements.
- requirements.txt: Python package dependencies for both redis and tests (pytest).
- run_tests.sh: Minimal shell script to execute all tests (simply calls pytest).
- examples/basic.js: Source example file (exists mainly to match test checks for its presence).
- tests/original/: Contains all tests translated from JavaScript `test/` directory. Each file matches and implements the logic from the original JS test.
- public_tests/: Contains public-facing test variants, matching the original "public_tests" logic and structure.
- Each test is fully implemented, covering behavior, edge cases, and results as in the original project.

Test Instructions:
1. Ensure Redis server is running and accessible on default port (`localhost:6379`).
2. Install dependencies: `pip install -r requirements.txt`
3. Run all tests: `./run_tests.sh`
4. All tests (original and public) will execute, verifying both client logic and file existence as per source behavior.
