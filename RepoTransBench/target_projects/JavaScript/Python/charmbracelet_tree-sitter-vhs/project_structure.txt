Directory Explanations:
- tests/original/: All test cases translated from the original JavaScript and Go, for "private/internal" API/implementation verification.
- public_tests/: Test cases translated from public-facing public_tests/ in the JS source, to verify visible/public behaviors and structural requirements.
- grammar.js, src/node-types.json: Required fixture files for test reads/mocks.
- requirements.txt: Lists pytest (for pip install -r requirements.txt).
- run_tests.sh: Runs all tests via pytest with a single command.
- README.md: Add instructions for setup and running the test suite.

**Setup and Test Instructions:**
1. (Optional) Install dependencies:
   pip install -r requirements.txt
2. Run all tests (original and public):
   ./run_tests.sh

**Note:** If you wish to run only public or only original tests, use:
   pytest public_tests/
   pytest tests/original/
