Directory overview:

src/
    tree_model.py
        Implement the TreeModel class and node logic here so tests can import from src.tree_model.

tests/original/
    Original, full-coverage tests translated from the JS repository. Place your implementation in src/ so these import and execute correctly.

public_tests/
    Translations of public test cases (for public test exposure/execution).

requirements.txt
    Dependencies (install with: pip install -r requirements.txt)

run_tests.sh
    Run all tests (original and public) with one command via pytest.

How to use:
    1. Implement `TreeModel` in src/tree_model.py
    2. Install dependencies:   pip install -r requirements.txt
    3. Run tests:              ./run_tests.sh

All test scenarios and logic are from the original JavaScript tests and preserved identically.
