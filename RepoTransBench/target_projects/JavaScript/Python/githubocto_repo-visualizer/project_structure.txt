- src/: All Python modules/logic required to run the tests.
- tests/original/: Translated original test cases (from JS).
- public_tests/: Public versions of some tests, as disclosed in the JS repo.
- requirements.txt: List of Python package dependencies (here: pytest).
- run_tests.sh: Bash script to run all tests via pytest.
- README.md: Project info and usage.
- project_structure.txt: This file, gives project overview and mapping.
