README.md
  - Overview and usage instructions.

src/
  - Source code for the library/module.
  - src/money.py is the entrypoint for financial handling functions.

tests/original/
  - High coverage, full internal/original test suite (all edge/internal/original test content translated from JS).
  - Separated with __init__.py for pytest discovery.

public_tests/
  - Tests intended for public/black-box validation, as in the original JS project.
  - Modular and similarly named as source, to mirror the JS suite and allow easy mapping from public_tests/.

requirements.txt
  - Lists pytest, the Python testing framework needed.

run_tests.sh
  - Simple one-liner script to run all tests (both tests/ and public_tests/) via pytest.

How to use:
1. Install dependencies: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`

Note:
- All test logic from JS is faithfully translated. Many tests expect functions to exactly mimic their JS counterparts' output and semantics. Implement src/money.py accordingly to pass all tests.
