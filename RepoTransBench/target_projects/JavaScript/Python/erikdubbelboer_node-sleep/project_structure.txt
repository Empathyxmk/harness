Directory explanations:
- src/: Python implementation source code (port of index.js)
- tests/original/: All original unit/integration tests from the source repo
- public_tests/: Public/coverage tests (direct translations of public JS tests)
- requirements.txt: Python dependencies
- run_tests.sh: Installs requirements and runs all tests with pytest
- project_structure.txt: This file
- README.md: Project summary/documentation and test instructions

Test/usage instructions:
1. Run `./run_tests.sh` from project root. All tests will execute via pytest.
2. Source code is in src/sleep_module.py.
3. All necessary test logic (including timing checks and exception cases) is implemented.
