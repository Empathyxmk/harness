Structure Explanation
---------------------
- `tests/original/`: Python ports of the original JS-based test cases.
- `public_tests/`: Python ports of public test cases from the original JS project's `public_tests/`.
- `requirements.txt`: Declares all Python dependencies (here, only pytest required).
- `run_tests.sh`: Shell script to run all test cases at once using pytest (easy/quick).
- `README.md`: Basic project info and test execution instructions.
- `project_structure.txt`: You are reading it.

Run all tests
-------------
    ./run_tests.sh

Python/pytest will auto-discover all test modules.
No configuration beyond installing required packages is needed.
