# Directory Explanations:
# - public_tests/: All translated public tests from public_tests/*.public.test.js, adapted for pytest
# - tests/: Placeholder for original (non-public) tests if ever needed
# - run_tests.sh: Simple shell script to run ALL tests (public and original, as present) using pytest
# - requirements.txt: Declares pytest as a dependency for running tests

# Test Running Instructions:
# 1. Install dependencies: `pip install -r requirements.txt`
# 2. Run all tests: `./run_tests.sh`
