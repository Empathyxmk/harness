# Directory explanations:
# - requirements.txt: Install all dependencies with `pip install -r requirements.txt` (only pytest needed here)
# - run_tests.sh: Executable bash script to run all tests (original and public) in one command
# - tests/original/: ALL original tests, identically ported from JavaScript (Jest) to Python (pytest)
# - public_tests/: ALL public tests, identically ported, using public-facing data variants where appropriate

# To run all tests, simply:
#   1. Install dependencies: pip install -r requirements.txt
#   2. Execute: ./run_tests.sh
