Directory/Files Overview:

src/super_expressive/
    - Python package for the main functionality (implementations go in core.py).

tests/original/
    - Contains all original ("private") tests converted from JavaScript.

public_tests/
    - Contains all public test cases, independently converted.

requirements.txt
    - Lists testing/development dependencies.

run_tests.sh
    - Run this script to execute all unit tests with one command.

Setup & Usage:
-----------------------
1. Install dependencies:
    pip install -r requirements.txt

2. Run all tests:
    ./run_tests.sh

You can also run individual test files directly with:
    pytest tests/
    pytest public_tests/
-----------------------
