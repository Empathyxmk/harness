project_structure.txt -- This explanation and directory tree.

Instructions:

1. Set up a Python virtual environment (optional but recommended):
   python3 -m venv venv
   source venv/bin/activate

2. Install dependencies:
   pip install -r requirements.txt

3. Place test files (fixtures: .pem, .txt, etc.) from the original JS 'test/' folder to the new 'test/' folder at project root,
   as Python tests expect these files in the relative '../test/' directory of the test scripts.

4. Run all tests with:
   ./run_tests.sh

All test logic is fully implemented and tests are separated into original and public suites, runnable with pytest.
