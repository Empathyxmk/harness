Directory explanations:

- requirements.txt:   Lists all required Python dependencies for this project.
- run_tests.sh:       Run "chmod +x run_tests.sh"; then "./run_tests.sh" runs all tests (both tests/ and public_tests/ via pytest).
- tests/original/:    Contains the original translated JS test logic, focusing on code "internals".
- public_tests/:      Contains compliance/public API-facing tests as required for public validation.
- project_structure.txt: This file (readme of the structure).

Setup and testing instructions:

1. Setup a virtualenv (optional, but recommended):
   python3 -m venv venv
   source venv/bin/activate

2. Install requirements:
   pip install -r requirements.txt

3. Run all tests:
   chmod +x run_tests.sh
   ./run_tests.sh

All tests will be discovered and run automatically.
