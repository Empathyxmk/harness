Descriptions:
- src/: Main Python package source code. (express_jwt_authz.py is a stub for middleware interface used by tests)
- tests/original/: Direct translations of the original project test cases.
- public_tests/: Translations of generated public test cases.
- requirements.txt: Python package requirement dependencies (pytest for testing).
- run_tests.sh: Simple Bash script for easily running all tests via pytest.
- project_structure.txt: This file, describes folder layout and roles.

Instructions:
1. Set up a virtualenv and install requirements: `pip install -r requirements.txt`
2. Run all tests: `./run_tests.sh`
