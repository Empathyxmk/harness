Instructions:

1. Setup:
   - Install dependencies: `pip install -r requirements.txt`

2. Run all tests:
   - Make the script executable if necessary: `chmod +x run_tests.sh`
   - Execute all tests: `./run_tests.sh`

Both `tests/original/` and `public_tests/` will be collected and run by pytest.

All original and public tests have been translated from JavaScript Mocha to Python pytest, preserving test intent and edge cases.
