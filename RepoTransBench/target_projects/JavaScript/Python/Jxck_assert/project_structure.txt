Directory explanations:

- src/jxck_assert/: Contains the implementation of the assertion functions and AssertionError, forming the assert API being tested.
- tests/original/: Contains the translated original (non-public) test cases from JavaScript, now written in Python using pytest framework.
- public_tests/: Contains the translated public tests from JavaScript, written in Python/pytest, separated as per source repo.
- requirements.txt: Test dependency definitions (pytest).
- run_tests.sh: Simple test runner script to execute all project tests.
- project_structure.txt: This project-wide structure and explanation file.

Testing instructions:

1. Install dependencies:
     pip install -r requirements.txt

2. Run all tests:
     ./run_tests.sh
