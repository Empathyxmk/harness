Directory Explanations:
-----------------------
- requirements.txt: Project dependencies. Run `pip install -r requirements.txt` to install.
- run_tests.sh: Run ALL tests (both tests/original and public_tests).
- tests/original/: Translated original (non-public) JavaScript tests.
- public_tests/: Translated public JavaScript tests.
- \_\_init\_\_.py: Marks directory as Python package, may be empty.
- test_\*.py: Python unittest or pytest test files.

Usage Instructions:
-------------------
1. Install Python dependencies:
      pip install -r requirements.txt

2. To run all tests (one-click):
      ./run_tests.sh

3. To run ONLY original or public tests:
      pytest tests/original/
      pytest public_tests/

All tests are translated from the JavaScript originals and are directly runnable with pytest.
