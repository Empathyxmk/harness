Directory/Files explanations:
- src/fft.py:
    Main FFT algorithm implementation; all tests expect FFT class to be importable from here.

- tests/original/:
    Contains Python translations of the original JavaScript test suites, preserving ALL original coverage AND structure.
    * test_fft.py:      Main original core test suite, functional and cross-referencing.
    * test_fft_extra.py:Edge cases, error-throws, conversion utilities etc.

- public_tests/:
    Contains Python translations of the "public" test suites, preserving all test logic.
    * test_fft_public.py:      Public-facing main FFT test suite (different numbers, truncation).
    * test_fft_extra_public.py:Public-facing extra/edge/error tests.

- requirements.txt:
    Lists all dependencies. (Install with `pip install -r requirements.txt`.)

- run_tests.sh:
    Run all tests (original and public) with a single command (`./run_tests.sh`). Uses standard `pytest`.

How to run:
    pip install -r requirements.txt
    ./run_tests.sh

Add FFT implementation in src/fft.py to make tests pass.
